# 绿意食光 · 素食与蔬食全球权威菜谱与测评导航

🌿 **Global Vegetarian & Vegan Authority Guide**

一个浅色清新、植物美学风格的全球权威素食与纯素平台导航系统。

---

## 🌟 页面特性

- **浅色清新植物美学**：采用嫩绿、鼠尾草绿与温润晨光配色体系，柔和微磨砂玻璃（Glassmorphism）与卡片微浮动动效。
- **全平台多维分类**：
  - 🇨🇳 **大中华区精选**：下厨房、豆果美食、爱料理、Cookpad台湾、美食天下、香哈网、杨桃美食网、香港01等
  - 🔬 **科学实测与实验室**：America's Test Kitchen、Serious Eats、Good Housekeeping Institute、Viva! Vegan Recipe Club、鲜味信息中心
  - 🌍 **全球媒体与榜单**：TasteAtlas 世界素食排名、BBC Good Food、HappyCow、NYT Cooking、Allrecipes、Food Network、EatingWell 等
  - 👩‍🍳 **知名名厨与获奖博客**：101 Cookbooks (Heidi Swanson)、Smitten Kitchen (Deb Perelman)、Cookie and Kate、Love and Lemons、Sharon Palmer
  - 🛠️ **数据工具与国际倡导**：Spoonacular API & 数据库、Veganuary 国际纯素一月、Reddit r/vegetarian 精华
- **实时即时搜索**：支持按平台名、特色标签、描述关键词与分类实时快速筛选。
- **特色标签筛选**：中式家常、严谨实测、食品科学、全食物、营养师主理、全球排行、视频教学等一键过滤。
- **收藏夹系统**：基于 LocalStorage 本地持久化，随时标记收藏喜爱的平台。
- **素食流派与营养指南弹窗**：内置纯素、蛋奶素、鲜味科学（Umami）与关键营养摄入建议。
- **全设备自适应**：完美适配桌面大屏、平板与手机移动端。

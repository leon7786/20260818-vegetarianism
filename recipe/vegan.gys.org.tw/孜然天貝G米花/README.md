?食材及佐料〔Ingredients〕：(4人份)​
▪天貝 ​ 200克​
▪胡椒鹽 ​ 適量​
▪孜然粉 ​ 適量​
▪油 ​ 適量​
​
?烹飪步驟：​
【刀工/前處理】​
1.天貝切1公分丁。​
​
【調理作法】​
1.天貝油炸至金黃色。​
2.炸好的天貝撒上胡椒鹽、孜然粉，完成！​

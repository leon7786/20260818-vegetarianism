## 📖 食譜圖文詳情 (中英雙語對照)

香椿是藥食兼用的食材，有著獨特的香氣，營養豐富且抗氧化第一！平常做好一罐放冰箱保存，拌飯隨時可配，非常方便！一個下飯的素燥，讓餐桌出菜不NG，餐餐都可以一碗飯配到底！​
​
?食材及佐料〔Ingredients〕：(可依人數需求做調整)​
▪素肉粒 300g​
▪香椿醬 1大匙​
▪胡椒粉 少許​
▪醬油 適量​
▪水 少許​
▪糖 適量​
▪鹽 適量​
​
?烹飪步驟：​
1. 素肉粒泡水至鬆軟，水分擠乾。​
2. 入鍋油炸，起鍋備用。​
3. 熱鍋，將素肉粒、醬油、香椿醬、水拌勻炒香。​
4. 續入胡椒粉、糖、鹽調味，小火煮10分鐘，完成!!!​

## 📖 食譜圖文詳情 (中英雙語對照)

【素食迷思 Q&A】明膠是提煉動物的膠質、水解熬製動物的皮或骨頭去製成，​
例如:魚皮、豬皮、牛皮等，它又可稱為動物膠、魚膠、吉利丁，是常見的食物添加劑。​
​
明膠可以分為兩種，有「食用」及「工業」用之分，工業用明膠是由垃圾皮革提煉，成本低廉。​
有許多黑心商人常將工業用的致癌明膠冒充為可食用明膠，而讓民眾在不知不覺中吃下最毒的食品‼️​
常含有明膠的食品如：棉花糖、小熊軟糖、部分果凍、漢堡糖等。​
​
根據新華新聞網調查發現：「食品中的明膠是一種不完全蛋白質，人體對其吸收利用率很低。」那些含有明膠的食品，不但根本沒有任何的營養成分，更讓許多無辜的動物白白犧牲。​
​
因此建議大家除了要警覺⚠️含有明膠的食品，因為它屬於葷食。​
兒童尤其要少吃含食用膠的食品，因為它會影響其他營養食品的攝入，而可能導致兒童營養不良、健康狀況亮紅燈?。​

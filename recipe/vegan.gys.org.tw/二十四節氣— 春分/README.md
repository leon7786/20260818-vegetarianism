二十四節氣—【春分】​
​
▏春分，日暝對分 ​ ​
「春分」是一年當中晝夜等長的日子，此時氣溫逐漸回暖，百花盛開，農民忙著耕種、果農培育果樹、茶農們忙著採收春茶，萬物生機蓬勃。​
​
▏跟著節氣養生​
春分是調整人體陰陽平衡的重要節氣，此時的天氣變化大，傳染病好發，應多注意保暖，多吃當令新鮮蔬菜、水果，如菠菜、香椿、碗豆、桑葚、草莓，還有多喝綠茶、紅茶、烏龍茶，除了可以養肝、助長陽氣還可提高身體的免疫力。​
​
▏跟著節氣戒殺護生​

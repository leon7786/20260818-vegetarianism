【觀音山 中華大悲法藏佛教會發起海鱺媽媽保育放流】​
觀音山 佛教會今年(2022)到澎湖跟農委會水試所合作，推動守護海洋活動，守護下一代的生態環境。​
​
【觀音山 與您一起守護生命、愛護海洋：海鱺媽媽、小海鱺寶寶感謝您】​
養殖戶說，「每一位海鱺每一年大約可以產(卵)兩次，每一次可以產300萬(顆卵)左右，所以繁殖速度算是滿快的，而且成長速度也滿快的。」每年4到9月是海鱺的繁殖季，因為成長速度快，成為了許多養殖業者及饕客的最愛。​
​
觀音山 中華大悲法藏佛教會帶領民眾，包括媽媽和小朋友去參與，透過保育放流跟海鱺媽媽順利孕育新生命的機會，來保育海洋資源。​
​
觀音山住持 龍德嚴淨仁波切表示，「海洋復育、生態保育是刻不容緩的，透過這樣有意義的活動，更能彰顯佛教慈悲利他的精神」。​
​
觀音山 佛教會與民眾說，「海洋保育，從你我做起！」您的護生善行，拯救萬千生靈，愛護海洋、保育放流馬上行動！​

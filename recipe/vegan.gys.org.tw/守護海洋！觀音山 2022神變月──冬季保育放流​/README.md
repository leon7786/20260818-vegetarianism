觀音山「2022神變月──冬季保育放流」主要放流物種為海膽、小丑魚、黃錫鯛，邀請您響應生命延續的保育放流活動，共同守護海洋平衡，修復海洋生態系，為海洋生物建造一處幸福園地。​
​
一、海膽​
海膽的主食是礁岩上的海藻，必須由牠們將海藻啃食乾淨，珊瑚的小寶寶才有空曠的礁岩能著苗生長。​
珊瑚礁是地球上最有價值的生態系統之一，孕育各類的海洋生物，是諸多海洋生物的家。如果海膽數量太少，藻類太多，會導致珊瑚礁消失。然而，海膽卻被人們吃到快滅絕了…。​
​
二、克氏雙帶海葵魚(小丑魚)​
動畫電影「海底總動員」的大賣座，使片中的主角小丑魚「尼莫」，成為家喻戶曉的水中明星，同時也成了水族熱門寵物而遭受不當捕捉。海裡的「尼莫」正逐漸消失中…。​
臺灣的原生種小丑魚「克氏雙帶海葵魚」，因為人為及環境變化，數量不斷減少，需要復育以修復海洋生態系，讓海洋復育發揮最大影響力！還給海洋生物一個適合生存的環境。​
​
三、黃錫鯛​
黃錫鯛棲息於沿岸岩礁區或礁砂交錯處， 為耐寒的魚種，不必擔心無法承受冰冷的水溫，具有群居性，產卵期為11-2月。此時正是施放的好時機，萬千魚子在腹中，救一條魚，等於就是救萬千條魚。​
​

【素食營養補給站】素食中的山珍─薑✨​
​
素食料理當中最常見到使用薑的料理。薑屬於薑科植物薑的根莖部分，除了作為一般做菜時的配菜外，還可以入藥唷!?此外，將熬出來的薑汁稀釋於洗澡水中，不但可以促進血液循環，也可以改善腰酸背痛的毛病喔!
​
?【薑的成份】​
1.生薑醇及薑烯酚（也許是止吐的重要成分）。​
2.薑辣素（辣味成分來源）。​
3.揮發油類（薑的香氣來源）。​
4.其他：黃樟素、澱粉等。​
​
?【薑的功用】​
1.預防暈車、暈船：?
實驗發現，服用生薑粉的受試者，出現暈車症狀的時間較晚，並且使胃部保持在較為正常的狀態。​
2.促進血液循環：
女性飲用薑茶可以改善手腳冰冷的症狀，或是緩和生理期不適現象，並有助於排汗。​
3.健胃整腸：​
生薑屬於溫性，可以降低食物的寒涼性，並且對於生冷食物有去腥功效。此外，還可以可消除漲氣、抒解消化不良症狀。​
4.其他：​
利尿消腫、預防感冒?、止痛等。​
​
?【食用須知】​
1.薑最好不要服用過量?，否則會對視力造成不良的影響。​
2.雖然薑的功效不錯，但是因為刺激性較強，所以食用時還是要適量比較保險。​
3.如果是痔瘡病患，千萬不可以同時食用薑與酒，否則易使痔瘡復發。​
4.眼睛乾澀、易長青春痘、肝病患者，或是喉嚨不舒服的人，最好不要食用生薑。​
5.若是覺得薑過於辛辣，可以先將其浸泡在清水中，便可減輕辛辣味!​

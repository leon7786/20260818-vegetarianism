素食迷思 Q&A｜「結蘭膠」素食者可以吃嗎？
​
食用膠可分為植物膠、海藻膠、動物膠、微生物膠、化學改性膠五類；「結蘭膠」是屬於微生物膠的範圍中，乃由微生物發酵生產而來的物質，就像酵素、醋等發酵的食品，所以結蘭膠是屬於「素食」。
​
一般而言，「結蘭膠」常被添加在飲料、優酪乳、果凍、果醬等，因此若食品內有添加「結蘭膠」，素食者是可以食用的。

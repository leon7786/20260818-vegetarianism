## 📖 食譜圖文詳情 (中英雙語對照)

杏鮑菇切成圓塊，橫切、縱切刻花，看起來如鮮嫩多汁飽滿的干貝，搭配色澤豐富的彩椒?，一道兼具美味與視覺享受的「彩椒素干貝」，您一定要學會！​
​
?食材及佐料〔Ingredients〕：​
▪️杏鮑菇 5個​
▪️青椒 1/4顆​
▪️黃椒 1/4顆​
▪️紅椒 1/4顆​
▪️鹽 少許​
▪️香菇粉 少許​
​
?烹飪步驟：​
1.杏鮑菇切圓塊狀，兩面刻花；青椒、黃椒、紅椒切方形，備用。​
2.起油鍋，杏鮑菇煎至金黃色，加入鹽、香菇粉調味。​
3.續入三色椒拌炒，完成!!!✅​

## 📖 食譜圖文詳情 (中英雙語對照)

素食迷思 Q&A｜你知道「吉利丁」與「吉利T」，哪一種素食者可以吃嗎？
​
吉利丁與吉利T都是製作甜點、果凍等常會用到的凝膠劑，但是其成分卻是大大的不同。
​
「吉利丁」(Gelatine)是從動物的骨頭、皮等組織提煉出來的膠質，又稱為明膠，素食者是不能食用的。
​
「吉利T」則是從海藻萃取而成的海藻膠，又稱為果凍粉，全素者是可以食用的，在購買甜點時要特別注意兩者的區別。

## 📖 食譜圖文詳情 (中英雙語對照)

今年過年不來豬，觀音山主廚教你手作藍帶朱排。
外表黃金酥脆，內裹香濃起司的藍帶朱排，Q彈甜鹹的菜脯麻糬燒，黃金雙炸物～讓你牛年旺返，吉祥如意過好年！
快跟著觀音山主廚，一起素食料理簡單做吧！
?食材及佐料〔Ingredients〕：(5人份)
▪火腿 1/3條
▪起司絲 30克
▪起司粉 10克
▪麵包粉 200克
▪麵糊、沙拉油 適量
▪菜脯麻糬燒 5塊
?烹飪步驟：
⭐藍帶朱排
1.火腿切0.5公分蝴蝶刀備用。
2.火腿夾入起司絲、起司粉，沾上麵糊，裹上麵包粉，壓扎實備用。
3.油加熱約180度，將食材炸至金黃。
⭐菜脯麻糬燒
1.約170度油溫，油炸約6分鐘即可。
【特別說明】
1.藍帶朱排可以搭配生菜絲，以及沙拉類的醬料，一起享用。
2.菜脯麻糬燒可在素料店購買。

## 📖 食譜圖文詳情 (中英雙語對照)

素食迷思 Q&A｜素食者如何補充膠原蛋白？
​
膠原蛋白的來源是什麼呢？一般而言，膠原蛋白是蛋白質的一種，只存在「動物」體內，常見的來源有豬皮、魚膠、海參、魚鱗等，所以100%屬於葷食的成分。
​
市面上所看到素食膠原蛋白、植物膠原蛋白等標示，指的是植物當中的「膠質」，植物膠質是由水溶性纖維與醣類構成，與動物性膠原蛋白有很大的不同。
​
素食者要補充膠原蛋白，可以從補充膠質（木耳、海帶、山藥、黃金果）並攝取富含維生素C（柑橘類水果）、維生E（酪梨、堅果）、蛋白質（豆腐、鷹嘴豆）等天然食物，讓身體自然合成膠原蛋白，同時還可以享受素食的種種好處。

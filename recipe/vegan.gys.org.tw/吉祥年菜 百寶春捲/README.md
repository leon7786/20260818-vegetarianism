## 📖 食譜圖文詳情 (中英雙語對照)

炸春捲有著迎接春天、喜慶的意思。
金黃的外表，猶如黃金萬兩，又有大富大貴的寓意。
這道百寶春捲搭配酸甜醬料，少了油膩多了美味，讓你吃了牛兆豐年。
快跟著觀音山主廚，一起素食料理簡單做吧！
?食材及佐料〔Ingredients〕：(3人份)
▪火腿 30克
▪香菇 10克
▪芋頭 200克
▪香菜、芹菜 適量
▪紅蘿蔔 10克
▪越南春捲皮 6張
▪馬蹄 30克
▪地瓜粉、沙拉油、糖、鹽、胡椒 適量
?烹飪步驟：
【刀工/前處理】
1.芋頭去皮，切塊蒸熟壓泥備用。
2.火腿、香菇、香菜、芹菜、紅蘿蔔、馬蹄切小丁。
【調理作法】
1.取一張越南春捲皮，平均拍水回軟，包入芋泥、炒好的餡料，捲成春捲狀並沾地瓜粉備用。
2.油鍋加熱約180度，放入春捲油炸至金黃色即可。
【特別說明】
1.可以搭配個人喜愛的醬料一起享用，推薦酸甜解膩風味的醬料。
2.炸春捲時要小心沾黏，以免易黏住。

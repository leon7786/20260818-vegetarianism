素食迷思 Q&A｜冰淇淋 是素食的嗎?
​
炎炎夏日，業者常推出不同限定口味的冰淇淋，讓大人小孩愛不釋手，然而冰淇淋，素食者可以放心食用嗎?
​
一般而言，生產者為了提升冰淇淋的口感、讓其不要那麼快融化，常會添加「乳化劑」與「安定劑」，這兩種成分的來源可能為動物性或是植物性，若兩皆為植物性，就可以安心購買；標示為動物性成分或是沒有標示，則需要詢問清楚，否則可能會吃下葷食。
​
市售的冰淇淋，大多為「奶素」，少部分為全素或蛋奶素，因為種類很多，需要仔細一一挑選；知名便利商店的霜淇淋，也在官網說明因為產線沒有獨立，素食者是不能食用的。因此確認成分標示、有詢問店家，才能避免吃到葷食。

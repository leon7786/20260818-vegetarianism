## 📖 食譜圖文詳情 (中英雙語對照)

素食迷思 Q&A｜你知道「動物性奶油」、「植物性奶油」的來源嗎？素食者可以吃嗎？
​
「動物性奶油」是由牛奶中萃取出來的乳脂，屬於天然奶油，其保存期限較短，製作過程比較少有添加物，奶素的人是可以食用的。
​
「植物性奶油」是將棕櫚油、椰子油等植物油加工製成，主要是為了模仿奶油的口感，製作過程中有較多添加物，屬於「人造奶油」，全素食者是可以食用的。
​
貼心叮嚀：當成分標示為「人造奶油」時，來源有可能包含動物油脂(牛油、豬油)，素食者在購買麵包抹醬、蛋糕甜點、玉米濃湯等產品時，需注意確認清楚成份來源。

## 📖 食譜圖文詳情 (中英雙語對照)

螞蟻上樹菜名源於肉末沾在粉絲上，看上去如螞蟻在樹枝上爬。素食的螞蟻上樹選用材料包括皮絲、各式菇類來取代肉末，口感上更能吸飽醬汁，選用讓蒟蒻條配起來更爽口Q彈。​
現在就一起跟著「觀音山蔬食館」的主廚，素食料理簡單做吧！​
​
?食材及佐料〔Ingredients〕：（3人份）​
▪皮絲300克​
▪杏鮑菇100克​
▪乾香菇50克​
▪蒟蒻條200克​
▪金針菇100克​
▪芹菜50克​
▪香油2ml​
▪素辣豆瓣醬1匙​
▪素蠔油2匙​
▪水50ml​
▪薑適量​
​
?烹飪步驟：​
1.將皮絲切塊，杏鮑菇切絲、金針菇切段、乾香菇泡軟後切細丁，芹菜、薑切細末後備用。​
2.將蒟蒻用沸水汆燙後取出。​
3.熱油鍋，倒入香油，放入薑末、皮絲、香菇丁、杏鮑菇炒香。​
4.加入蒟蒻條、金針菇 ，水、素辣豆瓣醬、素蠔油調味，最後撒上芹菜末、香菜擺盤，即完成。​

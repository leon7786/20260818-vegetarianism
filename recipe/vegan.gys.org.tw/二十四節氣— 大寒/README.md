「大寒」一年中最後一個節氣，代表冬季即將結束，農曆春節緊接而來，許多人忙著除舊佈新、備辦年貨，濃厚的過年氛圍充滿大街小巷，在外出時確實做好保暖防護，好好調養身體、養精蓄銳，以最佳的狀態迎接新的一年。

## 📖 食譜圖文詳情 (中英雙語對照)

過年餐桌上總是少不了一道吉祥羹湯，這一道香濃、滑嫩的福慧吉祥羹，吃得到傳統懷念的好味道，勾芡羹湯淋上醋、香油，撒上香菜，讓人忍不住食指大動！
快跟著觀音山主廚，一起素食料理簡單做吧！
食材及佐料〔Ingredients〕：(5人份)
▪素肉羹 100克
▪金針 30克
▪大白菜 200克
▪金針菇 70克
▪紅蘿蔔 適量
▪乾香菇 30克
▪竹筍 150克
▪香菜 少許
▪糖、鹽、胡椒粉、香油、醋、玉米粉 適量
烹飪步驟：
【刀工/前處理】
1.竹筍燙熟，切絲備用。
2.金針泡水後，打結。
3.紅蘿蔔、乾香菇切絲。
4.金針菇剝絲。
5.玉米粉加水稀釋。
【調理作法】
1.乾香菇炒香放著。
2.大白菜川燙後，起鍋泡冷水； 將大白菜切粗絲備用。
3.準備一鍋水，將水煮開，先放竹筍下去煮15-20分鐘，煮熟後，依序將香菇、金針菇、紅蘿蔔、大白菜、素肉羹放入鍋中。
4.將湯調味後，放入金針。
5.最後，將湯勾芡並淋上少許香油，起鍋後加入香菜。
【特別說明】
1.香油可用麻油代替，依個人喜好。
2.可依個人喜好選擇素料。

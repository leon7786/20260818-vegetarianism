## 📖 食譜圖文詳情 (中英雙語對照)

這一道簡單易學的『美式麥香G堡』，不僅愛護動物，自己動手做蔬食，健康又環保，醬料也可依個人喜好變化喔。​
快跟著觀音山蔬食館主廚，一起素食料理簡單做吧!​
​
?食材及佐料〔Ingredients〕：(3人份)​
▪素G塊 9塊​
▪起司片 3片​
▪漢堡 3個​
▪美式芥末醬 適量​
▪番茄醬 適量​
▪美奶滋 適量​
​
?烹飪步驟：​
1.將素G塊炸熟。​
2.將漢堡烤過切開，擠上美乃滋。​
3.漢堡麵包依序放上起司片、素G塊、適量美式芥末醬及番茄醬。​
4.擺盤完成！！​
【特別說明】​
可依個人喜好變化醬料。​

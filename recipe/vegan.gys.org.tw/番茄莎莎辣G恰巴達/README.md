## 📖 食譜圖文詳情 (中英雙語對照)

巧巴達是傳統的義式麵包，含水量高、口感鬆軟不失嚼勁，因麵包又平又長像拖鞋，又稱拖鞋麵包。​
觀音山主廚使用特色巧巴達麵包，內夾素辣雞塊搭配特調番茄莎莎醬料，酸甜好吃又開胃！​
快跟著觀音山蔬食館主廚，一起素食料理簡單做吧!​
​
?食材及佐料〔Ingredients〕：(3人份)​
▪素辣雞塊 9塊​
▪美生菜 200克​
▪番茄 300克​
▪巧巴達麵包 3個​
▪九層塔 20克​
▪香菜 20克​
▪橄欖油 適量​
▪蜂蜜 適量​
▪糖 適量​
▪鹽 適量​
▪檸檬汁 適量​
​
?烹飪步驟：​
1.將番茄去籽切丁，香菜及九層塔切末。​
2.辣雞塊先炸過。​
3.巧巴達麵包烤過切開。​
4.製作番茄莎莎醬：將糖、鹽、番茄丁、香菜末、九層塔末，加入適量的橄欖油、蜂蜜和檸檬汁攪拌均勻，醃漬10分鐘。​
5.依序放上美生菜、辣雞塊，淋上番茄莎莎醬，完成！​
【特別說明】​
素雞塊種類（蛋素、全素）可依個人需求採買​

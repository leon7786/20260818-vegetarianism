## 📖 食譜圖文詳情 (中英雙語對照)

鮮甜翠綠的櫛瓜帶著迷迭香氣、素花枝丸灑上海鹽，展現出不同凡響的風味，絕對是您閤家大小團聚時的美味首選~ 中秋節即將到來，＃響應蔬食，在家試試素食花支串，非常的應景對味！​
​
食材與佐料：(3人份)​
▪️素花枝丸 10顆​
▪️綠櫛瓜 1條​
▪️紅椒 1顆​
▪️黃椒 1顆​
▪️迷迭香草 1株​
▪️海鹽 5克​
​
烹飪步驟：​
1. 彩椒切方塊；櫛瓜切圓片；素花枝丸對半切，備用。​
2. 將所有食材串入竹籤，製成花枝串。​
3. 將花枝串以中火油炸，炸至金黃色，起鍋瀝乾。​
4. 灑上海鹽、迷迭香草葉，完成!!!✅​

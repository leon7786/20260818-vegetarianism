​
適逢慈愛的母親節，觀音山搶救懷孕的海鱺媽媽活動亦推廣海洋淨灘、蔬食環保，盼一同加入愛護地球的行列。龍德嚴淨 仁波切：「民以食為天，如果吃素的習慣可以養成，會給自己帶來沒有負擔，沒有虧欠感。如果可以長期茹素，不以眾生的皮肉骨血來滋養自身，達到對眾生真正的尊重，那是一種真平等的體現。」​

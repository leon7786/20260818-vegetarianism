## 📖 食譜圖文詳情 (中英雙語對照)

【素食迷思Q＆A】吃素會沒體力，容易肚子餓❓​
​
答:香港中醫師葉榮坤《生存之道》裡面寫道:「長期食肉的人，動物脂肪損耗大量膽汁，對消化系統有不良影響，削弱了消化力。」​
​
所以食肉有耐飽的感覺，多食肉的人剛轉為吃素?，膽汁的消耗量隨即減少，消化力隨即轉強，因此容易感到飢餓。​
​
素食一般含脂量較少，故損耗膽汁亦少;素食所含的脂肪屬不飽和性植物脂肪，較動物脂肪易吸收，胃酸分泌亦少。因此，人體的膽汁及胃酸儲量相對增多。​
​
初轉食素的人消化力增強，容易飢餓是常有的現象。而且，長期食肉，消化系統所作的慣性分泌，在轉食素的初期依然按時出現。需經一段調整期就會協調平衡，不用擔心。?​
​
素食者的熱量低於葷食，吃下同樣的份量，熱量卻是低的。解決之道是：可以在肚子餓吃一些醣類(如：蘇打餅乾、全麥吐司??等)補充熱量。​

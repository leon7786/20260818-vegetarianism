## 📖 食譜圖文詳情 (中英雙語對照)

桑葚是我們常食用的水果之一，盛產於4到6月，它同時也是一味珍貴的中藥材，具有多種保健功效，可以保養肝腎的健康，並有讓頭髮變黑、眼睛?明亮的效果，是美容養顏的好食材。​
​
桑葚營養豐富，含有多種胺基酸、維生素及有機酸、胡蘿蔔素 等等，被譽為「二十一世紀的最佳保健果品」，能提高人體免疫力以及具有延緩衰老的功效。特別注意的是，桑葚含糖量高?，不可過量。​
​
桑葚一般都是直接食用，營養不易流失，亦可以搭配其他水果打成成果汁或是自己熬煮果醬，甚至可以入菜。​
​
?選購和保存方式：​
顏色越近紫黑的，表示越成熟也越甜，果實顆粒豐厚飽滿、蒂頭翠綠的較為新鮮，由於桑葚鮮果非常嬌貴、不易保存，可以將洗淨瀝乾的桑葚冷凍，延長保存期限。​

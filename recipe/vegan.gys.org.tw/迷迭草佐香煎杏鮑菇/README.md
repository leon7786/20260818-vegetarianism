?準備食材與佐料：(3人份)​
番茄2顆、杏鮑菇2條、火龍果半顆、奇異果2顆、水蜜桃罐頭取果肉2片、新鮮迷迭香1株、苜蓿芽50克、檸檬1/4顆、奶油150克、鹽5克、胡椒粒少許。​
​
?#素食料理簡單做，開始：​
1. 番茄洗淨切片(厚度約0.5cm) ；杏鮑菇去頭切厚片(厚度約3cm) ；苜蓿芽洗淨脫水；檸檬擠出檸檬汁取5～10ml，備用。​
2. 火龍果、奇異果、水蜜桃果肉，使用模型壓出小丁，裝飾備用。​
3. 奶油於鍋中小火熔化後，中火香煎杏鮑菇至雙面微焦黃，再加入鹽調味，起鍋備用。​
4. 鍋中放入迷迭香草，小火炒香，倒入碗中加入檸檬汁攪拌均勻，製成醬汁，備用。​
5. 以番茄片、杏鮑菇、水果小丁裝飾擺盤，淋上奶油檸檬汁，撒上胡椒粒，即可。​
​

?特別說明：​

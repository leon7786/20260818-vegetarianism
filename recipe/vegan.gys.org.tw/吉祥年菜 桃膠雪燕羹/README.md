?食材及佐料〔Ingredients〕：(5人份)
▪桃膠 12.5克
▪雪燕 12.5克
▪皂角米 12.5克
▪紅棗、枸杞、冰糖 適量
▪水 4000CC
?烹飪步驟：
【刀工/前處理】
1桃膠、雪燕泡水15小時，反覆過濾雜質清洗乾淨。
2.皂角米泡發10小時，清洗乾淨。
【調理作法】
1.先將桃膠、皂角米、紅棗加入水，約煮20分鐘後，再放入雪燕煮10分鐘。
2.最後，加入冰糖、枸杞即可。

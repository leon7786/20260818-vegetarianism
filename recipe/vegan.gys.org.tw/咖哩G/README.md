## 📖 食譜圖文詳情 (中英雙語對照)

無論是拌麵、拌飯都很適合！濃郁咖哩香氣，熱騰騰幸福滋味，一起來素食料理簡單做吧!​
​
?食材及佐料〔Ingredients〕：(3人份)​
▪素炸雞200克​
▪紅蘿蔔 1/2條​
▪馬鈴薯2顆​
▪玉米筍6支​
▪西芹末30克​
▪綠花椰菜1/4朵​
▪素咖哩塊4小塊​
▪水500c.c​
​
?烹飪步驟：​
1.紅蘿蔔、馬鈴薯洗凈去皮切塊；西芹洗淨切末；玉米筍洗凈切段；綠花椰菜切小朵洗凈，備用。​
2.將玉米筍、綠花椰菜汆燙，備用。​
3.熱油鍋180度，將素炸雞炸至金黃色，起鍋備用。​
4.熱鍋，放入紅蘿蔔塊、馬鈴薯塊拌炒，加入水煮滾沸。​
5.放入素咖哩塊攪拌均勻，轉小火，蓋鍋悶熟馬鈴薯及紅蘿蔔。​
6.放入炸好的素炸雞微拌即可。​
7.起鍋玉米筍、綠花椰菜，加入擺盤，灑上西芹末完成！​
​
【特別說明】​
1.可以搭配飯、麵食一起享用。​
2.炸雞入鍋後，微拌勻即可起鍋，避免煮太久影響口感。​

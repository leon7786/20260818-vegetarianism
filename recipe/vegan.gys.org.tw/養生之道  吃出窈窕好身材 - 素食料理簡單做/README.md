【#蔬食環保救地球】 吃出窈窕好身材，素食者通常比肉食者苗條。​
​

素食者有助血液保持微鹼性，使身體的新陳代謝活躍起來，加速燃燒脂肪。​
​
同時，不少素食食物都能讓您吃出窈窕好身材✨。​

▪大豆含亞油酸，即Omega6，亞油酸含量高達51.8%，能阻止膽固醇在體內積存。​

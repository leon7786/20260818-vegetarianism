## 📖 食譜圖文詳情 (中英雙語對照)

來自於非洲的植物「冰花」，葉面上結滿鹽晶顆粒，如同冰晶一般，故被譽為「鑽石花」，屬高經濟價值的蔬菜，而澎湖獨特的天候與空氣中的鹽分，非常適合其生長；冰花可以直接食用、做成沙拉、甚至打成果汁都很美味，其口感清爽，帶有天然的鹹味，是營養價值很高的養生蔬菜，快跟著觀音山主廚，一起素食料理簡單做吧！​
​
​

## 📖 食譜圖文詳情 (中英雙語對照)

＼＼＼海膽放流 大慈悲雲／／／​
慶讚偉大 蓮師成道暨 殊勝 湯東佳波大師聖誕紀念日​
系列活動吉祥圓滿 復育千隻馬糞海膽苗​
​
​
觀音山 中華大悲法藏佛教會 宜蘭 普賢佛學會，於03/12（六）舉辦偉大 蓮師成道暨大成就者 湯東佳波大師聖誕紀念日一系列的慶讚活動。當天下午恭請慈悲 龍德上師以吉祥具義的「春季海膽保育放流」，揭開慶讚活動的序幕。本次放流和「臺灣海洋保育與漁業永續基金會」合作，施放數千隻馬糞海膽苗，現場超過數百位的同修法友共同與會。​
​
​
在慈悲 龍德上師主法加持之下，同修法友虔誠合十，修持放生儀軌和六字大明咒，氣氛莊嚴而肅穆，一齊以佛力祝福、祈願生靈能免受身肉割截之苦，締結來日學佛修行的善因緣。同修魚貫地排成兩行，把一袋袋的海膽從車上搬下來，以兩兩接力的方式將海膽運至港口邊，由專人乘船至近海區域施放。​
​
​
澎湖的馬糞海膽是臺灣目前瀕臨滅絕的物種之一，由於人們認為繁殖季的海膽風味最鮮美，因此海膽往往來不及繁衍後代便被捕撈，海膽的復育刻不容緩。觀音山的保育放流活動，除了拯救物命，亦同時著眼於海洋生態的永續發展，希冀以護生的善行供養偉大 蓮師和 湯東佳波大師，為當日晚上於宜蘭「普賢佛學會」舉辦的薈供慶讚法會，開啟吉祥的緣起！​
​
​
而當日晚上 「 慶讚偉大 蓮師成道暨殊勝 湯東佳波大師聖誕薈供法會」，慈悲的 龍德上師亦親傳偉大 蓮師傳承的《八大龍王煙供法》，並做契機的開示：龍族具大威力能興雲布雨，善龍為佛教之護法，惡龍會障礙佛法，但如今因人類濫捕水族、排放工業廢水破壞生態，越來越多善龍轉為惡龍，而修持龍王供養的法門，能喚醒祂們往昔擁護佛法所發的本誓願力！​
​
​
在法會的隔一天便是「供養法界龍族賜財祈福法會」，觀音山眾弟子遵循偉大 蓮師及 湯東佳波大師所教勅，廣行放生、廣修供養，以此之善業消弭自身災厄、培福積德，並迴向天下無災無難、人民無憂無怖、安樂幸福！​

​

​
而素魚、素肉是一些由豆類、菇類加工製成，不必特別調味，嚐起來就非常有味道，因此對於初期轉吃素的人，素料是他們的最佳選擇?。許多餐廳業者也會搭配特別的素料來增加豐富度及美味度。?​
​
吃素的人並不是想吃魚肉的本體而去吃素魚、素肉，而是我們都喜歡吃有味道的美食，素魚、素肉只是其中一種而已。​

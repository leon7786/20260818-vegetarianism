傳統習俗會吃『臘八粥』來添運增福✨
⭐為何吃臘八粥可添運呢❓ ⭐
原來農曆十二月初八是✨佛陀成道紀念日✨，佛經記載，釋迦牟尼佛成佛之時，大地震動諸天神人齊讚，地獄、餓鬼、畜生三道的許多苦厄，一時體息，天鼓齊鳴，發出妙音，天雨曼陀羅花，曼殊沙花，金花、銀花、琉璃花、寶花、七寶蓮花…等做廣大供養，後世虔敬供養者無不廣植福田，來日圓成菩提！✨
這麼有意義的節慶，觀音山素食料理簡單做，邀請您一起快速料理臘八粥，護持供僧迅速累積福慧二資糧。
?準備食材〔Ingredients〕 (兩人份)
▪️市售八寶粥 2罐
▪️紅棗 少許
▪️白木耳(銀耳) 少許
▪️水 600ml
?? 跟著我們一起做：
❶ 起一鍋600ml的水煮沸。
❷白木耳洗淨用熱水泡軟，剝成小朵。
❸紅棗洗淨，可以用刀子劃開，讓紅棗風味更容易釋放出來。
❹倒入八寶粥，將白木耳和紅棗入鍋一起煮10分鐘之後，蓋上鍋蓋悶10分鐘。
❺一道吉祥好運的甜品就完成了！
【特別說明】
可以加入少許堅果，增加口感和風味，營養又美味。

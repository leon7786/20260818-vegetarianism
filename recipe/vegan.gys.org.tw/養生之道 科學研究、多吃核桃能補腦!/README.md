【＃素食營養補給站】科學研究、多吃核桃能補腦!​
​
有「堅果之王」之稱的核桃✨可說是健康好食材！?​
富含蛋白質、維生素E、多酚、Omega -3脂肪酸等營養，對健康好處多多，因此還有「長壽果」的美稱?。​
​
?英國《每日郵報》報導指出，​
美國哈佛醫學院在《營養生物化學期刊》發表了一項研究，研究員在罹癌老鼠?的飲食中，加入 57 公克的核桃，另一組老鼠以類似的飲食方式餵養，但是不吃核桃。​
25 天後發現有吃核桃的老鼠，其體內腫瘤的Omega-3脂肪酸的含量，比不吃核桃的老鼠多出了10倍，可以減少大腸直腸癌細胞的發炎現象?，還能減少供應至腫瘤的血流量，減緩腫瘤的成長速度?。​
​
Omega-3脂肪酸是由DHA、EPA、ALA所組成，有助於降低膽固醇和血壓，預防心血管疾病，其中ALA只存在於植物?之中，核桃就是ALA含量較多的食物，有豐富的Omega-3脂肪酸。​
此外，核桃每1公克就含有12.5毫克的多酚，還有豐富維生素E，可以幫助身體抗氧化，抗老效果再加分。?​
​
既然核桃有這麼多好處，下次嘴饞時，不妨吃一點核桃當作零嘴，既能滿足口腹之慾，又能吃進各種營養素，有助降膽固醇、抗老化，都能一次做到!?​

✨欣逢薩嘎達瓦月，一年之中難得值遇”億倍功德”日！
觀音山「搶救懷孕的海鱺媽媽」愛護海洋、放流保育計畫，引起各界熱烈迴響。本會將在億倍功德 薩嘎達瓦月，舉辦季節性的護生放流活動，放流期間為6月。
為確保護生放流之生靈不會再次被捕殺，本會不公布放流日期，改為圓滿後於官網公布相關活動訊息。

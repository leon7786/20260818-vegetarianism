?【綠色婚禮教戰守則】​
1.喜帖：電子/環保素材。
數位時代，e化的電子喜帖風格更多變，也能省下一筆費用成本，減少婚禮製造的垃圾量。自行設計線上回函機制，更即時準確的掌握出席狀況。​
​
2.地點：戶外/有意義的公共空間/方便搭乘大眾交通工具。​
在戶外舉辦婚禮，可以省下空調、燈光等碳足跡，還能親近大自然。
​
3.婚紗：租/借/一套到底。
以重複利用與不浪費為原則，並考量往後的實穿性。​
​
4.婚宴食材：採行素宴。​
取當地時令新鮮蔬果，特別講究食物里程數，拒食動物製品等高碳足跡食品。
​
5.伴手禮：實用性/具意義/注意製造過程。
注重實用且有意義的心意；製造材料、方式、地點則是禮物的挑選原則。​
​
6.禮金：可考慮捐給認同的公共議題或組織單位。​
在婚禮中充滿祝福，播下了善種子，讓善良的力量接力般地傳遞。​

## 📖 食譜圖文詳情 (中英雙語對照)

素食迷思 Q&A｜食用色素「胭脂紅」，素食者可以吃嗎？
​
答案是「不可以」，因為食用色素「胭脂紅」是從生活在仙人掌的「胭脂蟲」身上所提煉的，儘管它被定義為天然的食用色素，但還是屬於葷食的範疇。
​
❒ 食用色素「胭脂紅」，所添加的食物有哪些呢？
一般會在蛋糕、餅乾、草莓果醬、甜點、果汁等紅色食品中被添加，所以素食者在購買相關食品時，要特別注意是否有添加「胭脂紅」此種成份！

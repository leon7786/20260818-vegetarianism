## 📖 食譜圖文詳情 (中英雙語對照)

酥脆的金黃豆皮，包覆新鮮蘆筍、素火腿、紅黃椒及鳳梨片，豐富的口感層次，吃起來很有飽足感，可以作為宴客時招待客人的小點。​
快跟著觀音山蔬食館主廚，一起素食料理簡單做吧!​
​
?食材及佐料〔Ingredients〕：(4人份)​
▪生豆皮 5片​
▪蘆筍 5根​
▪素火腿 100克​
▪紅甜椒 1/2顆​
▪黃甜椒 1/2顆​
▪罐頭鳳梨 3片​
▪素蠔油 50ml​
▪太白粉 5克​
▪麵粉 適量​
▪香油 適量​
▪水 20ml​
​
?烹飪步驟：​
1.將蘆筍洗淨切3等份；紅甜椒、黃甜椒、素火腿切條狀；罐頭鳳梨片3片，每片切成6等分，備用。​
2.取生豆皮1片，放入蘆筍、紅甜椒、黃甜椒、素火腿、鳳梨2小片，麵粉加水拌成糊狀，將食材捲起後以麵糊固定。​
3.將時蔬卷放入150度熱油鍋大火油炸，炸至金黃色，即可起鍋。​
4.素蠔油加水，入鍋微炒熱，再加入10ml太白粉水，些微勾芡，製成醬汁。​
5.將時蔬卷擺盤，淋上適量香油及醬汁，完成！！​
【特別說明】​
醬汁可依個人口味調整，若不勾芡亦可直接淋上素蠔油即可。​

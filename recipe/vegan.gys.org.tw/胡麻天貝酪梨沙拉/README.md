?食材及佐料〔Ingredients〕：(4人份)
▪天貝 150克
▪酪梨 70克
▪番茄 70克
▪綜合生菜 100克
▪胡麻醬 適量
▪橄欖油 少許
?烹飪步驟：
1.天貝切1公分丁
2.酪梨切1公分丁
3.番茄去籽，切1公分丁
4.天貝油炸至金黃色備用
5.天貝、番茄、酪梨，淋上少許橄欖油，輕輕拌勻。
6.擺盤，放上天貝酪梨沙拉、綜合生菜、胡麻醬即可享用。

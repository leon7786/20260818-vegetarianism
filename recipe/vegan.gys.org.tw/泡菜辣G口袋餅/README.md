## 📖 食譜圖文詳情 (中英雙語對照)

口袋餅pita是中東地區傳統麵包，又稱阿拉伯薄麵包，烘烤後中間膨起，對切變成袋子形狀。​
可將新鮮蔬菜、變化食材滿滿包進口袋餅中，快跟著觀音山主廚，一起動手做這道美味早午餐料理吧！​
​
食材及佐料〔Ingredients〕：(3人份)​
▪素辣雞塊9塊​
▪素韓式泡菜100克​
▪生菜100克​
▪番茄1顆​
▪口袋餅1張​
​
烹飪步驟：​
1.將番茄切片，素辣雞塊炸過切對半。​
2.口袋餅使用平底鍋，雙面加熱至膨脹，切對半。​
3.取一張餅皮，將餅皮撐開，將食材依序擺上。​
4.擺盤完成！​

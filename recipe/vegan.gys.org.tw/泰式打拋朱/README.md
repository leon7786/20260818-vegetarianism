## 📖 食譜圖文詳情 (中英雙語對照)

「打拋」是泰國的國民美食，起源於它的食材：「打拋葉」，是相似於九層塔的辛香料，氣味更濃烈辛嗆，由於台灣不易買到，一般可直接用九層塔代替。​
這道「泰式打拋素肉」食譜 ，使用素碎肉收汁，更易入味，是下飯的絕佳配菜。現在就跟著「觀音山蔬食館」的主廚，一起素食料理簡單做吧！​
​
?食材及佐料〔Ingredients〕：（3人份）​
▪素碎肉600克​
▪番茄 4顆​
▪素火腿1/2條​
▪九層塔1把​
▪辣椒3條​
▪檸檬1顆​
▪素蠔油2匙​
▪糖2茶匙​
▪薑末適量​
▪香油適量​
▪胡椒粉適量​
​
?烹飪步驟：​
1.素碎肉用水浸泡至軟，擠乾水分。素火腿、番茄切丁，檸檬擠出汁，備用。​
2.素碎肉、素蠔油、糖、胡椒粉、香油醃製約20分鐘，備用。​
3.將素碎肉、火腿油炸過，備用。​
4.熱鍋後，放入薑末、番茄炒軟，依序放入素碎肉、素火腿，加入素蠔油、糖、胡椒粉、辣椒調味。​
6.放入九層塔，淋上檸檬汁，擺盤即完成。​

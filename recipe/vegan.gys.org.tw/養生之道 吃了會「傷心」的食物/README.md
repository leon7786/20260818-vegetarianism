保護心臟，別讓它「傷心」
牛肉、羊肉、豬肉屬於紅肉，含有較多飽和脂肪酸的紅肉，會提升⬆️總膽固醇、壞的膽固醇、三酸甘油酯的濃度，使血液凝集障礙血流，讓心臟無法得到足夠的氧氣和養分，容易引起心臟疾病。
紅肉對人體的傷害不只心臟，還會提高罹患大腸癌、中風、糖尿病的風險。
另外培根、熱狗或香腸，在製作過程中會添加鹽或含鈉的食品添加物，這些加工肉品?也屬於「傷心」食物，較高重口味餐點含鈉量過高，也會讓人血壓上升增加中風和心血管疾病。

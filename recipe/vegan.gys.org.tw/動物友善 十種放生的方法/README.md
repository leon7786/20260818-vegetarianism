​
放生是即時能修的福，以下幾種放生方法可供參考：​
一、以佛法利益有情?​
二、自己吃素或勸人吃素?​
三、勸人放生或阻止他人殺生?​
四、流通戒殺護生的善書?​
五、放生未經鹽水泡過的魚子?​
六、救助誤入蜘蛛網或墮入坑洞的生命?​
七、碗盆等物口莫朝上放置，不生蚊蠅?​
八、不焚燒枯枝落葉和垃圾?​
九、滾燙水不潑灑在庭院​
十、不穿皮製品?​

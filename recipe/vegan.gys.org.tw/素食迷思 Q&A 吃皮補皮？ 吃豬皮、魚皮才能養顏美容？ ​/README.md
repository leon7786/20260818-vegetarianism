## 📖 食譜圖文詳情 (中英雙語對照)

素食迷思
Q&A｜吃皮補皮？ 吃豬皮、魚皮才能養顏美容？
​
坊間流傳吃阿膠(驢皮)、豬皮、魚皮…，可以有膠原蛋白最美膚，能讓氣色變好，肌膚更Q彈有光澤，事實卻不然！
​
許多營養師指出，這些動物皮膠原蛋白的分子過大，人體能吸收的有限，效果不大，且這類食物通常脂質含量高，膠原蛋白還沒有吃到，就先吃進一堆讓自己容易發胖的脂肪。
​
想要養顏美容，皮膚白裡透紅，吃皮補皮可以選擇吃糙米、麥皮(麩皮、麥麩)、果皮；糙米比精米更營養，與精米的差別就是多了一層乳白色的皮，這一層皮中含有很多好東西。
​
吃糙米能保養皮膚、調和脾胃，提供我們身體很多必需的營養，讓人的健康內而外的改變；而麥皮(麩皮、麥麩)也可以熬粥，果皮(蘋果皮、梨皮、葡萄皮)比果肉的營養價格高，都是可以吃的，含有人體需要的某種特殊的營養成分。
​
愛美是人的天性，人人都希望自己皮膚光滑、臉色紅潤，求助美容師、護膚產品等，其效果就像是在舊牆壁上塗上油漆，遠看好像又白又光滑，近看仍無法掩蓋原來粗糙表面。
​
許多人吃蔬食無關信仰，他們的訴求是蔬食有助於自己在工作中或社交場合，保持姣好的形體與完美的形象，再者，蔬食讓人頭腦清楚體力充沛，說不完的好處，只要改變飲食習慣，你也能輕鬆擁有好體態、吃出好氣色。

## 📖 食譜圖文詳情 (中英雙語對照)

苦瓜味苦、性寒，具有消暑清熱、解毒健胃的效果。​
炎炎夏日，正適合來盤退火的苦瓜料理，消暑又充滿維生素C。​
快跟著觀音山蔬食館主廚，一起素食料理簡單做吧!​
​
?食材及佐料〔Ingredients〕：（20人份）​
▪苦瓜 3斤​
▪蔭瓜(愛之味) 1罐​
▪福菜 適量(1把)​
▪薑末 適量​
▪香菇 數朵​
▪茶葉 少許​
▪話梅 5粒​
▪冰糖 適量​
▪醬油 少許​
​
?料理步驟：​
1.福菜洗淨，泡軟切段 ; 香菇泡軟，備用。​
2.苦瓜洗淨，將子和囊取出後，切5~7公分的大塊。​
3.瀝乾苦瓜，油炸至金黃色撈起。​
4.利用炸過苦瓜留下的油鍋來爆香福菜、香菇及薑末。​
5.將炸好的苦瓜放入鍋內，加入約150CC水(半淹食材) ，加入蔭瓜1瓶。​
6.放少許醬油（試鹹度），冰糖少許，幾粒茶葉，5粒左右的話梅。​
7.煮開後轉小火慢燉30分鐘，入味後起鍋，擺盤完成！​

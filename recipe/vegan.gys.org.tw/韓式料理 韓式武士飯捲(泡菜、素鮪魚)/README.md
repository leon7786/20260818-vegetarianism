​ ​
食材及佐料〔Ingredients〕：(5人份)
▪️熱白飯 ​ ​ ​ 約5碗
▪️小黃瓜 ​ ​ ​ ​ 2條
▪️茼蒿 ​ ​ ​ 100克
▪️韓式泡菜 ​ ​ ​ 適量
▪️素鮪魚 ​ ​ ​ ​ 100克
▪️素G塊 ​ ​ ​ ​ 6個
▪️壽司海苔 ​ ​ ​ ​ 5片
▪️白芝麻 ​ 美奶滋 粗黑胡椒粒 香油 ​ 適量
​
​
烹飪步驟：
【刀工/前處理】
1. 小黃瓜洗淨去籽，切長條狀(適合包壽司大小)。
2. 茼蒿洗淨，燙熟瀝乾水分備用。
3. G塊炸熟，一切成二等分，長條狀備用。
4. 素鮪魚加入適量的黑胡椒，拌勻備用。
​
【調理作法】
1. 準備壽司捲簾，包上保鮮膜，放上一張壽司海苔(光滑面朝下)，雙手沾少許水，取飯平均鋪上海苔(海苔上方預留一公分不要鋪白飯；海苔下方一公分要有白飯鋪出來)
2. 韓式泡菜口味 : 依序擺上小黃瓜、泡菜、3個切好的G塊。
3. 素鮪魚口味 : 依序擺上小黃瓜、素鮪魚、美奶滋、茼蒿。
4. 捲飯步驟 : 將捲簾由下往上捲至2/3處，確認食材都在捲簾內，雙手手指將料往內收緊，再將飯捲往前推。最後用捲簾再次塑形。
5. 將飯捲一切四等分，擺入容器中，刷上薄薄的香油，撒上白芝麻即可享用。

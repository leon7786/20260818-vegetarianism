## 📖 食譜圖文詳情 (中英雙語對照)

香蕉中的寡糖，是腸道益生菌的營養來源，能幫助調整腸道環境，豐富的維生素和膳食纖維，搭配有優質蛋白、益生菌的優酪乳，口感綿密香氣濃郁，斷食 養生一次成功，快跟著觀音山主廚，一起素食料理簡單做吧！​
​
◎食材及佐料〔Ingredients〕：(1人份)​
▪️香蕉 ​ 2條​
▪️水 ​ 150cc​
▪️優酪乳 ​ 350cc​
​
◎烹飪步驟：​
【刀工/前處理】​
1. 香蕉去皮備用。​
​
【調理作法】​
1.將食材放入果汁機中攪打均勻，即可享用！​
​
【特別說明】​
全素者可用植物奶或豆漿替代牛奶。​

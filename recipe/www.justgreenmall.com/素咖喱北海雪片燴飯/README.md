# 素咖喱北海雪片燴飯 (Vegan Curry Snow Peas Rice with Plant Fish Flakes)

![素咖喱北海雪片燴飯](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：素咖喱北海雪片燴飯
- **料理名称 (简体)**：素咖喱北海雪片烩饭
- **English Title**：Vegan Curry Snow Peas Rice with Plant Fish Flakes
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：異國料理 / 咖喱燴飯
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：15 分鐘
- **總計耗時 / Total Time**：20 分鐘
- **來源平台 / Source**：[植境 JustGreen Mall](https://www.justgreenmall.com/blog/posts/vegan-curry-snow-peas-rice-1)

## 🌿 食材清單 / Ingredients
- 素北海雪片 200克
- 工研咖喱 1塊
- 熱白米飯 1碗
- 四季豆/豆角 1條 (切丁)
- 紅辣椒 1條 (切丁)
- 老薑絲 15克
- 芝麻油 1湯匙
- 生抽 1茶匙
- 海鹽 1/2茶匙
- 糖 1/2茶匙
- 白胡椒粉 少許
- 清水 1碗

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 【備料】素北海雪片解凍切塊，豆角切小丁，紅辣椒切碎，生薑切細絲。
2. 【熱鍋爆香】熱鑊倒入芝麻油，加入薑絲與辣椒丁爆香。
3. 【煎炒主料】加入素北海雪片與豆角丁，翻炒2-3分鐘至微金黃。
4. 【調配咖喱】倒入1碗清水煮沸，加入工研咖喱塊與生抽、糖調味，小火攪拌至咖喱完全融化濃稠。
5. 【燴飯盛盤】將濃郁的咖喱雪片淋在熱騰騰的白米飯上即可享用。

## 💡 大廚美味秘訣 / Chef's Tips
- 素北海雪片植物蛋白富含纖維，類似白身魚肉口感，搭配工研咖喱濃醇香辣，非常開胃。

調味料:
- 鹽 1/4茶匙
- 白胡椒粉 少許
- 生粉水 1茶匙
烹調步驟:
1. 煮熟米飯: 🍚
首先,我們要煮好一碗香噴噴的白米飯。可以用電飯煲或煮鍋煮飯,煮好後備用。米飯最好選用優質的長粒米,這樣煮出來的飯粒會更加鬆軟香糯。
2. 炒香材料: 🔥
熱鍋下油,待油溫升高後加入薑絲、豆角和辣椒丁。用中火快炒至薑香四溢,豆角和辣椒變得翠綠鮮嫩。這一步可以激發食材的香味,為整道菜奠定良好的風味基礎。
3. 加入素北海雪片: 🌊
將素北海雪片倒入鍋中,和其他食材一起翻炒。素北海雪片口感細膩,吸收其他食材的風味後會更加美味。炒至素北海雪片表面微微金黃,散發出誘人的香氣。
4. 加入水和咖喱: 🍛
這時候可以加入適量的水,然後放入工研咖喱塊。隨著咖喱塊慢慢融化,整個鍋裡會瀰漫著濃郁的咖喱香氣。同時加入鹽和白胡椒粉調味,然後轉小火慢燉約5分鐘,讓咖喱的味道充分滲透到每一個食材中。
5. 收汁: 💦
當咖喱sauce煮得差不多時,可以加入事先調好的生粉水。邊攪拌邊倒入,讓咖喱sauce慢慢變得濃稠。這樣不僅可以讓口感更加濃郁,還能讓咖喱sauce更好地包裹住每一粒米飯。
6. 最後調味: 🌟
關火前,滴入少許芝麻油提香。芝麻油的香氣會為整道菜增添一絲溫潤的口感,讓味道更加圓潤豐富。
7. 擺盤: 🍽️
將煮好的白米飯盛入碗中,再將香濃的咖喱素北海雪片燴飯淋在上面。可以撒上一些蔥花或香菜點綴,不僅美觀還能增添一絲清新的口感。
小貼士: 💡
1. 咖喱的辛香度可以根據個人口味調整。喜歡重口味的朋友可以適當增加咖喱的用量,反之則可以減少。🌶️
2. 為了增加營養和口感的層次,可以加入其他時令蔬菜,如玉米粒、青豆或西蘭花等。這不僅可以增加菜品的顏色,還能豐富整道菜的營養價值。🥦🌽
3. 如果喜歡更濃郁的奶香味,可以在最後加入一些椰奶或淡奶油,這樣會讓咖喱sauce更加順滑濃郁。🥥
4. 素北海雪片在烹飪時要注意火候,過度烹煮可能會影響口感。建議在加入咖喱sauce之前,先將素北海雪片稍微煎至表面金黃,這樣可以鎖住水分,保持口感的嫩滑。👨‍🍳
5. 剩餘的咖喱sauce可以冷藏保存,之後可以用來拌麵或是做成咖喱飯團,都是不錯的選擇。🍙

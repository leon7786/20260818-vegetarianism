## 🌿 食材及佐料清單 / Ingredients
- 一个白萝卜
- 两根胡萝卜
- 两个鸡蛋
- 姜末
- 盐
- 胡椒粉
- 花椒粉
- 面粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 将萝卜洗净去皮，擦成丝
2. 在盆内加入鸡蛋、盐、姜末、胡椒粉、花椒粉调味
3. 调味完成后加入面粉，注意稠度：太稀不易成型；太粘稠又会吃不出萝卜的味道
4. 将油烧热（丢一点面团马上可以浮起为标准）,用虎口和勺子配合挤丸子下锅
5. 用小火慢慢炸，炸到丸子熟透、色泽金黄的时候就可以出锅了。就这样就可以吃，你也可以配上自己喜欢的蘸料。甜、咸、酸、辣凭您的喜好选择

## 💡 大廚美味秘訣 / Chef's Tips
- 关于这道菜谱，有不少童鞋提出白萝卜胡萝卜相克什么的。后来经过多方了解，很多传统菜都有这样的搭配，并不是什么禁忌，请大家放心食用吧。冬天的时候准备一些放在冰箱，应季有方便。汆丸子，炒丸子，做砂锅菜什么的都很方便。

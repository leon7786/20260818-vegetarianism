## 🌿 食材及佐料清單 / Ingredients
- 一个白萝卜
- 两根胡萝卜
- 两个鸡蛋
- 姜末
- 盐
- 胡椒粉
- 花椒粉
- 面粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 将萝卜洗净去皮，擦成丝
2. 在盆内加入鸡蛋、盐、姜末、胡椒粉、花椒粉调味
3. 调味完成后加入面粉，注意稠度：太稀不易成型；太粘稠又会吃不出萝卜的味道
4. 将油烧热（丢一点面团马上可以浮起为标准）,用虎口和勺子配合挤丸子下锅
5. 用小火慢慢炸，炸到丸子熟透、色泽金黄的时候就可以出锅了。就这样就可以吃，你也可以配上自己喜欢的蘸料。甜、咸、酸、辣凭您的喜好选择

## 💡 大廚美味秘訣 / Chef's Tips
- 总结：1.有些人的做法会将萝卜先放盐挤掉水分，这里没有这么做希望尽量保持萝卜中的营养成分。而且也不影响口感。 
2.炸的时候一定要用小火并不断翻动丸子，这样才会受热均匀而且色泽也好看。 
3.一次如果没有炸透的话可以先盛出来晾凉之后在回炸一次。

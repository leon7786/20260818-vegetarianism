## 🌿 食材及佐料清單 / Ingredients
- 红柿子椒
- 米饭
- 西红柿
- 胡萝卜
- 盐
- 生抽

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 番茄沙司 盐 生抽（这些统统放在一起调成汁，如果太稠，可少加点水）
2. 胡萝卜，柿子椒，西红柿都切成丁
3. 锅内烧少许的油，下入西红柿丁炒化
4. 下入胡萝卜丁，柿子椒丁翻炒
5. 倒入调料汁和米饭炒均匀即可

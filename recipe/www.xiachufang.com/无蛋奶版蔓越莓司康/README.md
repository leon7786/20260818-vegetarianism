# 无蛋奶版蔓越莓司康

## 🌿 食材及佐料清單 / Ingredients
- 100g低筋面粉
- 20g细砂糖
- 1/4小匙盐
- 1/2小匙泡打粉
- 20g玉米油
- 40g水
- 10g蔓越莓干

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 将粉质的低粉、砂糖、盐、泡打粉用面粉筛筛入容器中拌匀
2. 将油与粉质材料混合，用手搓成粗粉状
3. 加水到粗粉混合物中和匀，再加蔓越莓干
4. 揉成面团
5. 将面团擀成2厘米厚的饼，用圆饼干模压形，继续将剩余的面继续重复此动作直到面团用完
6. 将圆形面胚放在烤盘中，上表面抹上稀糖浆（用1糖3水一起小火慢煮到颜色深黄即可）
7. 入预热好的烤箱，200度烤中层上下火烤20分钟即可

## 💡 大廚美味秘訣 / Chef's Tips
- 1.1小匙=5ml 
2.烘焙用玉米油或葵花籽油等无味油

## 🌿 食材及佐料清單 / Ingredients
- 血糯米
- 红枣
- 红糖

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 血糯米和红枣放入锅中，加足量水，大火烧开后转小火煮半个小时2.关火前加入红糖拌匀， 懒的童鞋也可以直接用电饭锅~

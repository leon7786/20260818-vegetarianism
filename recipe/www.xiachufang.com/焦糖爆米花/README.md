# 焦糖爆米花

## 🌿 食材及佐料清單 / Ingredients
- 60g小玉米
- 60g糖
- 40g水
- 20g黄油

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 炒锅预热下，倒入一点植物油，放入一把小玉米晃匀，中小火加热
2. 等看到有玉米粒爆开的时候，关小火，盖上盖子，不时的晃动锅子
3. 差不多全爆开的时候，出锅备用
4. 把糖和水放入锅中，中小火加热
5. 熬糖水的时候，不要搅动，等看到糖水颜色变成焦糖色后，放入黄油
6. 这时就可以搅动了，黄油融化后与焦糖搅匀
7. 放入爆米花，快速翻匀，放入铺了油布的烤盘上晾凉

## 💡 大廚美味秘訣 / Chef's Tips
- 做法非常简单哦，还是时下很流行的奶油焦糖口味的，保证好吃。

## 🌿 食材及佐料清單 / Ingredients
- 新鲜菠萝
- 一小把新鲜薄荷叶
- 2大匙砂糖

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 去好皮的菠萝切片，去掉硬心，放淡盐水中泡一会
2. 薄荷去掉梗留下叶，洗净，控干水分~一定要控干水！然后剁碎与2大匙砂糖一起捣一捣，糖就绿了，撒泡好的菠萝上，开吃

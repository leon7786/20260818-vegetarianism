# 藕丁炒青椒

## 🌿 食材及佐料清單 / Ingredients
- 莲藕
- 青椒
- 油
- 盐
- 酱油

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 新鲜的莲藕去皮切丁，用清水冲洗几遍，洗去表面的淀粉
2. 青椒切成小块
3. 锅热入油，放入藕丁翻炒1分钟，加一点酱油，翻炒均匀
4. 最后放入青椒，炒出香味后加适量盐即可起锅

## 💡 大廚美味秘訣 / Chef's Tips
- 夏末秋初，正是莲藕新鲜脆嫩之时，炒着吃格外地清香。加一点酱油提味，还很下饭，中午带便当吃不错。

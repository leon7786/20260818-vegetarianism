## 🌿 食材及佐料清單 / Ingredients
- 300G白萝卜
- 100g粘米粉
- 五朵干香菇
- 一勺盐
- 半勺白胡椒粉
- 两勺生抽
- 100g水

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 白萝卜300g去皮擦丝，挤掉过多的水分
2. 干香菇提前用温水泡发，泡好后切丝
3. 粘米粉100g加同比例凉水调成稠糊
4. 锅烧热下少许油，下香菇炒香，再下白萝卜翻炒一会
5. 加盐，白胡椒粉，生抽调味
6. 关火，倒入粘米粉糊拌匀，然后倒入涂底油的耐高温容器中压实
7. 上蒸锅，中火40分钟左右
8. 取出待完全冷却后切厚片，可直接吃，也可小火煎下再吃~

## 💡 大廚美味秘訣 / Chef's Tips
- 素萝卜糕的小贴士
 白萝卜和粘米粉的比例3:1 粘米粉和水的比例是1：1 
用水发香菇更有风味 
倒入混合物前，容器中涂植物油这样蒸好可以轻易扣出~ 
另外~粘米粉就是俗称的大米面

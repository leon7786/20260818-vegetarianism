# 快手冰镇泡菜

- **料理名稱**：快手冰镇泡菜
- **原始標題**：快手冰镇泡菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：爽口凉菜
- **來源平台 / Source**：[下廚房 · 素食主義專區](https://www.xiachufang.com/recipe/1002018/)

## 🌿 食材及佐料清單 / Ingredients
- 一把樱桃萝卜
- 一根黄瓜
- 三片叶卷心菜
- 一个红彩椒
- 100ml白醋
- 30g白糖
- 一勺5ml盐
- 两片香叶
- 十粒花椒

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 蔬菜洗净，樱桃萝卜和黄瓜切片，卷心菜撕小块，红椒切块
2. 加入100ml白醋，30g白糖，一勺盐,两片香叶，几粒花椒
3. 用手压一压泡菜，如果液体没有没过泡菜继续加凉白开水没过
4. 密封好放入冰箱冷藏3个小时以上就可以吃了

## 💡 大廚美味秘訣 / Chef's Tips
- 1.我做的分量大约连水带菜是一升 
2.可以冷藏一个星期，随吃随取 
3.喜欢吃辣可以放两个朝天椒进去 
4.其他例如胡萝卜，心里美萝卜，都可以泡

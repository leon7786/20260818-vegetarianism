# 芦笋炒蘑菇

- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 经典热菜
- **來源平台 / Source**：[下廚房 · 素食主義專區](https://www.xiachufang.com/recipe/15379/)

## 🌿 食材及佐料清單 / Ingredients
- 芦笋
- 口蘑
- 生抽
- 盐

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 芦笋去掉老根切成段，口蘑切成片用开水焯过沥干
2. 先用油炒蘑菇片，加一点生抽，等蘑菇变色后放入芦笋一起翻炒，最后加盐出锅

## 💡 大廚美味秘訣 / Chef's Tips
- 需要注意的是蘑菇非常容易吸入咸味，所以生抽和盐都要少放，否则炒出来蘑菇会很咸。

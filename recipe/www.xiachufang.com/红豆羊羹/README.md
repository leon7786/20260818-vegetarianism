## 🌿 食材及佐料清單 / Ingredients
- 120g红豆沙
- 3g琼脂
- 130g水

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 琼脂3g放入凉水中泡几分钟以去除杂质
2. 捞出琼脂与130G水放入锅中加热搅拌至融化
3. 豆沙倒入锅中一起搅拌加热
4. 混合物倒入容器待凉至常温后移至冰箱冷藏一个小时即可

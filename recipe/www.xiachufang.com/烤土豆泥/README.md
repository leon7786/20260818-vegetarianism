## 🌿 食材及佐料清單 / Ingredients
- 大号一个土豆
- 1大匙橄榄油
- 1/2小匙海盐
- 少许黑胡椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 土豆洗净，去皮切块放入锅中蒸或煮熟
2. 土豆块加入橄榄油，盐，黑胡椒捣成泥
3. 土豆泥装入可烤箱用的容器中，用叉子捣松（保留空隙增加表面积)
4. 放入烤箱250度，上层 10分钟即可

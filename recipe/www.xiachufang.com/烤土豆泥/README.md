## 🌿 食材及佐料清單 / Ingredients
- 大号一个土豆
- 1大匙橄榄油
- 1/2小匙海盐
- 少许黑胡椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 土豆洗净，去皮切块放入锅中蒸或煮熟
2. 土豆块加入橄榄油，盐，黑胡椒捣成泥
3. 土豆泥装入可烤箱用的容器中，用叉子捣松（保留空隙增加表面积)
4. 放入烤箱250度，上层 10分钟即可

## 💡 大廚美味秘訣 / Chef's Tips
- 一定要用叉子捣的松松的~这样烤出来的表面是焦焦的，很香 
还有就是橄榄油一定稍微多放一点，这样才不会太干。 
 
另外，对很多关于橄榄油耐高温与否的各种说法进行总结 
1.橄榄油完全可以高温烹饪，因为高温后也不会产生对人体有害的物质。橄榄油比其它植物油具有更好的高温稳定性，烟点也很高。可反复使用十数次而不会产生化学物质分解，而一般植物油最多使用三次以上就会产生化学成分的变化。 
2.橄榄油高温后，一部分不饱和脂肪容易氧化转化成饱和脂肪酸。 
 
总结一下，橄榄油适合高温烹饪，因为耐高温不会产生有害物质，但是高温会破坏一些营养成分。

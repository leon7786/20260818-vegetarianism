## 🌿 食材及佐料清單 / Ingredients
- 半个柠檬
- 一听苏打水
- 少许薄荷叶

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 柠檬半个榨汁，加入苏打水和捣过的薄荷叶即可
2. 个人喜欢喝不加糖的，也可以根据个人口味加糖~

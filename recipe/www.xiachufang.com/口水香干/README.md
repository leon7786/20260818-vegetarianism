## 🌿 食材及佐料清單 / Ingredients
- 1大匙熟花生碎
- 少许香芹碎
- 2块香干
- 2小匙辣椒粉
- 1小匙花椒粉
- 1小匙糖
- 2大匙生抽
- 2小匙陈醋
- 3大匙白开水或素高汤
- 1小匙白芝麻

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 这种立方体的卤制香干，市场都有卖，洗净切片，摆在盘中
2. 制辣油，取无水的碗一只，加2小匙辣椒粉，1小匙花椒粉、1小匙白芝麻，干净锅里烧适量油，烧热后泼在小碗里，用勺子快速搅拌匀成辣椒油
3. 再加入1小匙糖、2大匙生抽、2小匙陈醋及3大匙开水或素高汤拌匀成为浇汁，浇在香干上，撒熟花生碎和少许香芹碎即可

## 💡 大廚美味秘訣 / Chef's Tips
- 1.我喜欢用黄飞红花生做花生碎，麻麻辣辣很香 
2.可以提前备好这道菜，让汁充分浸泡香干，入味更足~

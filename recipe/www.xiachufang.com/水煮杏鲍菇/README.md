# 水煮杏鲍菇

- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 经典热菜

## 🌿 食材及佐料清單 / Ingredients
- 两个杏鲍菇
- 几根香芹
- 一把黄豆芽
- 2大匙郫县豆瓣酱
- 几个干辣椒
- 1大匙花椒
- 1个八角
- 两三片生姜
- 1/2小匙糖

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 蔬菜洗净 
调料准备好以防手忙脚乱
2. 香芹切段，杏鲍菇去掉老根，先切两段，然后对半切块，接着尽量切薄片~
3. 锅烧热下油，入生姜、八角、花椒、干辣椒小火煸香，接着下入郫县豆瓣酱炒香，然后倒入估计能没过菜2/3的水，烧开，下糖，下豆芽煮三四分钟，然后下入芹菜段和杏鲍菇片搅拌，煮个一二分钟~杏鲍菇片变软（杏鲍菇很容易熟）即可关火
4. 装盘，这样就可以吃了，少油更健康，如果你想让水煮的气氛更足一点，再在菜上撒点粗辣椒粉和花椒粉另起锅烧热一点油浇在上面即可。点缀点香芹叶

## 💡 大廚美味秘訣 / Chef's Tips
- 郫县豆瓣已经够咸了，所以无需格外加盐 
花椒辣椒的量根据个人口味调整 
1大匙=15ML 
1小匙=5ML

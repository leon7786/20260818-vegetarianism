# 南瓜银耳露

## 🌿 食材及佐料清單 / Ingredients
- 一朵小银耳
- 大约150g（差不多是2杯半）南瓜
- 约1100ml水

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 银耳洗净，加水泡发，去除底部黄色的部分，撕小朵放入豆浆机
2. 南瓜去籽，切黄豆大的小块，放入豆浆机
3. 倒入水，接通电源，选择五谷或者米糊功能
4. 15分钟后，银耳露就做好了，可以趁热倒入冰糖，也可以放凉后加蜂蜜等调味

## 💡 大廚美味秘訣 / Chef's Tips
- 南瓜银耳露的小贴士
 1、出来南瓜，紫薯和红薯做银耳露都不错哦。 
2、如果买的南瓜很甜，其实不加糖也很好喝。 
3、总觉得冰糖放入豆浆机太硬，一般都是做好后加，很快就融化了。 
4、银耳要买上乘的，没有被硫磺熏过的才好。

## 🌿 食材及佐料清單 / Ingredients
- 1人份鲜面条
- 1大匙碎米芽菜
- 2大匙油炸花生（或烤的炒的）
- 2小匙香油
- 1大匙香芹碎（可略）
- 1大匙生抽
- 1小匙醋
- 2小匙辣椒油
- 1小匙花椒粉
- 1/2小匙糖

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鲜面条放入锅中煮熟，捞出控干水分与1大匙香油拌匀防止粘在一起
2. 今天家里没碎米芽菜了，用了同是芥菜腌制成的四川酸菜切碎替代。花生（黄飞红）用石臼捣碎
3. 用香油拌过的面条，加入酸菜碎、花生碎、生抽、辣椒油、醋、花椒粉和糖拌匀即可
4. 自己又烫了几棵菠菜配在旁边

## 💡 大廚美味秘訣 / Chef's Tips
- 1.碎米芽菜是四川的一种小菜，用芥菜剁碎加盐和红糖及香料腌渍而成，在四川的大小超市都有一小袋 一小袋的出售~。估计其他地方不是特别好买，其实用四川酸菜也可替代，都是芥菜做的~。一般市场 都有卖四川酸菜的，如果实在没有，用点袋装的小咸菜替代吧~ 
 2.花生碎只要用油炸的花生米都可以，如果没有石臼可以放在保鲜袋中用擀面杖压碎。 
 3.如果嫌麻烦，香芹碎也可省略，不会影响风味。

## 🌿 食材及佐料清單 / Ingredients
- 一人份乌冬面
- 几朵香菇
- 半根胡萝卜
- 一块香干
- 一个西红柿
- 两颗小油菜
- 2小匙咖喱粉
- 1/2小匙盐
- 1/2小匙糖

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 备料：所有蔬菜洗净，香菇去蒂切片，胡萝卜切片，香干切片，西红柿切块待用
2. 锅烧热下少许油，下咖喱粉小火略微炒出香味即可（炒过了会苦），然后下西红柿炒化
3. 加两碗水到锅中煮开，下胡萝卜、香菇、香干、乌冬面同煮五分钟左右
4. 下入容易熟的油菜，加盐和糖调味同煮片刻即可
5. 不是严格素食的童鞋，可以忽略前面的咖喱粉，在最后快出锅前放入一两块咖喱块煮化即可，这样比较好掌握~

## 💡 大廚美味秘訣 / Chef's Tips
- 1.我在做咖喱的时候喜欢加一个西红柿进去炒化，这样汤汁更浓稠还带有微微酸味，风味绝佳~ 
2.咖喱粉每个品牌的配料都不一样，所以有忌口的童鞋一定要多看一眼~

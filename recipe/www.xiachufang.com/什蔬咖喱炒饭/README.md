## 🌿 食材及佐料清單 / Ingredients
- 米饭
- 西兰花
- 胡萝卜
- 玉米
- 青豆
- 圣女果
- （或普通咖喱粉，咖喱块）自制咖喱粉
- 盐

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西兰花与胡萝卜丁，青豆玉米粒一起用水焯过待用。圣女果从中间切开
2. 锅里倒油烧热，加咖喱粉小火炒香，然后加入圣女果翻炒
3. 锅中加入米饭炒匀，最后加焯熟的西兰花，胡萝卜丁，青豆玉米炒匀，加盐调味即可

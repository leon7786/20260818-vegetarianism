## 🌿 食材及佐料清單 / Ingredients
- 一两薏米
- 一根铁棍山药
- 适量白玉菇
- 1小匙生抽
- 1/2小匙盐

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 薏米提前浸泡几小时，山药不去皮，彻底洗净并用盐水浸泡干净切成段
2. 将薏米、山药放入锅中，加足量水没过，开火烧开然后转小火盖上盖子煮20分钟左右
3. 再下白玉菇、生抽盐继续煮5-10分钟即可
4. 素汤的味道一样惊艳，怎一个清鲜了得

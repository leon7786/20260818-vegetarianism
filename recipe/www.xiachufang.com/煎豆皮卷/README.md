## 🌿 食材及佐料清單 / Ingredients
- 麻辣粉
- 豆皮
- 甜面酱
- 糖
- 孜然粉
- 芝麻
- 辣椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 豆皮洗净后卷成密实一些的卷
2. 切片，用竹签串起来
3. 平底锅烧热后倒入一些油，放入豆皮卷
4. 煎至两面金黄。（也可以把油刷在豆皮卷上再煎）
5. 甜面酱+麻辣粉（可省）+糖拌匀，尝一下味道，感觉合适就行
6. 把调好的酱刷到豆皮卷上
7. 撒一些孜然粉，辣椒粉和芝麻

## 💡 大廚美味秘訣 / Chef's Tips
- 今天看到家里有豆皮，突然很想吃烤豆皮了。 
因为只有一张，串不了几串，不值得开烤箱，就煎来吃了。 
两面煎的金黄酥脆，内心却还是软软的，抹上酱料，撒点芝麻和孜然，别提多香了。 
不知道你有没有试过这种吃法，真的很好吃哦~ 
虽然卷好的样子很像素鸡，但是这个豆皮卷煎起来比素鸡好吃，因为素鸡的质地很实，没有豆皮酥脆。

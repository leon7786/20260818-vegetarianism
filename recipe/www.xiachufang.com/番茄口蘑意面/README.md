# 番茄口蘑意面

## 🌿 食材及佐料清單 / Ingredients
- 3个西红柿
- 300g口蘑
- 少许香芹
- 6大匙番茄酱
- 1/2小匙黑胡椒粉
- 3大匙橄榄油
- 1小匙盐
- 3人份意大利面

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 原料洗净待用
2. 西红柿顶端划十字，底端去蒂。放入开水锅中烫一分钟，取出剥掉外皮切成丁待用。口蘑切片待用
3. 烧开一锅水，下入意面和少许盐中火煮15分钟左右。另起锅烧热下橄榄油，下番茄丁炒软，接着下番茄酱、口蘑、盐、黑胡椒粉同炒，小火炒至酱汁浓稠，西红柿化掉即可。捞出意大利面控干水，下入酱锅中炒匀撒香芹碎即可
4. 1.通常我先煮上意面，然后利用煮面的时间烫一下西红柿 
2.意面的软硬程度根据口味调整 
3.煮意面原则是多水多盐，放入1小匙盐这样煮的过程中意面会入味

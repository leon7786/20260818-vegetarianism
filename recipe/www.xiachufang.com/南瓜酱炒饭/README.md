## 🌿 食材及佐料清單 / Ingredients
- 米饭
- 南瓜
- 青豆
- 玉米粒
- 香菇
- 盐
- 黑胡椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 南瓜洗净，去皮去瓢切成1厘米左右的丁待用
2. 香菇去蒂切丁，速冻的青豆玉米粒解冻
3. 锅烧热下少许油，下南瓜丁炒匀加水没过南瓜，小火煮至水收了一半
4. 用勺子压碎一半的南瓜，加入青豆玉米香菇同炒，加盐黑胡椒粉调味
5. 加入米饭一起炒匀即可出锅

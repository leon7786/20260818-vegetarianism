# 香煎藕饼

## 🌿 食材及佐料清單 / Ingredients
- 一节莲藕
- 各少许红椒青椒
- 三朵香菇
- 4大匙（60ml)面粉
- 1小匙盐
- 少许白胡椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 莲藕去皮，剁碎，或用擦丝器擦碎，香菇洗净去蒂切碎，青红椒切碎
2. 将莲藕碎用手挤一下，挤掉一部分水分，不要挤太干。香菇碎放锅中加油炒香待用
3. 将莲藕碎与香菇碎、青红椒碎、面粉、盐、白胡椒粉拌匀
4. 用手将混合物拍成小饼，放平底锅加少许油中小火煎至两面金黄即可

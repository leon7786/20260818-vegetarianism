## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 锅中烧一锅水，加两个干辣椒，几粒花椒，两勺生抽一勺盐煮开
2. 先下入不易熟的根茎类蔬菜，如土豆萝卜等等还有红薯粉煮8分钟左右 （为了节省烫的时间，最好都切成薄片）
3. 再下入易熟的叶子菜还有豆皮煮两分钟
4. 捞出烫好的菜放入碗中，芝麻酱加锅里烫菜的水搅拌调成糊，再加适量盐拌匀 浇在菜上，喜欢吃辣的可以再加点辣椒油

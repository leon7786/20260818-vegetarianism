- **原始標題**：爽口蓑衣黄瓜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 经典热菜

## 🌿 食材及佐料清單 / Ingredients
- 黄瓜
- 盐
- 糖
- 生抽
- 陈醋

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 挑选比较直的黄瓜，放在菜板上侧面垫根筷子，刀垂直于菜板，与黄瓜成45度角切片， 因为有筷子垫着所以不会切断，一面切完了把黄瓜翻过来同样方法切另一面
2. 加上盐，糖，生抽，和陈醋待十分钟入味即可

## 💡 大廚美味秘訣 / Chef's Tips
- 蓑衣刀的切法，不仅是好看，交织层叠的黄瓜吃起来更脆，口感更丰富。

## 🌿 食材及佐料清單 / Ingredients
- 土豆
- 黄瓜
- 西红柿
- 素食者可不加，替换成胡萝卜片之类的蔬菜即可香肠

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 土豆用沸水过后，剥去外皮，碾碎
2. 趁热放入洋葱，再加入黄瓜片、西红柿丁和香肠丁
3. 要土豆冷却后，加入沙拉酱

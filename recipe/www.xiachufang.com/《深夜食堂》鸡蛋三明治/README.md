## 🌿 食材及佐料清單 / Ingredients
- 切片吐司
- 鸡蛋
- 沙拉酱
- 盐
- 胡椒

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 煮熟的鸡蛋切碎，再放点沙拉酱
2. 只是因为要混合在一起，一定要搅拌均匀
3. 最后在放点盐和胡椒，和在一起
4. 夹在两层面包中间，切掉硬边，分成三角形

# 草莓油醋沙拉 (Fresh Strawberry Vinaigrette Salad)

## 🌿 食材清單 / Ingredients
- 綜合生菜 100 g
- 草莓 4顆
- 小番茄 4顆
- 小黃瓜 半條
- 紅蘿蔔 1/3根
- 康寶草莓果醬 2大匙
- 巴薩米克醋 1大匙
- 特級初榨橄欖油 2大匙
- 檸檬汁 1小匙
- 黑胡椒 少許
- 鹽 少許

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 綜合生菜、草莓、小番茄、紅蘿蔔與小黃瓜洗淨瀝乾。
2. 草莓、小番茄對半切，紅蘿蔔、小黃瓜切丁後，與綜合生菜放入沙拉碗。
3. 康寶草莓果醬、巴薩米克醋、橄欖油、檸檬汁、黑胡椒與鹽混合攪拌均勻，調製成草莓油醋醬。
4. 將草莓油醋醬均勻淋在沙拉上，上方再綴以草莓果醬與新鮮草莓，即可享用。

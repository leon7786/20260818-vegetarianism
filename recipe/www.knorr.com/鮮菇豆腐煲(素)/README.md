# 鮮菇豆腐煲(素) (Fresh Mushroom Tofu Claypot)

![鮮菇豆腐煲(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：鮮菇豆腐煲(素)
- **料理名称 (简体)**：鲜菇豆腐煲(素)
- **English Title**：Fresh Mushroom Tofu Claypot
- **素食流派 / Diet**：奶素 Lacto-Vegetarian
- **料理分類 / Category**：煲仔 / 熱炒
- **份量 / Servings**：4 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：15 分鐘
- **總計耗時 / Total Time**：20 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%AE%AE%E8%8F%87%E8%B1%86%E8%85%90%E7%85%B2(%E7%B4%A0).html/176042)

## 🌿 食材清單 / Ingredients
- 蛋豆腐 2盒（600g）
- 鴻喜菇 50公克
- 雪白菇 50公克
- 鮮香菇 80公克
- 花椰菜 60公克
- 紅蘿蔔 30公克
- 薑末 5公克
- 水 400㏄
- 康寶鮮味炒手(奶素) 2匙
- 白胡椒粉 1/4茶匙
- 太白粉水 2大匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鴻喜菇、雪白菇洗淨剝散，花椰菜切小朵，紅蘿蔔切小片。
2. 蛋豆腐切厚片，鮮香菇洗淨去蒂頭。
3. 熱鍋倒入3大匙油，放入蛋豆腐煎至兩面金黃後，取出備用。
4. 再熱鍋倒入1大匙油，加入薑末炒香，放入做法1的材料及水、鮮味炒手(奶素)、白胡椒粉，煮滾後放入蛋豆腐及鮮香菇同煮。
5. 以小火煮約1分鐘後，用太白粉水勾薄芡即可。

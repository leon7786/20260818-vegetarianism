# 鮮菇豆腐煲(素) (Fresh Mushroom Tofu Claypot)

![鮮菇豆腐煲(素)](cover.jpg)

- **料理名稱 (繁體)**：鮮菇豆腐煲(素)
- **料理名称 (简体)**：鲜菇豆腐煲(素)
- **English Title**：Fresh Mushroom Tofu Claypot
- **素食流派 / Diet**：蛋奶素 Lacto-Ovo Vegetarian（含蛋豆腐、奶素調味料）
- **料理分類 / Category**：豆腐料理 / 煲仔類 / 家常熱炒
- **份量 / Servings**：4 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：15 分鐘
- **總計耗時 / Total Time**：20 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%AE%AE%E8%8F%87%E8%B1%86%E8%85%90%E7%85%B2(%E7%B4%A0).html/176042)

## 🌿 食材清單 / Ingredients
- 蛋豆腐 2盒（約600公克）
- 鴻喜菇 50公克
- 雪白菇 50公克
- 鮮香菇 80公克
- 花椰菜 60公克
- 紅蘿蔔 30公克
- 薑末 5公克
- 清水 400㏄
- 康寶鮮味炒手(奶素) 2匙
- 白胡椒粉 1/4茶匙
- 太白粉水 2大匙（太白粉與水以1:2比例調勻）
- 食用油 4大匙（煎豆腐用3大匙 + 爆香煮煲用1大匙）

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. **食材備料**：鴻喜菇、雪白菇洗淨後用手剝散成小株；花椰菜切成適口小朵；紅蘿蔔去皮切薄小片。
2. **切配豆腐與香菇**：蛋豆腐小心切成厚片（約1.5~2公分厚，避免翻炒時碎裂）；鮮香菇洗淨去蒂頭，表面可劃十字花刀方便入味。
3. **香煎豆腐（定型金黃）**：熱鍋倒入3大匙食用油，油溫升至中溫（約160°C）後放入蛋豆腐片，以中火慢煎至底部金黃定型後輕輕翻面，煎至雙面呈金黃酥香狀，撈出瀝油備用。
4. **爆香起煲與煨煮**：原鍋（或砂鍋）倒入1大匙食用油，下薑末以中小火爆炒出香氣；加入鴻喜菇、雪白菇、花椰菜、紅蘿蔔片翻炒均勻，隨後倒入400㏄水、加入2匙康寶鮮味炒手(奶素)及1/4茶匙白胡椒粉，大火煮滾後輕輕放入煎好的蛋豆腐厚片與鮮香菇同煮。
5. **小火入味與薄芡**：轉小火微沸燴煮約1分鐘讓豆腐與蔬菜吸附高湯精華，最後均勻淋入2大匙太白粉水以鍋鏟背面輕推勾薄芡，湯汁濃稠透亮即可起鍋（或移入預熱砂鍋）熱騰騰上桌。

## 💡 料理小貼士 / Chef's Tips
- **豆腐煎製防碎訣竅**：蛋豆腐質地極為細嫩，煎製時務必熱鍋熱油且切勿急於翻動，待底面煎至結成金黃焦皮後再翻面；煨煮時以晃動鍋身或鍋鏟輕推為主，可保持豆腐形狀完整美觀。
- **雙菇搭配鮮味加倍**：鴻喜菇與雪白菇口感脆嫩鮮甜，搭配鮮香菇的濃郁香氣，經薑末爆香與康寶鮮味炒手提鮮，能釋放豐富的天然谷氨酸鮮味，湯鮮味美。
- **砂鍋保溫效果更佳**：若家中有砂鍋，可在起鍋前先將砂鍋空燒預熱，出鍋倒入砂鍋能鎖住高溫，端上桌滋滋作響、香氣撲鼻。

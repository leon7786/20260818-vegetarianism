# 菇菇素米糕 (Savory Mushroom Vegetarian Sticky Rice Cake)

![菇菇素米糕](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：菇菇素米糕
- **料理名称 (简体)**：菇菇素米糕
- **English Title**：Savory Mushroom Vegetarian Sticky Rice Cake
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：米食 / 點心
- **份量 / Servings**：8 人份
- **準備時間 / Prep Time**：10 分鐘
- **烹飪時間 / Cook Time**：25 分鐘
- **總計耗時 / Total Time**：35 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E8%8F%87%E8%8F%87%E7%B4%A0%E7%B1%B3%E7%B3%95.html/255111)

## 🌿 食材清單 / Ingredients
- 長糯米2杯
- 水2杯
- 薑末10克
- 泡發香菇丁30克
- 杏鮑菇丁100克
- 枸杞20克
- 胡麻油2大匙
- 全素鮮味炒手3茶匙
- 白胡椒粉1茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 長糯米洗淨後，用2杯水浸泡約2小時備用。
2. 熱鍋下麻油爆香薑末。下香菇、杏鮑菇入鍋炒香。將浸泡的長糯米及水、枸杞入鍋炒勻，加入全素鮮味炒手、胡椒粉充分炒勻後，取出放入電鍋內鍋。
3. 放入電鍋，外鍋加1杯水，蒸至跳起後拌勻即可。

# 炸海苔腐皮卷 (全素) (Crispy Nori Bean Curd Skin Rolls (Vegan))

![炸海苔腐皮卷 (全素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：炸海苔腐皮卷 (全素)
- **料理名称 (简体)**：炸海苔腐皮卷(全素)
- **English Title**：Crispy Nori Bean Curd Skin Rolls (Vegan)
- **素食流派 / Diet**：純素 Vegan
- **料理分類 / Category**：炸物 / 點心
- **份量 / Servings**：5 人份
- **準備時間 / Prep Time**：10 分鐘
- **烹飪時間 / Cook Time**：13 分鐘
- **總計耗時 / Total Time**：23 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E7%82%B8%E6%B5%B7%E8%8B%94%E8%85%90%E7%9A%AE%E5%8D%B7-(%E5%85%A8%E7%B4%A0).html/179568)

## 🌿 食材清單 / Ingredients
- 豆皮 5 塊
- 紅甜椒 1/4 顆
- 玉米筍 2 條
- 四季豆 6 條
- 海苔 5 張
- 油 少許
- 水 4茶匙
- 康寶鮮味炒手(奶素) 2又1/4匙
- ※本食譜使用HD9642 飛利浦 渦輪氣旋健康氣炸鍋

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 將2匙康寶鮮味炒手(奶素)溶於清水裡成豆皮醃漬料，攤開豆皮，在朝內的一面均勻抹上適量的豆皮醃漬料。
2. 蔬菜切成同豆皮寬度，灑上1/4匙康寶鮮味炒手(奶素)。
3. 豆皮鋪上海苔，放上適量蔬菜，捲成一卷。
4. 豆皮卷好後，收口朝下，放入氣炸鍋煎烤盤上，並於表面噴油。氣炸鍋設定190度 13 分鐘。
5. 完成聲響，取出並切片即可，亦可沾番茄醬吃。

## 💡 料理小貼士 / Chef's Tips
- 氣炸鍋料理好方便! 加點鮮味炒手簡單調味，帶出食材自然清甜

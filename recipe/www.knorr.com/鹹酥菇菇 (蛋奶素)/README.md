# 鹹酥菇菇 (蛋奶素) (Taiwanese Crispy Fried Mushrooms (Ovo-Lacto))

![鹹酥菇菇 (蛋奶素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：鹹酥菇菇 (蛋奶素)
- **料理名称 (简体)**：咸酥菇菇(蛋奶素)
- **English Title**：Taiwanese Crispy Fried Mushrooms (Ovo-Lacto)
- **素食流派 / Diet**：蛋奶素 Ovo-Lacto
- **料理分類 / Category**：炸物 / 小吃
- **份量 / Servings**：4 人份
- **準備時間 / Prep Time**：25 分鐘
- **烹飪時間 / Cook Time**：7 分鐘
- **總計耗時 / Total Time**：32 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%B9%B9%E9%85%A5%E8%8F%87%E8%8F%87-(%E8%9B%8B%E5%A5%B6%E7%B4%A0).html/188824)

## 🌿 食材清單 / Ingredients
- 金針菇 50 克
- 杏鮑菇 250 克
- 九層塔 適量
- 油 適量
- 乾辣椒末 少許
- 康寶鮮味炒手(奶素) 3匙
- 雞蛋 2 顆
- 木薯粉 1 杯
- *本食譜使用HD9642 飛利浦 渦輪氣旋健康氣炸鍋

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 杏鮑菇切塊並抹上1匙康寶鮮味炒手(奶素)， 醃 10 分鐘入味，金針菇可省略此步驟。
2. 雞蛋打勻並加入1匙康寶鮮味炒手(奶素)拌勻；木薯粉加入 1 匙康寶鮮味炒手(奶素)混合成麵衣 。
3. 將金針菇分成小束，與杏鮑菇分別先後沾上蛋液與麵衣，並平鋪在盤子上 10 分鐘反潮，並於正反面噴油。
4. 將金針菇放入氣炸鍋的煎烤盤上，不要重疊。氣炸鍋設定 190 度 7 分鐘 。 剩1 分鐘時打開氣炸鍋，將九層塔噴油，壓在菇的下面。
5. 完成聲響，打開氣炸鍋，取出食材、放入杏鮑菇，並重複步驟4。
6. 在所有食材灑上少許康寶鮮味炒手(奶素)提味，亦可灑上乾辣椒。

## 💡 料理小貼士 / Chef's Tips
- 推薦使用康寶鮮味高湯或素食調味料，快速提鮮提升料理層次。

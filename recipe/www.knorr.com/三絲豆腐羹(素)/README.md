# 三絲豆腐羹(素) (Three Shreds Tofu Thick Soup)

![三絲豆腐羹(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：三絲豆腐羹(素)
- **料理名称 (简体)**：三丝豆腐羹(素)
- **English Title**：Three Shreds Tofu Thick Soup
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：羹湯 / 湯品
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：8 分鐘
- **烹飪時間 / Cook Time**：12 分鐘
- **總計耗時 / Total Time**：20 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E4%B8%89%E7%B5%B2%E8%B1%86%E8%85%90%E7%BE%B9(%E7%B4%A0).html/176044)

## 🌿 食材清單 / Ingredients
- 筍絲 100公克
- 香菇絲 30公克
- 嫩豆腐絲 250公克
- 紅蘿蔔絲 60公克
- 水 400㏄
- 康寶鮮味炒手(奶素) 2匙
- 白胡椒粉 1茶匙
- 太白粉水 3大匙
- 香油 1茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 香菇絲、紅蘿蔔絲、筍絲用開水汆燙10秒後瀝乾。
2. 取一湯鍋，加入水及所有材料，以中火煮開，加入康寶鮮味炒手(奶素)、白胡椒粉調味。
3. 煮滾後轉小火，用太白粉水勾芡，加入香油即可。

## 💡 料理小貼士 / Chef's Tips
- 加入多種蔬菜絲，再用鮮味炒手(奶素)簡單調味，三絲豆腐羹營養又美味!

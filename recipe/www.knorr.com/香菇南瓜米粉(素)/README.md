# 香菇南瓜米粉(素) (Mushroom Pumpkin Rice Vermicelli)

![香菇南瓜米粉(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：香菇南瓜米粉(素)
- **料理名称 (简体)**：香菇南瓜米粉(素)
- **English Title**：Mushroom Pumpkin Rice Vermicelli
- **素食流派 / Diet**：奶素 Lacto-Vegetarian
- **料理分類 / Category**：麵食 / 米粉
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：4 分鐘
- **烹飪時間 / Cook Time**：15 分鐘
- **總計耗時 / Total Time**：19 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%A6%99%E8%8F%87%E5%8D%97%E7%93%9C%E7%B1%B3%E7%B2%89(%E7%B4%A0).html/188973)

## 🌿 食材清單 / Ingredients
- 米粉 80公克
- 南瓜絲 150公克
- 青江菜絲 50公克
- 香菇絲 30公克
- 豆皮絲 100公克
- 康寶鮮味炒手(奶素) 2匙
- 水 150㏄

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 米粉以熱水汆燙約30秒後撈起瀝乾，用筷子攤平放涼。
2. 熱鍋倒入少許油，放入香菇絲、豆皮絲、南瓜絲拌炒，再加入康寶鮮味炒手(奶素)及水調味拌勻。
3. 放入做法1的米粉及青江菜絲一起拌炒，至湯汁收乾即可。

## 💡 料理小貼士 / Chef's Tips
- 推薦使用康寶鮮味高湯或素食調味料，快速提鮮提升料理層次。

# 五福腐皮捲 (Five Blessings Bean Curd Skin Rolls)

![五福腐皮捲](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：五福腐皮捲
- **料理名称 (简体)**：五福腐皮卷
- **English Title**：Five Blessings Bean Curd Skin Rolls
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：精緻熱菜 / 年菜
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：3 分鐘
- **烹飪時間 / Cook Time**：7 分鐘
- **總計耗時 / Total Time**：10 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E4%BA%94%E7%A6%8F%E8%85%90%E7%9A%AE%E6%8D%B2.html/233570)

## 🌿 食材清單 / Ingredients
- 煙燻豆皮 3張
- 胡蘿蔔絲 50克
- 泡發香菇絲 40克
- 芹菜段 40克
- 金針菇 60克
- 豆芽 120克
- 奶素鮮味炒手 2茶匙
- 白胡椒粉 1/2茶匙
- 香油 1茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 熱鍋下2茶匙油，先下香菇絲及胡蘿蔔絲炒香。
2. 再下芹菜段、金針菇、豆芽及奶素鮮味炒手、白胡椒粉炒勻，淋上香油即可盛出。
3. 煙燻豆皮用熱開水略洗過瀝乾。取一張豆皮攤開，取適量炒好的料鋪上，捲成圓筒狀。依序包好，對切裝盤即可。

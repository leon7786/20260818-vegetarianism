# 如意冬瓜卷 (Ruyi Winter Melon Rolls with Mushroom Stuffing)

![如意冬瓜卷](cover.jpg)

- **料理名稱 (繁體)**：如意冬瓜卷
- **料理名称 (简体)**：如意冬瓜卷
- **English Title**：Ruyi Winter Melon Rolls with Mushroom Stuffing
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：精緻熱菜 / 宴席料理 / 精工素菜
- **份量 / Servings**：6-8 人份
- **準備時間 / Prep Time**：15 分鐘
- **烹飪時間 / Cook Time**：20 分鐘
- **總計耗時 / Total Time**：35 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E5%A6%82%E6%84%8F%E5%86%AC%E7%93%9C%E5%8D%B7.html/255110)

## 🌿 食材清單 / Ingredients
- 冬瓜 600公克
- 乾香菇（泡發） 50公克
- 胡蘿蔔 30公克
- 黑木耳 30公克
- 綠蘆筍 50公克
- 玉米筍 60公克
- 薑末 5公克
- 康寶原味/全素鮮味炒手 2茶匙
- 清水 30公克（炒餡用）
- 白胡椒粉 1/2茶匙
- 芝麻香油 1茶匙
- 太白粉水 2大匙（太白粉1茶匙+水2大匙調勻）
- 浸泡冬瓜鹽水：清水 300公克 + 食鹽 1/2茶匙

## 🔪 刀工與前處理要求 / Prep & Knife Skills
1. **冬瓜刨片薄透如紙**：冬瓜削去外皮，去除瓜瓤與種籽，修切成長方塊；使用多功能刨片器（或精湛刀工）順著纖維順長刨成厚度約 0.1~0.15 cm、長約 10~12 cm 的均勻薄片。
2. **五彩素絲粗細均勻**：
   - **香菇、胡蘿蔔、黑木耳、玉米筍**：均切成約 0.2 cm 粗細、長約 5 cm 的精細均勻細絲。
   - **綠蘆筍**：切除老根、削去硬皮，切成 5 cm 整齊小段。
   - **生薑**：去皮切成極細薑末。

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. **鹽水浸泡軟化冬瓜**：將刨好的冬瓜薄片放入大碗中，倒入清水 300公克與食鹽 1/2茶匙，輕輕拌勻浸泡約 3 分鐘。待冬瓜片因鹽水滲透失水變得柔韌軟化、不易折斷時撈出，用廚房紙巾輕印吸乾水分備用。
2. **煸炒五彩素餡**：熱鍋倒入少許食用油，下薑末以小火炒香；轉中大火，下入香菇絲、胡蘿蔔絲、黑木耳絲、綠蘆筍段及玉米筍絲快速翻炒至香氣釋放。
3. **調味勾芡固形**：倒入清水 30公克、康寶鮮味炒手 2茶匙、白胡椒粉 1/2茶匙翻炒均勻入味；淋入太白粉水大火快速翻炒勾緊濃芡（使芡汁緊密包裹蔬菜絲而不散落），最後淋入香油 1茶匙拌勻，盛出攤平稍放涼作為如意餡料。
4. **精工卷裹造型**：取一片軟化冬瓜片平鋪於砧板上，在靠前端處夾取適量五彩素餡橫放；從一端緊密向前捲裹成圓筒狀，收口朝下整齊排入耐熱蒸盤中，依序完成全部冬瓜卷。
5. **大火快蒸保脆嫩**：蒸鍋水燒大滾，將裝盤的冬瓜卷放入蒸鍋，加蓋以大火蒸約 5 分鐘，至冬瓜片熟透呈現晶瑩翠白、半透明玉石質地即可出鍋。
6. **原汁淋芡增光**：將蒸盤中蒸出的清甜蔬菜原汁倒回小鍋中加熱，若味道淡可補少許鮮味炒手，淋入少許薄水澱粉勾琉璃薄芡，滴 2 滴香油，均勻淋澆在冬瓜卷表面，增色添亮。

## 💡 料理小貼士 / Chef's Tips
- **冬瓜薄片軟化訣竅**：冬瓜刨片後必須經過淡鹽水浸泡 3 分鐘，鹽漬能軟化植物纖維使其具有韌性，卷裹時服帖不開裂；且能提前逼出冬瓜多餘生水並微微賦予底味。
- **內餡勾芡緊實**：炒素餡時務必勾濃芡（抱汁芡），能鎖住蔬菜脆度與鮮甜，卷餡時蔬菜絲不鬆散掉落。
- **蒸煮火候嚴控**：冬瓜薄片極薄，大火蒸 5 分鐘恰好斷生透明；切忌長時間蒸煮，以免冬瓜軟爛化水、失去脆嫩外形。
- **琉璃淋芡視覺升級**：利用蒸出的鮮美清汁回鍋做「琉璃琉光芡」，淋在冬瓜卷上晶瑩透亮、色澤如翡翠玉如意，是高檔宴席素菜的招牌亮點。

# 如意冬瓜卷 (Ruyi Winter Melon Rolls with Mushroom Stuffing)

## 🌿 食材清單 / Ingredients
- 冬瓜600克
- 香菇絲50克
- 胡蘿蔔絲30克
- 黑木耳絲30克
- 蘆筍段50克
- 玉米筍絲60克
- 薑末5克
- 原味鮮味炒手2茶匙
- 水30克
- 白胡椒粉1/2茶匙
- 香油1茶匙
- 太白粉水2大匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 冬瓜用刨片器刨成薄片。放入碗中，加入300克水及1/2茶匙鹽，浸泡3分鐘後撈出瀝乾。
2. 熱鍋下少許油，下薑末、香菇絲、胡蘿蔔絲、黑木耳絲、蘆筍段及玉米筍炒香。
3. 加入水、原味鮮味炒手、白胡椒粉炒勻，用太白粉水勾芡，加入香油呈現料。
4. 取冬瓜片，放上餡料，捲成圓筒狀，依序做完。放入盤中，蒸約5分鐘後即可。

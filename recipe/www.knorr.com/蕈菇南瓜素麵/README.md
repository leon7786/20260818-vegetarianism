# 蕈菇南瓜素麵

![蕈菇南瓜素麵](cover.jpg)

## 📋 基本資訊
- **料理名稱**：蕈菇南瓜素麵
- **份量**：2 人份
- **準備時間**：5 分鐘
- **烹飪時間**：10 分鐘
- **總計耗時**：15 分鐘
- **來源網站**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E8%95%88%E8%8F%87%E5%8D%97%E7%93%9C%E7%B4%A0%E9%BA%B5.html/159588)

## 🌿 食材清單
- 南瓜絲 180公克
- 柳松菇 80公克
- 青江菜絲 60公克
- 薑絲 5公克
- 蕎麥麵 200公克
- 水 500㏄
- 香菇湯塊 1塊
- 白胡椒粉 1/4茶匙
- 香油 1/2茶匙

## 🍳 烹飪步驟
1. 煮一鍋滾水，放入麵條，以小火煮約1分鐘後撈出瀝乾，放入湯碗中備用。
2. 熱鍋，加入1大匙油，放入薑絲炒香，再加入南瓜絲及柳松菇炒軟，倒入水煮滾，加香菇湯塊、白胡椒調味，淋上香油後，最後放入青江菜絲煮熟，將湯料倒入作法(1)盛裝麵條的碗中即可。

## 💡 料理小貼士
- 吃多了大魚大肉，偶爾來點清淡的變化，不妨嘗試素食新選擇，香菇湯塊配上南瓜與菇類，絕對是此時的最佳首選。

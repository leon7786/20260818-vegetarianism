# 蕈菇南瓜素麵 (Mushroom Pumpkin Vegetarian Noodles)

![蕈菇南瓜素麵](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：蕈菇南瓜素麵
- **料理名称 (简体)**：蕈菇南瓜素面
- **English Title**：Mushroom Pumpkin Vegetarian Noodles
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：麵食 / 主食
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：10 分鐘
- **總計耗時 / Total Time**：15 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E8%95%88%E8%8F%87%E5%8D%97%E7%93%9C%E7%B4%A0%E9%BA%B5.html/159588)

## 🌿 食材清單 / Ingredients
- 南瓜絲 180公克
- 柳松菇 80公克
- 青江菜絲 60公克
- 薑絲 5公克
- 蕎麥麵 200公克
- 水 500㏄
- 香菇湯塊 1塊
- 白胡椒粉 1/4茶匙
- 香油 1/2茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 煮一鍋滾水，放入麵條，以小火煮約1分鐘後撈出瀝乾，放入湯碗中備用。
2. 熱鍋，加入1大匙油，放入薑絲炒香，再加入南瓜絲及柳松菇炒軟，倒入水煮滾，加香菇湯塊、白胡椒調味，淋上香油後，最後放入青江菜絲煮熟，將湯料倒入作法(1)盛裝麵條的碗中即可。

## 💡 料理小貼士與大廚提鮮技巧 / Chef's Tips & Umami Secrets
- **風味層次**：吃多了大魚大肉，偶爾來點清淡的變化，不妨嘗試素食新選擇。香菇湯塊配上南瓜與菇類，絕對是此時的最佳首選。
- **大廚提鮮技巧**：南瓜的天然甘甜與柳松菇的木質蕈香相得益彰，爆香薑絲能去生提香，加入康寶香菇湯塊可快速釋放濃醇素高湯精華，免去數小時熬湯步驟。
- **麵條口感秘訣**：蕎麥麵煮約1分鐘至八分熟撈出，再倒入滾熱的南瓜菇菌湯頭，麵體能充分吸收鮮美高湯且保持Q彈不軟爛。

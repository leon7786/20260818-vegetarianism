# 金沙豆腐 (Golden Salted Egg Tofu)

![金沙豆腐](cover.jpg)

## 🌿 食材清單 / Ingredients
- 雞蛋豆腐 1盒（約300公克）
- 青蔥 1根（切蔥花，避五辛者可改用芹菜末或香菜末）
- 太白粉（或地瓜粉/玉米澱粉） 少許（適量，用於裹粉煎脆）
- 康寶私廚料理醬-金沙豆腐醬 1包（約60-80公克）
- 食用油 適量（煎豆腐用油適量 + 炒金沙醬用油約1大匙）
- 辣椒 1/2根（選配，切圈添色增香）

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. **食材備料**：將青蔥洗淨切成蔥花；辣椒切細圈備用。
2. **豆腐吸水與裹粉**：將雞蛋豆腐從盒中取出切成立方塊（約2~2.5公分見方）；用紙巾將雞蛋豆腐每一面均勻徹底擦乾水分（吸乾水分是防止油爆且能讓外皮酥脆的關鍵），接著將豆腐塊表面均勻裹上一層薄薄的太白粉。
3. **香煎豆腐（外酥內嫩）**：熱鍋下適量食用油（中火油溫約160°C~170°C），輕輕放入裹好粉的豆腐塊，以中火慢煎，適時翻動各面，將豆腐每一面均煎至金黃酥脆後，撈出瀝乾油份備用。
4. **炒製金沙醬（小火起沙冒泡）**：熱鍋下少許食用油（約1大匙），**轉「小火」**，倒入康寶金沙豆腐料理醬（或蒸熟壓碎的鹹蛋黃泥），快速攪拌均勻；保持小火加熱至醬汁受熱乳化、均勻冒出細密金黃泡沫（起沙出香）。
5. **回鍋裹醬與盛盤**：待金沙醬冒泡起沙且散發濃郁蛋黃香氣後，立即回鍋加入煎好的金沙豆腐塊，快速輕巧翻炒或顛鍋，使每塊豆腐均勻裹上一層厚厚金沙醬；待醬汁收乾緊裹於豆腐表面，最後撒入蔥花（及辣椒圈）拌勻即可關火盛盤。

## 💡 料理小貼士 / Chef's Tips
- **吸乾水份避免脫粉油爆**：雞蛋豆腐含水量極高，裹粉前必須用紙巾將表面水分徹底吸乾，下鍋時粉皮才不易脫落，油煎時也不會噴油。
- **炒金沙醬關鍵在於「小火慢炒」**：金沙醬（鹹蛋黃）非常容易在高溫下焦苦，熱鍋冷油後一定要轉最小火慢慢推炒，看見醬汁均勻泛起綿密黃色細泡（起沙）時立即下豆腐翻炒。
- **顛鍋裹醬保持酥脆完整**：豆腐裹上金沙時以顛鍋或鍋鏟背面輕推為主，動作快速輕柔，既能均勻包裹濃郁金沙醬汁，又能保持豆腐外酥內嫩、形狀完整。

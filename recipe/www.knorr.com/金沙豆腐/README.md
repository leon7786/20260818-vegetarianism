# 金沙豆腐 (Golden Salted Egg Tofu)

![金沙豆腐](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：金沙豆腐
- **料理名称 (简体)**：金沙豆腐
- **English Title**：Golden Salted Egg Tofu
- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：熱炒 / 經典家常
- **份量 / Servings**：3 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：10 分鐘
- **總計耗時 / Total Time**：15 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%87%91%E6%B2%99%E8%B1%86%E8%85%90.html/232937)

## 🌿 食材清單 / Ingredients
- 雞蛋豆腐1盒
- 蔥1根
- 太白粉少許
- 康寶私廚料理醬-金沙豆腐醬1包

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 將蔥段切成蔥花，豆腐切塊備用。
2. 用紙巾將雞蛋豆腐將每一面均勻擦乾水份後切塊並裹上太白粉。
3. 熱鍋下油將豆腐煎兩面至金黃色備用
4. 熱鍋下少許油(約一大匙)並「小火」將康寶金沙豆腐料理醬拌勻後快速攪拌均勻，待醬汁冒泡後，回鍋加入剛剛處理好的豆腐
5. 待醬汁收乾後，最後加上蔥花即可完成

## 💡 料理小貼士 / Chef's Tips
- 蛋黃香氣超濃郁！將雞蛋豆腐煎至兩面金黃，再與康寶金沙豆腐料理醬一起拌炒均勻，最後撒上蔥花或辣椒就完成。色香味俱全，食慾大開！

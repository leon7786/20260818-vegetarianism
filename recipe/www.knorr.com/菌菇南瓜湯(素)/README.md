# 菌菇南瓜湯(素) (Creamy Mushroom Pumpkin Soup (Vegetarian))

![菌菇南瓜湯(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：菌菇南瓜湯(素)
- **料理名称 (简体)**：菌菇南瓜汤(素)
- **English Title**：Creamy Mushroom Pumpkin Soup (Vegetarian)
- **素食流派 / Diet**：奶素 Lacto-Vegetarian
- **料理分類 / Category**：湯品 / 西式濃湯
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：15 分鐘
- **烹飪時間 / Cook Time**：2 分鐘
- **總計耗時 / Total Time**：17 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E8%8F%8C%E8%8F%87%E5%8D%97%E7%93%9C%E6%B9%AF(%E7%B4%A0).html/229648)

## 🌿 食材清單 / Ingredients
- 南瓜塊 300克
- 雪白菇50克
- 鴻喜菇50克
- 水 600CC
- 鮮奶 100CC
- 康寶鮮味炒手(奶素) 2茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 南瓜入鍋與600CC水一起小火悶煮約10分鐘後關火放涼。
2. 將放涼的南瓜連湯用果汁機打成泥後入鍋小火煮開。
3. 加入鮮奶及鮮味炒手(奶素)煮滾後，加入雪白菇及鴻喜菇煮滾約1分鐘即可。

## 💡 料理小貼士 / Chef's Tips
- 推薦使用康寶鮮味高湯或素食調味料，快速提鮮提升料理層次。

# 香菇油豆腐煲 (Braised Shiitake Mushroom with Fried Tofu Claypot)

![香菇油豆腐煲](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：香菇油豆腐煲
- **料理名称 (简体)**：香菇油豆腐煲
- **English Title**：Braised Shiitake Mushroom with Fried Tofu Claypot
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：煲仔 / 熱炒
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：10 分鐘
- **總計耗時 / Total Time**：15 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E9%A6%99%E8%8F%87%E6%B2%B9%E8%B1%86%E8%85%90%E7%85%B2.html/233589)

## 🌿 食材清單 / Ingredients
- 油豆腐 500克
- 泡發香菇 30克
- 筍片 100克
- 胡蘿蔔片 30克
- 甜豆筴 40克
- 薑末 15克
- 水 300克
- 香菇湯塊 2塊
- 太白粉水 1大匙
- 香油 2茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 油豆腐切小塊用開水燙洗過瀝乾。熱鍋下油，爆香香菇及薑片。加入筍片、胡蘿蔔片炒勻。
2. 加入水及香菇湯塊煮滾。下油豆腐及甜豆筴燉煮約3分鐘。
3. 用太白粉水勾薄芡，淋上香油即可。

## 💡 料理小貼士 / Chef's Tips
- 簡單就能完成的蔬食料理，用香菇湯塊讓湯頭味道更鮮美!

# 涼拌素什錦(素) (Cold Tossed Assorted Vegetarian Salad)

![涼拌素什錦(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：涼拌素什錦(素)
- **料理名称 (简体)**：凉拌素什锦(素)
- **English Title**：Cold Tossed Assorted Vegetarian Salad
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：涼拌 / 前菜
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：10 分鐘
- **總計耗時 / Total Time**：15 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E6%B6%BC%E6%8B%8C%E7%B4%A0%E4%BB%80%E9%8C%A6(%E7%B4%A0).html/176045)

## 🌿 食材清單 / Ingredients
- 豆皮絲 100公克
- 紅甜椒絲 50公克
- 芹菜段 50公克
- 金針菇 50公克
- 木耳絲 60公克
- 黃豆芽 150公克
- 康寶鮮味炒手(奶素) 1匙
- 白醋 2茶匙
- 細砂糖 2茶匙
- 芝麻香油 2大匙
- 薑末 10克
- 水 2大匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 所有材料一起用開水汆燙約1分鐘後，泡冰水瀝乾。
2. 熱鍋下少許油，薑末下鍋小火炒香。放入所有調味料煮滾後倒出放涼。再與做法1燙熟的材料一起拌勻即可。

## 💡 料理小貼士 / Chef's Tips
- 美味又營養的涼拌素什錦，加入康寶鮮味炒手(奶素)簡單調味，能帶出食材的自然鮮甜!

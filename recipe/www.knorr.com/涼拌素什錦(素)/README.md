# 涼拌素什錦(素) (Cold Tossed Assorted Vegetarian Salad)

![涼拌素什錦(素)](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：涼拌素什錦(素)
- **料理名称 (简体)**：凉拌素什锦(素)
- **English Title**：Cold Tossed Assorted Vegetarian Salad
- **素食流派 / Diet**：全素 Vegan / 奶素可用
- **料理分類 / Category**：涼拌 / 開胃前菜
- **份量 / Servings**：2-4 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：10 分鐘
- **總計耗時 / Total Time**：15 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E6%B6%BC%E6%8B%8C%E7%B4%A0%E4%BB%80%E9%8C%A6(%E7%B4%A0).html/176045)

## 🌿 食材清單 / Ingredients
- 豆皮絲 100公克
- 紅甜椒絲 50公克
- 芹菜段 50公克
- 金針菇 50公克
- 木耳絲 60公克
- 黃豆芽 150公克
- 薑末 10公克
- 康寶鮮味炒手(奶素/全素) 1匙
- 白醋 2茶匙
- 細砂糖 2茶匙
- 芝麻香油 2大匙
- 水 2大匙
- 食用油 少許（爆香薑末用）

## 🔪 刀工與前處理要求 / Prep & Knife Skills
1. **粗細長短一致**：
   - **豆皮、紅甜椒、黑木耳**：均切成寬約 0.2~0.3 cm、長約 5 cm 的均勻細絲。
   - **芹菜**：摘去老葉，洗淨後切成 5 cm 長段。
   - **金針菇**：切除根部雜質，手撕成均勻小束。
   - **黃豆芽**：洗淨並挑除豆殼與老根。
   - **老薑**：去皮切成細薑末。

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. **汆燙殺青**：湯鍋加足量水煮大滾，將黃豆芽、木耳絲、芹菜段、金針菇、豆皮絲及紅甜椒絲全體下鍋，大火快速汆燙約 1 分鐘至黃豆芽斷生去生豆味、蔬菜保持脆嫩。
2. **冰鎮過涼**：將燙熟食材迅速撈出，立即投入冰塊水/冷開水中充分浸泡冰鎮降溫，徹底冷卻後撈出用力擠乾/瀝乾水分備用。
3. **炒香乳化醬汁**：熱鍋下少許食用油，下薑末以小火慢炒爆香；倒入水 2大匙、白醋 2茶匙、細砂糖 2茶匙、康寶鮮味炒手 1匙、芝麻香油 2大匙，煮滾至糖融化、油醋微乳化後關火，盛出徹底放涼。
4. **拌勻裝盤**：將完全冷卻的薑香調味汁倒入瀝乾冰鎮的什錦食材中，充分抓拌均勻，靜置 5 分鐘入味後即可盛盤上桌。

## 💡 料理小貼士 / Chef's Tips
- **汆燙過涼關鍵**：汆燙時間嚴格控制在 1 分鐘內，撈起後務必立刻投入冰水，能迅速阻斷食材內部餘溫，完美鎖住芹菜翠綠與甜椒鮮紅，並保持爽脆多汁的口感。
- **冷熱分離拌製**：調味汁先加熱煮滾能激發薑末與芝麻香油的複合香氣，但調味汁**必須完全放涼後**才能與什錦蔬菜拌合，防止溫熱醬汁將爽脆蔬菜燙軟出水。
- **風味提升**：食用前放入冰箱冷藏 15-20 分鐘，冰涼爽口、酸甜開胃，是夏日或宴席解膩的首選涼菜。

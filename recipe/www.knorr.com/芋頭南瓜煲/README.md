# 芋頭南瓜煲 (Braised Taro and Pumpkin Pot)

![芋頭南瓜煲](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱 (繁體)**：芋頭南瓜煲
- **料理名称 (简体)**：芋头南瓜煲
- **English Title**：Braised Taro and Pumpkin Pot
- **素食流派 / Diet**：蛋奶素 Ovo-Lacto
- **料理分類 / Category**：煲仔 / 濃醇料理
- **份量 / Servings**：2 人份
- **準備時間 / Prep Time**：5 分鐘
- **烹飪時間 / Cook Time**：8 分鐘
- **總計耗時 / Total Time**：13 分鐘
- **來源網站 / Source**：[Knorr 康寶食譜官網](https://www.knorr.com/tw/r/%E8%8A%8B%E9%A0%AD%E5%8D%97%E7%93%9C%E7%85%B2.html/234529)

## 🌿 食材清單 / Ingredients
- 芋頭丁200克
- 南瓜丁200克
- 薑末5克
- 芹菜丁20克
- 金黃玉米濃湯包1包
- 水600CC

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 薑末下鍋與芋頭、南瓜炒香，加入100CC水燜3分鐘。
2. 加入500CC水及金黃玉米濃湯包拌勻小火煮滾，約1分鐘，撒上芹菜末即可。

## 💡 料理小貼士 / Chef's Tips
- 選用南瓜的香甜結合芋頭的軟糯，搭配金黃玉米濃湯包做出的芋頭南瓜煲，是一道富含營養價值和膳食纖維的健康佳餚！老少咸宜。

罗汉斋 / 罗汉全斋 / 罗汉菜
粤菜佛门素斋代表作，香菇、木耳、腐竹等菇菌豆制品与蔬菜合炒或焖煮，酱油、糖、香菇水调味，清鲜丰盛、寓意吉祥，年节常见，配料无固定标准，也是海外华人餐馆辨识度最高的中国传统素菜之一。

鼎湖上素
广东肇庆庆云寺名斋，以银耳、香菇、笋和豆制品为核心，辅以素高汤煨制，清雅。

素烧鹅 / 烧素鹅
杭帮菜江南仿荤代表，豆腐皮（千张）卷入香菇丝、胡萝卜丝，先蒸后煎或卷制后炸烧，外形口感仿烧鹅。

素佛跳墙
闽菜传统佛跳墙的素食化版本，菌菇、竹笙、笋做出浓郁汤味，也有猴头菇、竹荪、芋头、栗子、红枣加素高汤慢炖的高级做法。

素鱼 / 素鱼片
广东、江南寺院菜，豆腐、腐皮、面筋等模拟鱼肉，中国仿荤素菜代表。

素鸡
江浙沪传统仿荤，豆腐皮卷制、卤制，口感类似鸡肉，可红烧或凉拌。

素鸭
江浙沪海派素斋常见款，腐皮、豆制品制成；名店款见功德林素鸭。

素火腿
江浙沪传统仿荤菜，以豆制品、面筋等制成。

东坡豆腐
浙江苏浙菜豆腐名菜，与苏东坡饮食文化相关。

干烧冬笋
江南浙菜山珍素菜，以冬笋为主，鲜香浓郁。

油焖笋 / 油焖春笋
杭帮、江浙节令名菜，突出笋的鲜甜和酱香；嫩春笋重油重糖烹制，色泽红亮，鲜嫩爽口。

素什锦
江浙与北方传统素菜，木耳、香菇、豆腐干等多种蔬菜、豆制品、菌菇组合。

香菇油菜 / 香菇青菜
全国及江南经典家常素菜，鲜香菇配油菜、小白菜、油麦菜或上海青，焯水或直接炒，生抽或素蚝油调味，鲜香清淡。

香菇菜心
上海本帮菜，冬菇配油菜心，与香菇油菜近亲，更强调菜心。

地三鲜
东北国民素菜，茄子、土豆、青椒切块分别过油或煎，再用酱油、糖、盐勾芡翻炒或红烧，外酥里嫩、咸鲜回甜，下饭。

干煸四季豆 / 干煸豆角
川菜经典，传统版本可做纯素；豆角炸或煸至表皮起皱，再加干辣椒、花椒、蒜末干煸，干香麻辣。

麻婆豆腐（素食版）
川味素食餐厅常见款，香菇末或木耳末代替肉末，豆瓣酱、花椒粉、辣椒面做成麻辣红油，勾芡后撒花椒粉。

素春卷
江南、粤港及华人地区非常普及的传统素食点心。

素炒三丝
全国传统宴席素菜，胡萝卜、笋、木耳或豆腐干等切丝合炒。

甜酸斋
香港、广东传统斋菜，酸甜口味，常见豆制品、腐皮。

草堂八素
广东佛门高级寺院素斋，讲究多种蔬食组合与刀工。

素鲍鱼
高级传统素斋仿荤名菜，以植物原料模拟鲍鱼。

素海参
高级传统素斋仿荤名菜，以植物原料模拟海参。

素燕窝
高级传统素斋仿荤名菜，以植物原料模拟燕窝。

素狮子头
高级传统素斋仿荤菜，以豆制品、菌菇等制成。

素八珍
高级传统素斋综合素馔。

佛门素斋拼盘
寺院素斋拼盘，汇集多种佛门素菜。

功德林素鸭
上海百年素食名店招牌，海派仿荤；优质豆腐衣层层叠叠，浸满特制甜咸卤汁，是素鸭最有名的餐厅表达。

四喜烤麸
上海本帮经典冷盘，烤麸搭配香菇、木耳、黄花菜、花生，浓油赤酱。

鱼香茄子（素版）
川菜代表，鱼香味型但无鱼；茄子炸或煎软，用豆瓣酱、蒜姜末、糖、醋、生抽调成鱼香汁烧制，酸甜微辣。

家常豆腐
豆腐煎香后配木耳、青椒、胡萝卜等，黄豆酱或豆瓣酱炒香烧制，酱香浓郁。

红烧豆腐
家常酱香豆腐，与家常豆腐、东坡豆腐、麻婆豆腐不是同一道。

干煸茄子
家常素菜，茄子配辣椒干煸。

酸辣土豆丝
中国家常素菜之王；土豆切丝去淀粉，干辣椒、花椒爆香，醋、盐、少许糖快炒，脆爽酸辣，约五分钟出锅。

醋溜白菜
北方、鲁菜、东北家常，大白菜帮叶分开，先炒帮再加叶，陈醋、糖、盐、干辣椒快炒，酸甜清脆，火候要求高。

手撕包菜
包菜手撕成片，干辣椒、蒜、花椒爆香后大火快炒，少许醋提味，脆嫩爽口。

蒜蓉西兰花
简单快手家常菜，蒜蓉炒西兰花，保留清脆口感。

虎皮青椒 / 虎皮尖椒
川菜家常，青椒或青尖椒大火煸至表皮起虎皮焦斑，加蒜、生抽、醋、糖、盐或香醋调味，微辣带酸甜。

红烧茄子
茄子切条或块，少油煎或炸至软，生抽、老抽、糖、蒜末红烧收汁，软糯入味，酱香浓郁，极下饭。

番茄炒豆腐
家常快手菜，番茄与豆腐同炒。

白菜豆腐汤
清淡家常汤，白菜与豆腐同煮。

清炒时蔬
依时令用油麦菜、上海青等清炒。

干锅杏鲍菇
杏鲍菇仿肉质感，微辣干香，偏锅气。

干煸杏鲍菇
现代家常，杏鲍菇撕丝或切条，少量油干煸至焦香，洒芝麻与干椒，偏干香。

宫保猴头菇
创意仿荤，借鉴宫保鸡丁，猴头菇处理后与花生、干辣椒同炒。

凉拌豆腐皮
爽口开胃凉菜。

凉拌腐竹
全国通用凉菜，腐竹泡发后搭配黄瓜、木耳，淋香油与陈醋。

蚝油生菜（素蚝油版）
港式家常，用素蚝油调味。

糖醋藕片
甜酸开胃，可做凉菜或热炒。

酸辣汤（素版）
豆腐、木耳、笋丝，酸辣开胃。

番茄豆腐汤
清淡家常汤品。

拍黄瓜
黄瓜拍裂切块，盐稍腌去水，加蒜末、醋、香油、少许糖或生抽，可选辣椒油，清爽解腻。

小葱拌豆腐
嫩豆腐压碎或切块，加小葱花、盐、香油、少许生抽或麻油，清淡鲜香，适合夏天。

蒜蓉蒸茄子
茄子蒸软，蒜蓉炒香后加生抽、糖、香油淋上，或蒸时放蒜蓉，软糯蒜香。

凉拌木耳
黑木耳泡发焯水，加蒜、醋、生抽、香油、辣椒油、香菜拌匀，爽脆开胃。

红烧冬瓜
冬瓜切块，生抽、老抽、糖、少许蚝油或蘑菇酱油红烧，软糯入味，清淡不油腻。

荷塘小炒
莲藕、胡萝卜、荷兰豆、玉米笋、木耳切条或片，大火快炒，清爽多彩。

荷塘月色
粤菜创新素菜，莲藕、荷兰豆、百合、木耳同炒，清脆爽口，诗意摆盘。

上汤娃娃菜 / 蒜蓉娃娃菜
娃娃菜切开焯水或蒸炒，用菌菇上汤或蒜蓉加生抽调味，鲜嫩多汁。

蒜蓉粉丝娃娃菜
粤菜蒸菜，娃娃菜铺底，泡软粉丝与大量炒香蒜蓉清蒸，清淡鲜美。

清炒空心菜 / 蒜蓉空心菜
南方家常，空心菜大火快炒，蒜爆香后下菜，加盐，也可加豆豉或辣椒，鲜香脆嫩。

桂花糯米藕
江浙甜品素菜，莲藕孔中塞入糯米慢火熬煮，切片后淋桂花糖浆。

松仁玉米
东北甜香素菜，甜玉米粒与松仁同炒，香甜软糯，儿童喜爱。

拔丝地瓜
鲁菜、东北著名甜味素菜，红薯块炸熟后裹上熬化拔丝的白糖，外脆里糯。

麻酱拌菠菜
北方家常凉菜，焯水菠菜切段，淋芝麻酱与少许花生碎。

半月沉江
厦门南普陀寺名菜，原名当归面筋汤。水面筋与香菇分置，黑白如半月沉江；1962 年郭沫若据「半月沉江底，千峰入眼窝」改名，后列入福建经典名菜。

腊八粥
农历腊八纪念释迦牟尼成道，寺院与民间同食。五谷杂粮加红枣、莲子、桂圆等熬成，是佛教饮食里传播最广的食物之一。

文思豆腐
淮扬名菜，豆腐切成极细丝入清汤，以刀工和汤色见长。传统或用荤汤，寺院与素馆以菌菇素高汤制作。

干炸响铃
杭州名菜。豆腐皮卷制后油炸，中空如铃、外脆里空；素馆以蔬菜或豆腐为馅。

冰糖湘莲
湘菜甜品名菜。湖南莲子用冰糖清炖，莲子粉糯、汤清甜，本身即素。

炒双冬 / 油焖双冬
冬菇配冬笋，香糯对爽脆，年菜有「双冬」吉祥口彩；湘菜里少见的不辣代表之一。

红烧面筋
江浙沪素馆与家常都极常见。油面筋吸满酱汁，软糯酱香。

苦尽甘来 / 苦瓜酿素肉
佛门吉祥菜名。苦瓜挖瓤酿素馅蒸熟切片，先苦后甘，常见于斋宴。

清炒绿豆芽 / 醋炒豆芽
全国快手家常。绿豆芽大火快炒，可加醋、辣椒、蒜，脆嫩解腻，成本极低。

芹菜炒香干
江浙沪家常。芹菜配豆腐干，清香有嚼劲。

青椒土豆片
全国极常见家常。青椒配土豆片，咸香微辣，和酸辣土豆丝一样是土豆家常里的高频菜。

# 中国 / 华人地区最著名素菜 Top 25

口径：国际辨识度、寺院与名店传承、历史文化地位、菜系代表性。传统中式素食，不等于现代严格纯素。家常国民菜另见《家常Top25.md》。

1. 罗汉斋 / 罗汉全斋 / 罗汉菜
粤菜佛门素斋代表，也是海外中餐馆最广为人知的中国素菜（Buddha's delight）。香菇、木耳、腐竹、笋、面筋等合炒或焖煮，完整版常取十八种食材象征十八罗汉；年初一常见，配料无固定标准。

2. 鼎湖上素
广东肇庆鼎湖山庆云寺名斋，后为广州菜根香、西园酒家代表菜。三菇六耳、竹荪、莲子、笋等分别煨熟再扣制，讲究素高汤与层次；有「满汉全席中唯一斋品」的说法，鲜嫩滑爽、清雅。

3. 素烧鹅 / 烧素鹅
杭帮菜、江南仿荤代表，相传与杭州寺院素斋相关。豆腐皮（千张）卷入香菇丝、胡萝卜丝，先蒸后煎或炸烧，外形口感仿烧鹅。

4. 素佛跳墙
闽菜佛跳墙的素食化版本。菌菇、竹笙、笋、芋头、栗子、红枣等加素高汤慢炖或蒸制，汤味浓郁，是高级素席压轴之一。

5. 半月沉江
厦门南普陀寺名菜，原名当归面筋汤。水面筋与香菇分置，黑白如半月沉江；1962 年郭沫若据「半月沉江底，千峰入眼窝」改名，后列入福建经典名菜，兼具药膳风味。

6. 功德林素鸭
上海功德林百年素食名店招牌，海派仿荤。优质豆腐衣层层叠叠，浸满甜咸卤汁，是「素鸭」最有名的餐厅表达。

7. 素鸡
江浙沪传统仿荤，豆腐皮卷制、卤制，口感类似鸡肉，可红烧或凉拌，素馆与家宴都常见。

8. 素鱼 / 素鱼片
广东、江南寺院菜，豆腐、腐皮、面筋等模拟鱼肉，是中国仿荤技法的典型。

9. 素火腿
江浙沪传统仿荤，豆制品或面筋制成，切片拼盘或入菜提鲜。

10. 东坡豆腐
浙江、苏浙菜豆腐名菜，与苏东坡饮食文化相关，烧制酱香软嫩。

11. 草堂八素
陕西长安草堂寺一脉的佛门素斋，也是「长安八景宴」相关名菜。多种蔬食、菌菇、面筋组合，讲究一菜多味与刀工。

12. 四喜烤麸
上海本帮经典冷盘。烤麸搭配香菇、木耳、黄花菜、花生，浓油赤酱，年节与素席常见。

13. 油焖笋 / 油焖春笋
杭帮、江浙节令名菜。嫩春笋重油重糖焖至红亮，鲜甜酱香，是江南素菜辨识度很高的时令菜。

14. 干烧冬笋
江南、浙菜山珍素菜，冬笋为主干烧，鲜香浓郁。

15. 炒双冬 / 油焖双冬
冬菇配冬笋，香糯对爽脆，年菜有「双冬」吉祥口彩；湘菜里少见的不辣代表之一，也作素席热菜。

16. 甜酸斋
香港、广东传统斋菜，酸甜口味，常用腐皮、豆制品等味浓素料，是罗汉斋的浓味变体。

17. 素春卷
江南、粤港及海外华人地区极普及的传统素食点心，蔬菜、菌菇、豆干等做馅。

18. 桂花糯米藕
江浙甜品素菜。莲藕孔中塞入糯米慢火熬煮，切片淋桂花糖浆，粉糯香甜。

19. 腊八粥
农历腊八纪念释迦牟尼成道，寺院与民间同食。五谷杂粮加红枣、莲子、桂圆等熬成，是佛教饮食里传播最广的食物之一。

20. 文思豆腐
淮扬名菜，豆腐切成极细丝入清汤，以刀工和汤色见长。传统或用荤汤，寺院与素馆以菌菇素高汤制作，清鲜如羹。

21. 干炸响铃
杭州名菜。豆腐皮卷制后油炸，中空如铃、外脆里空；素馆以蔬菜或豆腐为馅，是豆皮仿荤工艺的代表点心。

22. 冰糖湘莲
湘菜甜品名菜。湖南莲子用冰糖清炖，莲子粉糯、汤清甜，本身即素。

23. 素狮子头
高级素斋仿荤，豆制品、菌菇等制成大丸，红烧或砂锅，形制取自扬镇狮子头。

24. 红烧面筋
江浙沪素馆与家常都极常见。油面筋吸满酱汁，软糯酱香，是面筋素菜里最有名的热菜之一。

25. 苦尽甘来 / 苦瓜酿素肉
佛门吉祥菜名。苦瓜挖瓤酿素馅蒸熟切片，先苦后甘，常见于斋宴与素席。

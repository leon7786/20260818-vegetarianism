## 🌿 食材及佐料清單 / Ingredients

- 盐 适量 (配料)
- 鸡精 适量 (配料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备材料
2. 尖椒洗净，去蒂和筋籽，切段。大蒜切末
3. 取蚝油，用清水澥开，加入适量盐、少许糖、香醋、鸡精调成酱汁
4. 锅中不要放油，将尖椒段干煸
5. 直至绿尖椒表皮起泡微微变焦后盛出
6. 锅中放油，下蒜末爆香
7. 放入煸好的尖椒翻炒
8. 加入酱汁调味
9. 翻炒均匀，关火装盘即可

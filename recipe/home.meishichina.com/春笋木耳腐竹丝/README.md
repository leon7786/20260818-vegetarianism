## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 水发腐竹，切成丝，焯一下水。
2. 春笋切成片，焯一下水。
3. 水发木耳，焯一下水。
4. 锅里加入少许油，煸炒一下花椒粒和姜丝，然后捞出，炒一下笋丝。
5. 然后加入腐竹和木耳进行翻炒，锅里对一些开水，这时候加入老抽，生抽，盐和糖进校调味。
6. 小火炒10分钟即可，出锅前加入味精调味。

# 胡萝卜炒韭菜芽

- **原始標題**：胡萝卜炒韭菜芽
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 经典热菜
- **來源平台 / Source**：[美食天下 · 精華素食專區](https://home.meishichina.com/recipe-229699.html)

## 🌿 食材及佐料清單 / Ingredients
- 韭菜芽 105克 (主料)
- 胡萝卜 55克 (主料)
- 盐 适量 (辅料)
- 味精 适量 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 食材：韭菜芽（已清洗切段）、胡萝卜（已清洗擦成丝）
2. 烧锅倒油烧热，下入胡萝卜丝翻炒翻炒。
3. 接着，合入切好的韭菜芽翻炒翻炒，加适量的盐。
4. 加适量的味精。
5. 调味炒匀，即成。
6. 出锅装盘。

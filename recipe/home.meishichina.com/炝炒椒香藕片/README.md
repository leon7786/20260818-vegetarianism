## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鲜藕打皮后切薄片。
2. 把切好的藕片用开水焯过后，过凉水。
3. 另起油锅，油热后放入鲜花椒、姜丝爆香。
4. 放入一汤匙剁椒，翻炒。
5. 倒入藕片，烹入白醋大火翻炒。
6. 入少许精盐，翻炒均匀后即可出锅。

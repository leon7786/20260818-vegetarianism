## 🌿 食材及佐料清單 / Ingredients
- 韭菜 适量 (主料)
- 食盐 适量 (辅料)
- 胡椒粉 适量 (辅料)
- 油 适量 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 把韭菜洗净
2. 烧开水放少量盐和几滴油，韭菜放入焯一下，迅速捞出冷水过凉。
3. 三四根韭菜一起摆整齐从根部开始慢慢卷起成卷，卷紧,用牙签从卷好的韭菜卷中间穿过。依次卷好所有的韭菜，放入已放锡纸的烤盘中。
4. 在韭菜卷上均匀地刷一层油，撒上食盐、胡椒粉
5. 放入已预热的烤箱，最底层，上下火150度，烤3分钟即可。
6. 出炉啰~

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 周日领着女儿去采摘园里刨的紫皮的花生。
2. 花生彻底清洗干净，有很多泥沙。
3. 捏开一个小口，方便入味。（呵呵主要是花生不多，我闲着也没事，如嫌麻烦此步也可忽略）
4. 在锅中加入适量水（我用的电压力锅），放入花生，花椒，八角和盐压15分钟。
5. 压好后再焖三个小时即可食用。

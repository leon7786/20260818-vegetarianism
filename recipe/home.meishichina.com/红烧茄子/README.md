## 🌿 食材及佐料清單 / Ingredients
- 长茄子 500克 (主料)
- 海鲜酱油 1克 (辅料)
- 葱段 5克 (辅料)
- 姜丝 5克 (辅料)
- 白糖 2克 (辅料)
- 盐 1克 (辅料)
- 鸡精 1克 (辅料)
- 蒜沫 5克 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 葱姜蒜切好备用
2. 长茄子切块
3. 下油煸香葱姜蒜，下茄子
4. 翻炒3分钟放酱油，在炒2分钟出锅，放调料出锅
5. 美味上桌啦

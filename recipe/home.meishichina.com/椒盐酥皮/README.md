## 🌿 食材及佐料清單 / Ingredients
- 饺子皮 195克 (主料)
- 椒盐 适量 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 食材：饺子皮、椒盐
2. 将饺子皮放在案板上切开。
3. 接着，在锅中加入油烧热，下入切好的饺子皮炸至金黄色捞出。
4. 放入大碗中。
5. 然后，加适量的椒盐。
6. 上下抖匀，即成。

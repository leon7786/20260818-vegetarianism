- 花椒 适量 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 黑豆芽洗净，干红椒切段、生姜切小片。
2. 锅里油热后放入干红椒段、生姜片、花椒爆香。
3. 倒入黑豆芽，大火翻炒。
4. 加少许精盐。
5. 倒入1/2汤匙酱油，大火煸炒至没有水汽即可。

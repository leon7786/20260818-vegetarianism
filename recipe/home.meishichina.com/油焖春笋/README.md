## 🌿 食材及佐料清單 / Ingredients
- 春笋 1个 (主料)
- 红甜椒 一个 (主料)
- 葱花 适量 (辅料)
- 花椒 10粒 (配料)
- 酱油 一大勺 (配料)
- 白糖 两小勺 (配料)
- 植物油 两大勺 (配料)
- 水 100克 (配料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备材料;
2. 春笋剥壳洗净，对剖，切成小段；
3. 红甜椒切成小块，葱花切成小段;
4. 将炒锅烧热，放油烧至五成熟时，放入花椒炸出香味后捞出；
5. 把春笋段入锅；
6. 煸炒至微黄时，加入酱油和白糖，再加入水，加盖子，用中火闷5分钟；
7. 然后拿开盖子，继续煮，收汁到只见油，不见水的状态，期间加入葱花、红甜椒翻炒一下，这样更入味;
8. 味道鲜美！

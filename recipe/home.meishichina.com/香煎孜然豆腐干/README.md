## 🌿 食材及佐料清單 / Ingredients
- 白豆腐干 若干 (主料)
- 植物油 适量 (辅料)
- 孜然粉 适量 (配料)
- 辣椒粉 适量 (配料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 白豆腐干选取几块，洗净，切成四方小块。
2. 锅内添少许油，油温热后倒入豆腐块摊平，用中火先浸炸。
3. 改为小火，慢慢将豆腐块反正面都煎到变黄。
4. 盘子内事先撒一些孜然粉，将煎好的豆腐块盛到盘子里，趁热在表面再撒入孜然粉及椒盐，喜欢吃辣味的可以放些辣椒粉，拌匀即可。也可以弄些口味甜咸的酱料汁淋在上面，更具街头小吃的风味。
5. 这就是美味的香煎孜然豆腐干啦！可以当做下酒小菜或零食呢。

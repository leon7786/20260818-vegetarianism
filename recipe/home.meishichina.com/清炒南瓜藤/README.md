## 🌿 食材及佐料清單 / Ingredients
- 南瓜藤 适量 (主料)
- 大蒜 适量 (主料)
- 盐 适量 (辅料)
- 鸡精 适量 (辅料)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 南瓜藤剥去外层老筋，掰小段洗净。大蒜切碎。
2. 锅中放少许油，加入大蒜碎煸香。
3. 加入南瓜藤炒软。
4. 加入盐和鸡精调味。

# 小米南瓜粥

## 🌿 食材及佐料清單 / Ingredients
- 黄小米 80克
- 老南瓜 150克
- 枸杞 10粒
- 清水 1000ml

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 小米淘洗干净；老南瓜去皮去瓤切成小薄片（薄片更容易熬化出沙）。
2. 砂锅加足量清水大火烧开，下入小米和南瓜片。
3. 再次煮沸后转中小火慢熬30分钟，中途用木勺顺时针搅拌几次防止粘底并促进米油析出。
4. 熬至南瓜软烂融于粥中、小米开花浓稠且表面结出金黄米油。
5. 出锅前加入洗净的枸杞煮2分钟即可。

## 💡 大廚美味秘訣 / Chef's Tips
- 开水下米不易粘底，老南瓜甘甜软糯，熬煮时多搅拌能快速熬出金黄浓郁的米油。

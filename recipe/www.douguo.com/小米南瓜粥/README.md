# 小米南瓜粥

## 🌿 食材及佐料清單 / Ingredients
- 小米 30克
- 南瓜 70克
- 红糖 20克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备好材料，小米30克，南瓜70克，红糖20克，这个是一人份的量。
2. 小米用凉水淘洗干净浸泡半小时候左右，南瓜去皮切成小块。
3. 焖烧杯先用100度的开水预热下，焖烧杯实际上就是保温效果比较好的保温杯，初始温度是很重要的，所以用之前一定要预热，水烧开后倒入杯子，拧紧杯盖，十分钟左右。
4. 取一锅把小米连同浸水和切好的南瓜一起倒入锅中，煮开。
5. 把杯子中的开水倒掉，煮开的小米南瓜放入杯子中。焖烧杯没有加热功能，所以食材必须煮沸再放入杯子中。
6. 这种天气，我焖了差不多1小时左右就可以了。
7. 打开杯盖，把红糖放入杯子，等红糖融化就可以喝了。
8. 倒入碗中。
9. 软糯香甜，温补养胃，简单省事的小米南瓜粥。

## 💡 大廚美味秘訣 / Chef's Tips
- 1、小米淘洗时要注意，不要用热水，不要使劲搓洗，只要用凉水轻轻淘洗两次就可以，淘洗好后用清水浸泡20-30分钟，煮的时候连同浸泡的水一起倒入锅中，这样煮出来的小米粥非常软稠，还会有层米油，非常香。
2、焖烧杯没有加热功能，就是保温效果比较好的保温杯，所以用的时候要先预热，用开水泡10几分钟再用，焖烧杯没有加热功能，食材必须煮沸再放入杯中。

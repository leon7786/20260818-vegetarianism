# 简单快手的西红鸡蛋拌面

## 🌿 食材及佐料清單 / Ingredients
- 鲜面条 200克
- 西红柿 2个
- 鸡蛋 2个
- 生抽 1.5勺
- 蚝油(素) 1勺
- 番茄酱 1勺
- 白糖 半勺
- 盐 少许
- 葱花 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西红柿划十字开水烫皮后切小丁；鸡蛋加少许盐打散成蛋液。
2. 热锅热油，倒入蛋液快速滑散炒熟盛出备用。
3. 锅底留少许油，下入番茄丁翻炒至出红油出汁，加入生抽、素蚝油、番茄酱、白糖和少许水慢熬成浓郁番茄酱汁。
4. 倒入炒好的鸡蛋块翻炒均匀，让鸡蛋充分吸饱浓郁番茄汁，撒上葱花。
5. 另起一锅水烧开，下入面条煮熟捞出过凉水沥干，盛入大碗中。
6. 将热腾腾浓稠的西红柿鸡蛋卤浇在面条上，拌匀即可享用。

## 💡 大廚美味秘訣 / Chef's Tips
- 番茄切小丁更容易炒化出红沙，加一小勺番茄酱能让色泽更加红亮、酸甜开胃。

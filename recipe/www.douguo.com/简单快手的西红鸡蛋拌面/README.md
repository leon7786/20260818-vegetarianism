# 简单快手的西红鸡蛋拌面

## 🌿 食材及佐料清單 / Ingredients
- 西红柿 4个
- 面条 400克
- 油 适量
- 生鸡蛋 2个
- 葱花 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备好所需要的食材
2. 西红柿清洗干净，表面用刀划“十”字，锅中水烧开，放入西红柿煮2分钟左右，表皮分离
3. 剥去表皮，切成 小块，备用
4. 盆中打入2个鸡蛋，打散
5. 锅加热，少许底油，下鸡蛋液，锅中炒熟划开成小块，盛出备用
6. 锅烧热，下入底油，放入西红柿块，翻炒
7. 炒出汤汁，放入一勺番茄酱
8. 加入一勺白糖调味
9. 准备一个碗，加一勺淀粉，添加适量的水勾芡，备用
10. 锅中放入炒好的鸡蛋
11. 添加一碗水，煮开
12. 加一勺食盐调味
13. 再加入调好的水淀粉，煮开盛出
14. 锅中添加适量清水，加少许玉米油 水开下入手擀面
15. 煮熟后过一次凉水，捞出
16. 上面浇上做好的西红柿鸡蛋卤，撒少许葱花 吃的时候拌匀，超棒的

## 💡 大廚美味秘訣 / Chef's Tips
- 煮手擀面的时候水开再浇2-3次水差不多就熟了。添加番茄酱是为了更好的调味，如没有可以不加。

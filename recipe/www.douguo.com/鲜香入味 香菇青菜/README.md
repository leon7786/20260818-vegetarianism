## 📋 基本資訊 / Recipe Overview
- **料理名稱**：鲜香入味
- **原始標題**：鲜香入味【香菇青菜】
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜

## 🌿 食材及佐料清單 / Ingredients
- 青菜 350g
- 鲜香菇 5朵
- 大蒜 3瓣
- 生抽 1汤匙
- 清水 小半碗
- 盐 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 锅中热油，小火将蒜末煸香
2. 放入香菇片，加少许生抽
3. 加半碗清水，小火焖1分钟
4. 放入青菜
5. 出锅前加少许盐调味

## 🌿 食材及佐料清單 / Ingredients
- 鸡蛋 3个
- 韭菜 少许
- 火腿肠 2根
- 味极鲜 1勺
- 鸡精 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 韭菜洗干净，切成小段，韭菜好吃，但胃不好的要少吃一点
2. 鸡蛋三个，打散搅拌均匀，火腿肠切成小丁，和鸡蛋搅拌均匀。多打几下，这样煎出来的鸡蛋更蓬松
3. 热锅凉油，倒入搅拌好的鸡蛋液，煎熟，撒上韭菜碎，搅拌均匀，韭菜不用炒太久，加入味极鲜和鸡精，就可以出锅了
4. 装盘，我们来吃吧
5. 搭配米饭，每次孩子老公都能吃一大碗

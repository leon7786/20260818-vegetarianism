# 蒜蓉油麦菜

![蒜蓉油麦菜](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：蒜蓉油麦菜
- **原始標題**：#钟于经典传统味#蒜蓉油麦菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2392083.html)

## 🌿 食材及佐料清單 / Ingredients
- 油麦菜 350克
- 盐 1茶匙
- 生抽 1勺
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 油麦菜洗净沥干水分，切成长段。
2. 炒锅烧热倒入适量食用油。
3. 调大火下入油麦菜茎部先炒，再下叶部快速翻炒至叶片变软呈翠绿色。
4. 加入适量生抽和食盐调味，大火爆炒均匀入味。
5. 快速出锅装盘防止出水变黄。

## 💡 大廚美味秘訣 / Chef's Tips
- 油麦菜炒制时间不宜过长，大火快炒30-40秒即可，保持脆嫩多汁。

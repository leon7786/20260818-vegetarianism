# 蒜蓉油麦菜

![蒜蓉油麦菜](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：蒜蓉油麦菜
- **原始標題**：蒜蓉油麦菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2392083.html)

## 🌿 食材及佐料清單 / Ingredients
- 油麦菜 300g
- 蒜瓣 一头
- 大葱 一段
- 生抽 2勺
- 蚝油 1勺
- 白砂糖 半勺
- 食盐 适量
- 黑胡椒粉 适量
- 淀粉 一勺

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 油麦菜洗净切段，下锅焯水30秒
2. 捞出过冷水，沥干水分摆入盘中。
3. 所有调料放入小碗中搅拌均匀
4. 锅中烧热适量油，放入葱末蒜末，炒至金黄
5. 倒入料汁，煮至浓稠
6. 煮好的料汁浇到菜上，拌匀即可
7. 清脆爽口
8. 如果你也喜欢，记得关注我哦！

## 💡 大廚美味秘訣 / Chef's Tips
- 1、焯水一定不要太久，不然就不脆了
2、喜欢辣味可以炒葱蒜的时候放点辣椒粉

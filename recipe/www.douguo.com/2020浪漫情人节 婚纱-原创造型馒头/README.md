- 蓝色面团：适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 60g面团滚圆后整形成圆锥，如图，忘记拍照要做一个爱心的馒头
2. 8mm直径圆形，5个，如图叠加
3. 卷起
4. 对半切开
5. 粘合在圆锥面团上，粘满
6. 蓝色小球做装饰
7. 发酵，蒸制，上面一个白色爱心馒头用牙签固定即可

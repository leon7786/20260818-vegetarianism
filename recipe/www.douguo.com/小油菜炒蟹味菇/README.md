# 小油菜炒蟹味菇

## 🌿 食材及佐料清單 / Ingredients
- 小油菜 250克
- 蟹味菇 150克
- 盐 1茶匙
- 生抽 1勺
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 小油菜洗净对半切开或掰散；蟹味菇剪去根部洗净沥干。
2. 锅中烧开水，下入蟹味菇焯水1分钟去除菌菇草酸与涩味，捞出沥干。
3. 炒锅烧热倒油，下入焯好水的蟹味菇大火翻炒出香味。
4. 下入小油菜快速大火翻炒至菜叶变软颜色翠绿。
5. 调入生抽和适量食盐翻炒均匀入味即可出锅装盘。

## 💡 大廚美味秘訣 / Chef's Tips
- 蟹味菇焯水后炒制更爽口嫩滑，大火快炒保持油菜清脆多汁。

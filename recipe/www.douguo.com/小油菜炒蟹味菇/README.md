# 小油菜炒蟹味菇

![小油菜炒蟹味菇](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：小油菜炒蟹味菇
- **原始標題**：小油菜炒蟹味菇
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2060962.html)

## 🌿 食材及佐料清單 / Ingredients
- 小油菜 150克
- 蟹味菇 150克
- 蒜 10克
- 盐 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备食材；油菜洗净泥沙；蟹味菇摘成小条
2. 锅中加一点盐煮开水，加入小油菜烫软后捞出沥水备用
3. 大蒜切片
4. 热锅凉油，加入蒜片炒出香味
5. 加入蟹味菇炒熟
6. 加入油菜和少许盐调味
7. 翻炒均匀即可
8. 成品
9. 成品

## 💡 大廚美味秘訣 / Chef's Tips
- 蟹味菇在炒至过程中自然会出水，所以烹饪时不用额外加水了哦

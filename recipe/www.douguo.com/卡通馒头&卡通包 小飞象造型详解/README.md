## 🌿 食材及佐料清單 / Ingredients
- 中筋面粉 200克
- 温水 105克
- 酵母 2克
- 细砂糖 10克
- 蝶豆花粉/果蔬粉 适量
- 黑可可粉 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 面粉、温水、酵母与细砂糖揉成光滑细腻、无气孔的白色基础面团。
2. 分出部分面团加入蝶豆花粉揉成蓝色（身体和大耳朵），分小块揉成粉色（内耳和帽子）与黄色。
3. 取大块蓝色面团滚圆作为小飞象头部与身体。
4. 擀出两片扇形蓝色面片做大耳朵，贴上粉色面片作耳心，用清水粘贴在头部两侧。
5. 捏出长鼻子与黄色小帽子固定在头顶，用黑可可粉面团点缀出萌萌的大眼睛。
6. 整形完成后放入蒸屉醒发至1.5倍大（轻按缓慢回弹）。
7. 冷水上锅大火烧开，中火蒸15分钟，关火焖5分钟后再揭盖。

## 💡 大廚美味秘訣 / Chef's Tips
- 揉面一定要排净内部空气直至切面完全无气孔，蒸出来的卡通造型才会光滑如婴儿肌。

# 番茄炒花菜

![番茄炒花菜](cover.jpg)

- **料理名稱**：番茄炒花菜
- **原始標題**：番茄炒花菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2336727.html)

## 🌿 食材及佐料清單 / Ingredients
- 白花菜 半颗
- 熟番茄 2个
- 盐 1茶匙
- 白糖 半勺
- 生抽 1勺
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 花菜掰成小朵，淡盐水浸泡10分钟冲净；番茄去皮切小块。
2. 沸水锅中加少许盐，下花菜焯水1.5分钟至半熟捞出沥干。
3. 热锅下油，倒入番茄块翻炒至软烂出浓郁红汁。
4. 加入焯好水的花菜翻炒均匀，让花菜充分吸收番茄红汁。
5. 加入生抽、白糖和盐调味，大火翻炒2分钟入味即可出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 花菜提前焯水能缩短翻炒时间并保持爽脆口感，番茄炒透出汁包裹花菜更入味。

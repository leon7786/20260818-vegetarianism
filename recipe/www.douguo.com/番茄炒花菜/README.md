# 番茄炒花菜

![番茄炒花菜](cover.jpg)

- **料理名稱**：番茄炒花菜
- **原始標題**：番茄炒花菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2336727.html)

## 🌿 食材及佐料清單 / Ingredients
- 番茄 1个
- 花菜 适量
- 蒜末 少许
- 调味汁 适量
- 食盐 少许
- 食用油 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 把花菜掰成小朵，清洗干净，用盐水泡十分钟再冲洗干净，番茄去皮切成小块。
2. 烧一锅水，水开之后，倒入花菜焯水，煮一分钟捞出沥干水分。
3. 起锅下油，先放蒜末煸香，再倒入番茄翻炒出沙，翻炒的过程中，用锅铲将番茄铲碎。
4. 倒入花菜，放食盐，快速的翻炒均匀。
5. 简单又下美味的番茄炒花菜就做好啦，用来下饭特别的美味，孩子的最爱。
6. 出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 1、花菜掰成小朵之后，加盐水浸泡十分钟可以起到杀虫杀菌的作用。

2、番茄先在顶部画十字，再烧一些开水烫一下，把外皮撕掉。这样吃起来更美味。

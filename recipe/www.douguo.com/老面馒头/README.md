# 老面馒头

## 🌿 食材及佐料清單 / Ingredients
- 中筋面粉 500克
- 老面种 100克
- 食用碱面 1-2克
- 温水 240克
- 白糖 10克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 老面种用温水化开，加入面粉和白糖揉成均匀面团，盖保鲜膜发酵至蜂窝密集（发酵充足）。
2. 取食用碱面用少许温水化开，一点点揉入发酵好的面团中（闻味道微带麦香无酸味即为碱度适中）。
3. 案板撒干面粉，用力反复揉搓排气戗面，揉至面团光滑细腻如丝绸。
4. 搓成长条分成均匀面剂，逐个揉圆整理成高庄馒头生胚。
5. 放入蒸屉二次醒发15-20分钟至体积稍膨大。
6. 冷水上锅，水开后中大火蒸20分钟，关火焖5分钟后再开锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 戗面揉透是老面馒头层次丰富、麦香浓郁、越嚼越香的精髓。

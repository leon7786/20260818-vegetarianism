- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2360460.html)

## 🌿 食材及佐料清單 / Ingredients
- 酵母
- 面粉 100克
- 水 100克
- 酵母 2克
- 主面团
- 面粉 310克
- 水 100克
- 酵母 3克
- 白糖 40克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 提前把酵头的材料混合，放冰箱冷藏13个小时以上（不超72小时）。
2. 发好的酵头和主面团的材料混合。
3. 抓成团。
4. 揉成光滑面团，密封发酵。
5. 发至两倍大取出。
6. 加适量面粉搓成长条。
7. 揪出小剂子。
8. 揉圆。
9. 冷水上锅，盖上锅盖醒发2倍大。
10. 中大火15分钟左右即可。

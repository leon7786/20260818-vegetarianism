## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 白色面团滚圆，40g左右
2. 橘色擀薄，直径10cm左右，中间挖洞，直径4cm左右
3. 绿色擀成长条，用刀切出如图锯齿状
4. 橘色包裹住白色面团，绿色围一圈，贴紧 ，白色和红色做耳朵
5. 水滴状白色做手
6. 黑色和红色做好五官和腮红
7. 手脚贴合就完成啦
8. 这个菜谱只是教了造型，多包涵

# 清炒小白菜

![清炒小白菜](cover.jpg)

- **難易度 / Difficulty**：切墩(初级)

## 📝 料理故事與簡介 / Story & Introduction
> 小白菜是常见的蔬菜种类，它的茎叶可以食用，味道鲜美，有甜甜的味道，小白菜是蔬菜里面维生素和纤维素含量最丰富的蔬菜。对我们来说富有营养性，小白菜具有清热去火，润肠道的作用。

## 🌿 食材及佐料清單 / Ingredients
- 小白菜：1把（约600克）
- 小葱：1根
- 姜：少许
- 蒜：3瓣
- 盐：2克
- 味极鲜：适量
- 鸡精：1克
- 小尖椒：1根
- 淀粉：少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 小白菜一把。
2. 小白菜清洗干净，切三段。
3. 葱切小段，姜切末，蒜切碎，装盘备用。
4. 热锅起油油温五成热放入葱姜蒜一起爆香。
5. 放入小白菜翻炒，加入盐，味极鲜，勾薄芡，快速翻炒均匀至汤汁冒泡，放入鸡精翻炒均匀即可出锅。
6. 撒上尖椒碎，绿叶丛中一点红，是不是很诱人啊！
7. 成品。

## 💡 大廚美味秘訣 / Chef's Tips
- 在做这道菜的时候，翻炒速度一定要快。

## 🌿 食材及佐料清單 / Ingredients
- 大米 100克
- 黑米 30克
- 红米 30克
- 燕麦米 30克
- 糙米 30克
- 清水 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 将黑米、红米、糙米、燕麦米提前浸泡2-3小时以软化谷皮。
2. 大米淘洗干净，与泡好的杂粮粗粮混合拌匀。
3. 放入电饭煲内胆中，按粗粮饭水位线加入清水（约粗粮总量1.3-1.5倍）。
4. 开启电饭煲“杂粮饭”或“精煮饭”模式烹饪。
5. 煮好后保温焖10分钟，开盖用饭勺翻拌散汽即可食用。

## 💡 大廚美味秘訣 / Chef's Tips
- 杂粮提前浸泡可以让粗粮与大米同时熟透，米饭软糯有嚼劲，膳食纤维丰富。

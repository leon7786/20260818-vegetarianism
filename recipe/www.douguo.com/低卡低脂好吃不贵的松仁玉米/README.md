## 📝 料理故事與簡介 / Story & Introduction
> 松仁玉米的功效结合了松仁和玉米两种食材的营养价值，在中医学上也是一道开胃健脾的 美食， 玉米含有丰富的矿物质、蛋白质和脂肪，食用之后不仅能促进食欲，预防心脑血管等疾病，还有提神醒脑，健胃利尿等作用。松仁同样有健脑益智的作用，与玉米混合可以令大脑更加聪明，孩童可以多吃。松仁，玉米，乳瓜用植物油进行烹饪，可以促进人体对维生素E更好的吸收。

## 🌿 食材及佐料清單 / Ingredients
- 熟玉米粒：200克
- 熟松仁：20克
- 胡萝卜：半根
- 乳瓜：半根
- 油：10克
- 葱花：5克
- 糖：10克
- 盐：1克
- 淀粉：1勺
- 清水：适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 所有配料洗净切好备用
2. 热锅放油放入葱花爆香
3. 放入胡萝卜丁翻炒变色
4. 放入乳瓜继续翻炒均匀
5. 放入熟玉米粒继续翻炒均匀
6. 放入白糖，盐，翻炒均匀后，水和淀粉搅拌均匀后撒入锅中少许翻炒均匀即可。

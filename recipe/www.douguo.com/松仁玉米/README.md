![松仁玉米](cover.jpg)

- **料理名稱**：松仁玉米
- **原始標題**：松仁玉米
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：米食料理
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2411636.html)

## 🌿 食材及佐料清單 / Ingredients
- 玉米粒 一盘
- 松子仁 一把
- 盐 1茶匙
- 糖 小半碗
- 油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 热锅凉油先炒糖
2. 糖全部融化变成淡黄色。
3. 加入熟玉米粒和松仁翻炒均匀。加盐
4. 加入少量水炒两分钟左右
5. 可以用少量水淀粉勾芡。(也可以不用。)
6. 成品

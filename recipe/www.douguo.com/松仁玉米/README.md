## 🌿 食材及佐料清單 / Ingredients
- 甜玉米粒 250克
- 熟松子仁 30克
- 青豆/胡萝卜丁 30克
- 白糖 1勺
- 盐 半茶匙
- 水淀粉 少许
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 甜玉米粒洗净沥干，青豆和胡萝卜丁洗净备用；松子仁小火烘焙出香味。
2. 锅中烧开水，下入玉米粒、胡萝卜丁和青豆焯水1.5分钟捞出沥干水分。
3. 炒锅烧热倒少许油，下入焯好水的玉米粒、胡萝卜丁和青豆大火翻炒1分钟。
4. 加入白糖和少许食盐翻炒均匀，淋入薄水淀粉快速翻炒裹匀亮泽。
5. 关火前撒入香脆松子仁翻拌均匀，出锅装盘。

## 💡 大廚美味秘訣 / Chef's Tips
- 松子仁最后一步放入能保持酥脆不回软；甜玉米选用鲜甜多汁的品种口感最佳。

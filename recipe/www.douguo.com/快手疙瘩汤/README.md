# 快手疙瘩汤

- **料理分類 / Category**：湯品羹湯

## 🌿 食材及佐料清單 / Ingredients
- 西红柿 1个
- 鸡蛋 2个
- 盐 2勺
- 油 一勺
- 番茄酱 1勺
- 葱花(或香菜) 适量
- 面粉 1.5杯

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西红柿切丁
2. 鸡蛋加一点点盐，打散
3. 葱花或香菜末切好
4. 面粉放到稍微大点的盆里，加一点点盐
5. 打好的鸡蛋液，一点点加入到面粉盆里，一边加，一边快速搅拌，成小疙瘩
6. 热锅冷油
7. 油温约5成热，下西红柿快速翻炒，至变色
8. 加番茄酱
9. 炒至软烂，变红。西红柿如果很酸，可以加一点点糖。喜欢还可以加一点生抽
10. 加入冷水
11. 煮开
12. 一点点加入步骤5的疙瘩，一边加，一边快速扒拉开，不要粘到一起
13. 加入盐，不要太咸，记得鸡蛋和面粉里面已经加过的盐的分量。
再开锅时打入剩余蛋液，快速搅开
14. 出锅时撒一点点葱花或香菜末即可

## 💡 大廚美味秘訣 / Chef's Tips
- 鸡蛋液不要一次加入，多次，少量

# 快手疙瘩汤

![快手疙瘩汤](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：快手疙瘩汤
- **原始標題**：快手疙瘩汤
- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/3020308.html)

## 🌿 食材及佐料清單 / Ingredients
- 面粉 120克
- 西红柿 1个
- 鸡蛋 1个
- 菠菜 2棵
- 生抽 1勺
- 盐 适量
- 香油 几滴
- 白胡椒粉 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西红柿切小丁；菠菜焯水洗净切碎；鸡蛋打散。
2. 面粉装碗，用漏勺淋极细水滴，边滴边快速摇晃搅拌成细腻珍珠小面疙瘩。
3. 锅中热油爆香番茄炒出浓汤，加足量水烧沸。
4. 均匀撒入面疙瘩搅拌煮2-3分钟。
5. 淋入蛋液成蛋花，加入菠菜碎、生抽、盐、白胡椒粉调味，淋香油出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 菠菜提前焯水去除草酸；面疙瘩分次撒入避免黏连。

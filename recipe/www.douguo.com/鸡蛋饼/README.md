# 鸡蛋饼

![鸡蛋饼](cover.jpg)

- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2779351.html)

## 🌿 食材及佐料清單 / Ingredients
- 面粉 100克
- 鸡蛋 2个
- 清水 150ml
- 葱花 适量
- 盐 半茶匙
- 植物油 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 面粉中加入清水搅拌成细腻无颗粒的面糊。
2. 打入2个鸡蛋，加入盐和葱花顺时针充分搅拌均匀。
3. 平底锅刷薄油预热，舀入一勺蛋面糊轻轻转动锅子摊成薄圆饼。
4. 中小火煎至表面凝固变色，翻面继续煎至两面金黄微焦香。
5. 出锅卷起切段即可趁热食用。

## 💡 大廚美味秘訣 / Chef's Tips
- 面糊调至可流动的稀稠度，摊出的鸡蛋饼薄嫩松软，香葱提味。

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 40g面团上面做一个熊鼻子
2. 红色擀薄，4个圆形叠加，如图，8mm左右直径圆形
3. 中间切开
4. 玫瑰花粘合在熊头
5. 粘合满的状态
6. 【熊身体】水滴状 每3g左右面团，4个水滴做熊胳膊和腿
7. 身体是60g面团，推高，粘合腿和胳膊后，粘满玫瑰花
8. 黄色薄片 2个三角形做蝴蝶结
9. 蝴蝶结完成
10. 发酵，蒸制

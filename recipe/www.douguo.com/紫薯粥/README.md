# 紫薯粥

## 🌿 食材及佐料清單 / Ingredients
- 紫薯 一根
- 大米 80克
- 清水 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 大米淘洗干净。
2. 将淘洗干净的大米倒入破壁机搅拌杯内。
3. 加入600毫升的清水。
4. 将搅拌杯放置于主机上，插上电源，选择熬粥功能，按下启动按钮，先将大米煮十五分钟。
5. 利用煮粥的时间将紫薯洗净，削皮，切成小丁。
6. 粥煮至十五分钟时，从投料口把紫薯丁倒入搅拌杯内，煮至熬粥时间结束即可。
7. 一碗有颜值又营养美味的紫薯粥做好了。早餐来一碗热腾腾香喷喷的暖胃粥最恰当不过了。

## 💡 大廚美味秘訣 / Chef's Tips
- 当然也可以直接在煤气灶上煮的，但是用破壁机实在太方便了，不用看火，只需准备材料就可以。如果豆浆机有熬粥功能的话也一样可以哦！

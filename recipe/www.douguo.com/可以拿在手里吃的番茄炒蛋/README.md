# 可以拿在手里吃的番茄炒蛋

## 🌿 食材及佐料清單 / Ingredients
- 番茄 2个
- 鸡蛋 4个
- 白糖 1勺
- 生抽 1勺
- 盐 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 把一个番茄顶部切一刀，当做盖子。番茄瓤挖出来备用。
另一个番茄切丁备用。
2. 鸡蛋打碗里，放入白糖和生抽，一起打散。
3. 热锅，放油，倒入蛋液，翻炒至两面金黄。
4. 放入切成丁的番茄，翻炒，放点水，盖上锅盖，中小火焖几分钟。
5. 试下咸淡，如果太淡，再放点盐或者生抽调味。刚刚好的话，就可以盛出来了。
6. 在挖空的番茄里，放入炒好的番茄炒蛋，可以拿在手里吃的，是不是很有趣。
7. 成品。
8. 成品。
9. 成品。

## 💡 大廚美味秘訣 / Chef's Tips
- 1，炒鸡蛋的油，可以比平常炒菜的时候多一些，油也要稍微热一些，这样炒出来的鸡蛋，量大且香。
2，选的番茄不能太软，不要太大。
3，我就装一个吃，其他的装盘，大家一起吃了

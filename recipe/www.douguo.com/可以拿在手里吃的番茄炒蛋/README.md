# 可以拿在手里吃的番茄炒蛋

- **素食流派 / Diet**：蛋素 Ovo-Vegetarian

## 🌿 食材及佐料清單 / Ingredients
- 吐司片/卷饼皮 2张
- 番茄 1个
- 鸡蛋 2个
- 生抽 1勺
- 盐 少许
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 番茄切碎丁；鸡蛋加少许盐打散炒熟盛出。
2. 锅中少许油下番茄丁炒至浓稠收干多余水分，加入炒蛋和生抽拌匀成较干爽的番茄炒蛋馅。
3. 吐司片切去边角压薄或准备卷饼皮。
4. 将番茄炒蛋均匀铺在饼皮中央，卷紧或用吐司模具压边封口。
5. 放入平底锅或三明治机微煎定型至外皮酥脆。
6. 对半切开即可手拿着轻松享用，浓郁多汁不漏汤。

## 💡 大廚美味秘訣 / Chef's Tips
- 馅料水分需收干，包入吐司或饼皮中便于携带和手拿食用。

## 🌿 食材及佐料清單 / Ingredients
- 鲜银耳：半朵
- 南瓜：1块
- 红枣：10个
- 冰糖：适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备食材：鲜银耳洗净撕成小块备用，南瓜去皮切块备用，红枣去核备用
2. 把银耳，南瓜，红枣一起放入锅里
3. 加入足量的水，大火烧开，转小火煮30分钟就可以了
4. 加入适量冰糖调味就可以出锅啦
5. 满满的胶原蛋白哦，也让老爸养养皮肤哈
6. 成品

## 💡 大廚美味秘訣 / Chef's Tips
- 1、没有鲜银耳的话，可以用干银耳提前浸泡待用，用干银耳的话，煮的时间要稍微延长一下，煮到出胶就可以。
2、冰糖的量，按自己的口味来调整哦！
3、红枣记得去核哦，不然容易上火！

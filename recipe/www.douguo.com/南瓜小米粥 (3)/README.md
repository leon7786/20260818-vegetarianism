# 南瓜小米粥

- **料理名稱**：南瓜小米粥
- **原始標題**：南瓜小米粥
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：米食料理
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2300567.html)

## 🌿 食材及佐料清單 / Ingredients
- 小米 大半杯
- 南瓜 一块
- 大米 小半杯
- 红枣 16颗
- 冰糖 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 材料大集合哈
2. 准备食材前，先用砂锅烧半锅水备着 南瓜去皮切小块哈
3. 除冰糖外的所有所有食材清洗干净，放进烧开水的砂锅中
4. 开小火熬煮30分钟
5. 出锅前，按个人喜好调入少许冰糖，可以美美的享用啦

## 💡 大廚美味秘訣 / Chef's Tips
- 1、冰糖可加可不加的哦，随个人口味哦！
2、我自己喜欢用砂锅煮，砂锅煮出来的粥，吃起来特别的香哈！也可以前一晚用电饭煲预约好，隔天早上就可以吃了，简单快捷的哦！

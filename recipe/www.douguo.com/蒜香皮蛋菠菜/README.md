# 蒜香皮蛋菠菜

## 🌿 食材及佐料清單 / Ingredients
- 菠菜 200克
- 胡萝卜 50克
- 皮蛋 2个
- 蒜瓣 35克
- 盐 2克
- 鸡精 2克
- 香油 适量
- 水淀粉 1汤勺

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 胡萝卜洗净切薄片备用。
2. 皮蛋切块备用，我用的是自家做的鸡蛋皮蛋，当然鸭蛋做的皮蛋更好或者是松花蛋。话说皮蛋和松花蛋是一个东西吗？
3. 蒜瓣拍碎备用。
4. 菠菜洗净后切成段儿，我的菠菜买的大了，我切了三段，小菠菜切两段就行了。
5. 锅中倒入适量水，再放入一茶匙盐，一汤勺食用油，拌匀后大火烧开，放入菠菜断生后捞出。
6. 捞出的菠菜沥干水份，均匀的铺在盘中。
7. 另起锅，倒入适量油，大火烧热后放入蒜瓣，爆香。
8. 再放入胡萝卜片，炒匀炒香。
9. 再放入皮蛋块，炒匀。
10. 炒匀后倒入一大碗清水。
11. 加入盐，鸡精拌匀，煮至食材全部熟透。出锅前倒入一汤勺水淀粉，滴入几滴香油拌匀，待汤汁有粘稠感后关火。
12. 将煮好的菜肴全部浇在铺好的菠菜上即可。
13. 做完后我觉得皮蛋再多一个会更过瘾，可惜没有存货了。

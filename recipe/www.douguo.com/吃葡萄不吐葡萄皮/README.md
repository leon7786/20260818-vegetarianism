# 吃葡萄不吐葡萄皮

## 🌿 食材及佐料清單 / Ingredients
- 紫色面团材料：
- 中筋面粉 150克
- 清水 75克
- 自制紫薯粉 8克
- 玉米油 5克
- 白砂糖 5克
- 酵母 1.5克
- 绿色面团材料：
- 中筋面粉 40克
- 菠菜粉 1克
- 清水 20克
- 玉米油 1.5克
- 酵母 0.4克
- 白砂糖 1克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 紫色和绿色的材料分成揉成光滑的面团，松弛15分钟。
2. 紫色面团搓成长条，天气热未操作的面团可以放入冰箱冷藏室，以免发酵过快。
3. 切成小剂子。
4. 搓成圆形。
5. 在硅油纸上排好，如图，排的时候可以稍微抹些水，放一边备用。
6. 绿色面团分出15克，切成3份。
7. 搓成小长条。
8. 剩下的分割成3等份。
9. 分别搓成圆形。
10. 擀开，如图。
11. 用筷子从中间稍微夹下。
12. 压出纹路。
13. 用刮板稍微顶下边边。
14. 压好的样子，再把两片叶子从中间切开。
15. 把叶子放上。
16. 再把小长条放在两片叶子中间底下。
17. 放入蒸笼里，锅中倒入适量热水，放上蒸笼松弛15分钟，大火烧开，转中火蒸12分钟，关火后焖2分钟再取出。

# 番茄炒蛋

![番茄炒蛋](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：番茄炒蛋
- **原始標題**：番茄炒蛋
- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2298919.html)

## 🌿 食材及佐料清單 / Ingredients
- 新鲜鸡蛋 3个
- 成熟番茄 2个
- 盐 1茶匙
- 白糖 1勺
- 生抽 半勺
- 食用油 适量
- 葱花 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 番茄洗净切小块；鸡蛋打散加入少许盐搅匀。
2. 热锅宽油，油热倒入蛋液快速划散成大块，凝固盛出备用。
3. 锅留底油，下入番茄块大火煸炒，用锅铲稍压挤出丰富红汤。
4. 加入白糖、生抽和少许盐调味炒匀。
5. 倒入炒好的鸡蛋块翻炒15秒裹匀番茄浓汁，撒入葱花出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 糖是番茄炒蛋的点睛之笔，中和酸度提鲜；鸡蛋不要炒太老，保持嫩滑。

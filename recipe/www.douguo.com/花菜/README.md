## 🌿 食材及佐料清單 / Ingredients
- 花菜 500克
- 小米椒 6个
- 蒜子 5瓣
- 香葱 4根
- 生抽 2勺
- 白糖 少许
- 蚝油 1勺
- 水淀粉 2勺
- 油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 花菜用流水冲洗干净，掰成小块放入淡盐水中浸泡十分钟，这样可以泡出里边的小虫和残留的农药，然后再冲洗干净
2. 期间可以把小米椒、蒜、葱切一下
3. 再把生抽，蚝油，白糖，水淀粉拌匀成碗汁备用
4. 锅里做水烧开，下花菜焯水
5. 时间不用太长，看的颜色变深了，赶紧捞出来
6. 然后把它过一遍凉开水沥水备用，这样子处理一下更加的脆囗
7. 热锅凉油煸香葱白、蒜片、小米椒，接着倒入花菜，改大火翻炒均匀
8. 花菜基本上已经熟了，时间不用炒太久，倒入提前混合好的碗汁，如果觉得颜色太浅了，可以添加少许老抽哈
9. 出锅前加入葱叶
10. 简简单单几分钟，一道好吃又味美的家常花菜就做好啦

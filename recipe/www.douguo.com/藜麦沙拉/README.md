# 藜麦沙拉

![藜麦沙拉](cover.jpg)

- **料理名稱**：藜麦沙拉
- **原始標題**：藜麦沙拉
- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：涼拌前菜 / 輕食
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2338867.html)

## 🌿 食材及佐料清單 / Ingredients
- 藜麦 20克
- 芦笋 4根
- 胡萝卜 1截
- 紫薯 2个
- 鹌鹑蛋 4个
- 坚果 50克
- 海盐 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 藜麦冲洗两遍，装在容器里，用水浸泡2小时。
2. 锅中放水煮开，放入泡好的藜麦，中大火煮15分钟，煮熟后捞出沥干备用。
3. 芦笋和胡萝卜洗净，切成块，用沸水烫熟。
4. 紫薯蒸熟后切成小块。鹌鹑蛋蒸熟后切半切开。
5. 食材全部处理好以后装进大碗里，撒入适量海盐，拌匀即可。
6. 成品

# 藜麦沙拉

![藜麦沙拉](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：藜麦沙拉
- **原始標題**：藜麦沙拉
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2338867.html)

## 🌿 食材及佐料清單 / Ingredients
- 三色藜麦 50克
- 圣女果 6个
- 黄瓜 半根
- 玉米粒 30克
- 生菜 适量
- 橄榄油 1勺
- 柠檬汁 1勺
- 黑胡椒 适量
- 盐 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 三色藜麦洗净，加水煮15分钟至出小芽圈，捞出沥干放凉。
2. 玉米粒焯水煮熟捞出沥干；圣女果对半切开，黄瓜切丁，生菜撕小块。
3. 橄榄油、柠檬汁、盐和现磨黑胡椒碎拌匀调制成油醋汁。
4. 将生菜、黄瓜、玉米粒、圣女果和放凉的藜麦放入大沙拉碗中。
5. 淋入油醋汁充分翻拌均匀即可享用。

## 💡 大廚美味秘訣 / Chef's Tips
- 藜麦煮到露出白色胚芽圈口感最好；轻食减脂，富含优质植物蛋白与膳食纤维。

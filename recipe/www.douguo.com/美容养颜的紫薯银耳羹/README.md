# 美容养颜的紫薯银耳羹

## 🌿 食材及佐料清單 / Ingredients
- 银耳 半朵
- 紫薯 1个
- 冰糖 适量
- 枸杞 10粒
- 清水 1000ml

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 银耳提前泡发，去蒂洗净撕成细碎小朵。
2. 砂锅中加足量清水，放入银耳大火煮沸转小火慢炖35分钟至汤汁浓稠出胶。
3. 紫薯去皮切成小丁，加入银耳锅中继续炖煮15分钟至紫薯软烂。
4. 加入适量冰糖和枸杞，搅拌至冰糖融化煮2分钟。
5. 羹汤呈现浓郁浪漫的梦幻紫色，盛出即可享用。

## 💡 大廚美味秘訣 / Chef's Tips
- 银耳撕碎先炖出满满胶质再加紫薯，避免紫薯过早糊锅，口感更加细腻香滑。

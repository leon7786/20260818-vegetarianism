# 凉拌西兰花

- **料理名稱**：凉拌西兰花
- **原始標題**：凉拌西兰花
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2419276.html)

## 🌿 食材及佐料清單 / Ingredients
- 西兰花 1朵
- 熟白芝麻 适量
- 生抽 2勺
- 香醋 1勺
- 香油 1勺
- 白糖 少许
- 盐 半茶匙
- 辣椒油(可选) 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西兰花剪小朵，淡盐水浸泡冲洗干净。
2. 锅中水烧开加盐和油，下西兰花焯水1分钟断生捞出过冰水沥干。
3. 碗中调入生抽、香醋、香油、糖、盐和白芝麻拌匀成爽口料汁。
4. 将料汁淋在沥干的西兰花上充分抓拌均匀入味。
5. 装盘即可食用，清爽脆嫩解腻。

## 💡 大廚美味秘訣 / Chef's Tips
- 焯水过冰水是保持西兰花清脆脆绿的灵魂步骤。

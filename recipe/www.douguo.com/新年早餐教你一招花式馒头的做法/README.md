# 新年早餐教你一招花式馒头

## 🌿 食材及佐料清單 / Ingredients
- 大馒头 2个
- 火腿片 2片
- 芝士碎 适量
- 香葱 2根
- 鸡蛋 1个

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备好食材
2. 馒头划格子
3. 嵌入芝士碎
4. 嵌入火腿片碎末和香葱抹
5. 刷上蛋液，撒上黑胡椒粉
6. 送入烤箱150℃10分钟
7. 取出装盘，配上一杯咖啡。
8. 开吃吧

## 💡 大廚美味秘訣 / Chef's Tips
- 每个烤箱温度控制不一样，具体根据自家的烤箱温度而定。

# 韭菜炒鸡蛋这样做，清清爽爽，不油不腻

## 🌿 食材及佐料清單 / Ingredients
- [双人份用量] ：
- 韭菜 半捆
- 土鸡蛋 6个
- 鸡汁 一汤匙
- 原味鲜 一汤匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 韭菜半捆（借个味儿而已，熊熊还是爱吃鸡蛋）；走地鸡蛋6个（单人份减半）
2. 蛋液里加一汤匙鸡汁，半汤匙原味鲜，打散备用；韭菜切小段，备用。
3. 热锅热油，鸡蛋炒成大块儿，盛出备用（走地鸡蛋的颜色就是好好看）
4. 趁着锅热倒入韭菜翻炒（不用放油）
5. 韭菜蔫儿了之后，倒入半汤匙原味鲜，炒匀
6. 倒入鸡蛋一起翻炒，想要多大的块儿自己炒碎就好
7. 韭菜不出水，清清爽爽；不加一滴盐，清清淡淡却鲜鲜甜甜，更好的感受韭菜的鲜味儿和鸡蛋的香味儿。
8. 即便这么清淡，却也超级下饭

# 醋溜包菜

- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2422441.html)

## 🌿 食材及佐料清單 / Ingredients
- 包菜 半颗
- 干辣椒 3个
- 花椒 10粒
- 香醋/陈醋 2勺
- 生抽 1勺
- 白糖 半勺
- 盐 适量
- 食用油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 包菜用手撕成均匀适口的小块，洗净后务必彻底沥干水分（手撕比刀切口感更好）。
2. 碗中加入香醋2勺、生抽1勺、白糖半勺、盐少许，调匀成醋溜料汁备用。
3. 热锅下油，油温5成热放入花椒和剪段的干辣椒小火煸出香辣味。
4. 调大火，下入手撕包菜快速翻炒至叶片稍变软呈油亮半透明状。
5. 顺着锅边淋入调好的醋溜汁，大火快速翻炒均匀，激发出浓郁醋香即可关火出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 包菜炒前一定要控干水分，全程保持大火快炒，沿锅边淋醋才能爆出诱人镬气。

# 醋溜包菜

![醋溜包菜](cover.jpg)

- **料理名稱**：醋溜包菜
- **原始標題**：醋溜包菜
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：烘焙麵點 / 點心
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2422441.html)

## 🌿 食材及佐料清單 / Ingredients
- 包菜 半个
- 醋 1勺
- 生抽 2勺
- 蚝油 1勺
- 蒜头 1瓣
- 干辣椒 半个
- 油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 包菜洗净，掰成小瓣
2. 油锅烧热，建议油稍微多一点。放入红辣椒和蒜瓣炒香
3. 放入包菜翻炒至变色。放入两勺生抽，约30ml，一勺醋15ml
4. 再放1勺蚝油。翻炒均匀。
5. 成了。
6. 有点酸酸辣辣的，很开胃下饭。

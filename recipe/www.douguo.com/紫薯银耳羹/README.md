# 紫薯银耳羹

![紫薯银耳羹](cover.jpg)

- **料理名稱**：紫薯银耳羹
- **原始標題**：紫薯银耳羹
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：湯品羹湯
- **難易度 / Difficulty**：切墩(初级)
- **烹飪時間 / Cooking Time**：10~30分钟
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2318563.html)

## 📝 料理故事與簡介 / Story & Introduction
> 一早娃说要喝银耳羹，刚好冰箱还有半朵鲜银耳，再加个紫薯，娃说这颜色好漂亮呀！

## 🌿 食材及佐料清單 / Ingredients
- 鲜银耳：半朵
- 紫薯：1个
- 冰糖：适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鲜银耳切去根部，洗净撕成小块备用
2. 紫薯去皮切成丁备用
3. 把紫薯和银耳一起放进锅里，加入适量的水，煮至银耳软糯，紫薯熟了就可以
4. 出锅前加入适量冰糖调味即可
5. 满满的胶原蛋白哦！
6. 成品

## 💡 大廚美味秘訣 / Chef's Tips
- 1、用鲜银耳来煮的话，很容易就出胶了。我水开后煮了15分钟左右，就出胶了，紫薯也熟了。
2、冰糖的量根据自己的口味来调整哦！

# 海苔厚蛋烧

## 🌿 食材及佐料清單 / Ingredients
- 鸡蛋 3个
- 寿司海苔 1张
- 牛奶 2勺
- 盐 半茶匙
- 白糖 1/3茶匙
- 食用油 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鸡蛋打散，加入牛奶、盐、白糖搅拌均匀过筛。
2. 玉子烧锅抹薄油烧热，倒入一层薄蛋液摇匀。
3. 蛋液半凝固时铺上一条裁剪好的海苔片，从上往下卷起推至锅顶。
4. 再次抹油倒入第二层蛋液（抬起蛋卷让蛋液流至下方），半凝固后继续卷起。
5. 重复操作卷成厚厚金黄蛋卷，四面微煎定型。
6. 出锅切成厚片摆盘即可。

## 💡 大廚美味秘訣 / Chef's Tips
- 全程中小火慢煎，蛋液半凝固状态卷起不易散开且层次紧实嫩滑。

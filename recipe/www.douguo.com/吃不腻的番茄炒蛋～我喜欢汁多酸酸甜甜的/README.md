## 🌿 食材及佐料清單 / Ingredients
- 鸡蛋 2个
- 番茄 1个
- 生抽 适量
- 糖 少许
- 香葱 适量
- 盐 适量
- 五香粉 少许
- 调料水 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 番茄去皮切块
2. 鸡蛋加调料水打散，炒嫩点盛出备用。
3. 番茄加生抽、五香粉、糖炒软，再加少许调料水炒至浓汁，然后放入炒好的鸡蛋。
4. 翻拌均匀，炒开，尝咸淡调盐，撒入香葱出锅。
5. 嗯，不错！
6. 开动啦！

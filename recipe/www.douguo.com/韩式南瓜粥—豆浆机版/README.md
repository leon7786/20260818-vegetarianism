# 韩式南瓜粥—豆浆机版

## 🌿 食材及佐料清單 / Ingredients
- 南瓜 250g
- 大米 40g
- 糯米 50g
- 水 500g
- 冰糖 4个

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 上次去吃韩式料理，我老公说南瓜粥真好喝，我说我以前给你做过呀，他竟然说不记得，真是花了钱的才觉的好吃！早上做一次让他记忆深刻

准备南瓜一个 我用的板栗南瓜，糯米和大米洗干净提前一晚上泡水
2. 南瓜洗干净去皮全部切块
3. 豆浆机中加入南瓜 米 和500g水 
这几个合起来刚好在1000ml刻度线处
4. 加入中等大小的3-4颗冰糖
5. 开启豆浆机米糊模式 结束即可饮用
6. 按照方子量做出来的南瓜粥粘稠度刚好和外面卖的一样！肥肠好喝呢
快交作业哦

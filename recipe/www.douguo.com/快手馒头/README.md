# 快手馒头

- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜

## 🌿 食材及佐料清單 / Ingredients
- 全麦自发粉 300克
- 温水 160克
- 细砂糖 5克(可选)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 全麦自发粉中缓缓加入温水，用筷子搅拌成絮状。
2. 下手揉成光滑细腻的面团，揉面5-8分钟直至面光盆光手光。
3. 揉好的面团直接搓成长条，切分成均匀的小馒头剂子（一次发酵法更快捷）。
4. 垫上油纸摆入蒸屉，盖上锅盖温水发酵25-30分钟至体积明显变大、轻按回弹。
5. 开大火烧开水，转中火蒸15分钟，关火虚蒸3分钟出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 使用全麦自发粉省去调配酵母步骤，一次发酵省时省力，麦香浓郁低脂健康。

# 小麦仁豆浆西米露

## 🌿 食材及佐料清單 / Ingredients
- 西米 25g
- 干黄豆 一杯（豆浆机量杯）
- 小麦仁 半杯（豆浆机量杯）
- 红枣片 适量
- 葡萄干 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 干黄豆提前一晚泡发，不泡也可以，但是泡发过打得更细腻，小麦仁洗净，与黄豆一起放入豆浆机里，加水至最高水位线，选择五谷豆浆功能。
2. 打豆浆大约需要25-30分钟，这时可以煮西米，煮西米不难，但需要耐心。锅中倒入大半锅清水，煮开后倒入西米，中小火，不停搅拌，并逐量加入清水，一直煮到西米中心有小小的白点，关火，盖盖子，闷5分钟，西米就完全透明了！
3. 煮好西米后，捞出泡入凉开水中过凉，可以保持Q弹，等豆浆打好，就可以将西米和豆浆混合了。
4. 混合好西米和豆浆后，还可以加上一些红枣片，葡萄干等，豆渣非常细腻，无需过滤，豆香满满，Q弹顺滑！
5. 如果喜欢吃凉的，可以放入冰箱冰镇一会哦！
6. 热食，也是非常不错的早餐之选！

## 💡 大廚美味秘訣 / Chef's Tips
- 1.煮西米要勤搅拌，不然会团在一起哦！
2.此方子无糖，喜欢吃甜味，可以在豆浆打好后，加入白糖调味！

# 平价“燕窝”银耳雪梨汤

![平价“燕窝”银耳雪梨汤](cover.jpg)

- **料理名稱**：平价“燕窝”银耳雪梨汤
- **原始標題**：平价“燕窝”银耳雪梨汤
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：湯品羹湯
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2531785.html)

## 🌿 食材及佐料清單 / Ingredients
- 银耳 适量
- 红枣 7颗
- 冰糖 20克
- 雪梨 1个

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 依配方表准备材料，银耳提前浸泡至少2小时，洗净，去除底部黄色部份，备用。
2. 雪梨去皮切丁。
3. 梨丁、银耳、红枣、冰糖（不喜甜的小伙伴可以不加，梨和红枣自身有甜味）放入锅中，加适量的水，没过所有食材即可。
4. 先大火力煮开，转中小火力。
5. 半开盖炖煮半小时左右。
6. 直到炖煮出胶质即可。
7. 趁热吃，滋润你的好肌肤。
8. 好吃
9. 银耳红枣雪梨汤

## 💡 大廚美味秘訣 / Chef's Tips
- 1、银耳一定要提前泡发，这样可以缩短炖煮的时间。
2、煮的时间只是参考，以银耳的状态为准，只要煮出胶质就可以了，这样口感才是软滑甜润的。
3、不喜甜的小伙伴冰糖可以不加。

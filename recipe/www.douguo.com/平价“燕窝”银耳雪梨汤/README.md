# 平价“燕窝”银耳雪梨汤

## 🌿 食材及佐料清單 / Ingredients
- 银耳 半朵
- 雪梨 1个
- 枸杞 15粒
- 红枣 5颗
- 冰糖 30克
- 清水 1200ml

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 银耳提前用温水泡发30分钟，洗净撕成细碎小朵（越碎越容易出胶）。
2. 雪梨洗净去皮去核，切成均匀的小滚刀块备用。
3. 砂锅中加入清水和撕碎的银耳，大火烧开后转中小火慢炖35分钟，中途用勺子顺时针搅拌几分钟促进出胶。
4. 待银耳汤汁浓稠起胶质后，加入雪梨块、去核红枣继续慢炖15分钟。
5. 最后加入冰糖和枸杞，搅拌至冰糖完全融化，煮2分钟即可关火焖一会儿享用。

## 💡 大廚美味秘訣 / Chef's Tips
- 银耳撕得越碎出胶越快越多；顺时针充分搅拌能加速胶质析出。

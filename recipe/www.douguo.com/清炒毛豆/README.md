# 清炒毛豆

- **料理名稱**：清炒毛豆
- **原始標題**：清炒毛豆
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2330574.html)

## 🌿 食材及佐料清單 / Ingredients
- 新鲜毛豆 300克
- 红彩椒 半个
- 盐 1茶匙
- 生抽 1勺
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 新鲜毛豆剥壳洗净，控干水分；红彩椒切小丁搭配色彩。
2. 锅中烧开水，加入少许盐，下入毛豆粒焯水2分钟至8成熟，捞出沥干。
3. 热锅起油，下入焯好水的毛豆大火快炒。
4. 加入红椒丁继续翻炒出香，加入适量生抽和食盐调味。
5. 翻炒均匀入味后淋少许香油即可出锅装盘。

## 💡 大廚美味秘訣 / Chef's Tips
- 毛豆先焯水能去除豆腥味并缩短炒制时间，保持翠绿爽脆口感。

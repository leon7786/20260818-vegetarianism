## 📝 料理故事與簡介 / Story & Introduction
> 补气血，健脾养胃，既有营养又简单

## 🌿 食材及佐料清單 / Ingredients
- 红豆：50克
- 花生：50克
- 红枣：50克
- 枸杞：10克
- 红糖：40克
- 清水：1500毫升

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 红豆提前浸泡6小时
2. 把所有材料放入锅中
3. 大火烧开转小火慢熬1小时
4. 出锅

## 🌿 食材及佐料清單 / Ingredients
- 银耳 半朵
- 冰糖 适量
- 蝶豆花 适量
- 柠檬汁 几滴
- 桂花干 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 高颜值的养生小甜品
2. 准备好材料
3. 银耳洗净放入炖盅里，加水没过表面
4. 用“炖盅”模式炖1小时
5. 炖好加冰糖
6. 蝶豆花加水浸泡出颜色，倒入银耳羹中，加入柠檬汁撒干桂花

## 💡 大廚美味秘訣 / Chef's Tips
- 银耳不需要浸泡，喜欢吃爽口的就炖一个小时，喜欢软糯口感的就撕小朵炖一个半小时。

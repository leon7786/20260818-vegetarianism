## 🌿 食材及佐料清單 / Ingredients
- 木耳 200克
- 蒜 6瓣
- 干红椒 4个
- 白糖 20克
- 熟芝麻 20克
- 香油 20克
- 米醋 20克
- 生抽 30克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 干木耳冷水泡1小时（城里有直卖的湿木耳）
2. 去掉根部，挑选大块木耳撕成小块，方便入味
3. 起锅焯水1分钟
4. 捞出迅速过冷水，味道更脆嫩
5. 沥干水分，开始加料（蒜6瓣、干红椒4个、白糖20克、熟芝麻20克，香油20克、米醋20克、生抽30克）
6. 浇热油，之后把木耳和料一起搅拌入味，等10分钟即可开吃
7. 成品图
8. 奶奶说，好吃、喷香

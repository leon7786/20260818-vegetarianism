# 山药炒木耳

## 🌿 食材及佐料清單 / Ingredients
- 铁棍山药 1根
- 干黑木耳 10克
- 胡萝卜 半根
- 青椒 半个
- 盐 1茶匙
- 水淀粉 适量
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 黑木耳提前用温水泡发，去蒂洗净撕成小朵；胡萝卜和青椒切菱形片。
2. 铁棍山药去皮后切成斜切薄片，立即放入清水中浸泡防止氧化发黑。
3. 锅中烧开水，加入少许盐和几滴油，下入山药片、黑木耳和胡萝卜片焯水1分钟，捞出沥干。
4. 热锅倒入适量植物油，下入焯好水的食材和青椒片大火快速翻炒均匀。
5. 加入适量盐调味，淋入少许水淀粉勾薄芡，翻炒均匀使汤汁裹匀食材即可出锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 山药去皮时建议戴手套防过敏；焯水加几滴油和醋能保持山药爽脆白净。

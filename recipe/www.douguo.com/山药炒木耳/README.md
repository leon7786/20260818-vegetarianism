# 山药炒木耳

- **料理分類 / Category**：家常蔬食 / 經典熱菜

## 🌿 食材及佐料清單 / Ingredients
- 山药 1根
- 干木耳 1把
- 青红椒 各1个
- 盐 适量
- 花椒 少许
- 白糖 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备好需要用到的食材
2. 山药去皮清洗干净，然后切成菱形片。青红辣椒切小块备用。
3. 黑木耳放在冷水中提前泡发，清洗干净后撕成小朵。
4. 起锅烧水，水开放入山药片焯熟捞出控水，同样方法再将木耳炒烫1分钟捞出。
5. 起锅倒油，油热后放入几粒毛椒爆出香味，捞出。放入山药，木耳，青红椒翻炒，并加水1勺热水一同翻炒，防止粘锅。
6. 最后放入盐，点点白糖调味，即可出锅。
7. 成品
8. 成品

## 💡 大廚美味秘訣 / Chef's Tips
- 山药固然好，但有一点去皮后的山药易变黑，这时只要将切好的山药泡在白醋水中，有效隔绝空气防止氧化，山药就不会变黑了哦！

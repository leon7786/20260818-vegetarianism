# 清炒西兰花

## 🌿 食材及佐料清單 / Ingredients
- 西兰花 1朵
- 胡萝卜 适量(切花片)
- 盐 1茶匙
- 水淀粉 少许
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 西兰花切成小朵，用淡盐水浸泡10分钟后冲洗干净；胡萝卜切片。
2. 沸水锅中加入半勺盐和几滴食用油，放入西兰花和胡萝卜片焯水1分钟至断生变亮绿，迅速捞出过凉水沥干。
3. 炒锅烧热倒油，下入焯好的西兰花和胡萝卜大火快速翻炒。
4. 加入适量食盐调味，淋入少许薄水淀粉翻炒均匀裹汁。
5. 汤汁清亮后即可出锅装盘。

## 💡 大廚美味秘訣 / Chef's Tips
- 焯水加油加盐是西兰花保持翠绿不发黄的绝招，过冷水后口感更清脆爽口。

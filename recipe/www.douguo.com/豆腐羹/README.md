# 豆腐羹

## 🌿 食材及佐料清單 / Ingredients
- 嫩豆腐 1块
- 鸡蛋 1个
- 香菇 2朵
- 胡萝卜 半根
- 水淀粉 适量
- 生抽 1勺
- 盐 1茶匙
- 白胡椒粉 适量
- 香油 几滴
- 香菜/葱花 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 嫩豆腐切成细小丁，放入淡盐温水中浸泡5分钟捞出；香菇和胡萝卜洗净切细丝；鸡蛋打散。
2. 锅中倒入适量清水或素高汤烧开，下入香菇丝和胡萝卜丝煮2分钟出鲜味。
3. 下入豆腐丁轻轻推动，调入生抽、食盐和白胡椒粉调味。
4. 淋入水淀粉慢慢搅拌勾芡至汤汁浓稠滑亮。
5. 关小火缓缓淋入打散的蛋液形成丝丝蛋花。
6. 出锅前淋几滴香油，撒上葱花或香菜即可食用。

## 💡 大廚美味秘訣 / Chef's Tips
- 豆腐泡淡盐水不易碎；水淀粉勾薄芡后再淋蛋花，蛋花细腻漂浮不沉底。

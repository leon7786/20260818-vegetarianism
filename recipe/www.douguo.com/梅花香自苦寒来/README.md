## 🌿 食材及佐料清單 / Ingredients
- 酵母粉
- 南瓜
- 菠菜
- 紫甘蓝
- 咖啡粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 白色面饼做底，注意不要太薄。
2. 咖啡粉和的面捏出树脂的样子
3. 菠菜汁面粉用来剪出花心
4. 紫甘蓝揉成小面团，用白色面包起来

# 鲜榨果汁，分秒新鲜

## 🌿 食材及佐料清單 / Ingredients
- 橙子 1个
- 苹果 半个
- 胡萝卜 半根
- 柠檬汁 几滴
- 纯净水 100ml
- 蜂蜜 适量(可选)

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 橙子去皮掰成小瓣去籽；苹果洗净去皮去核切小块；胡萝卜洗净切丁。
2. 将处理好的所有果蔬块放入破壁机或原汁机中。
3. 加入适量纯净水与几滴新鲜柠檬汁（防止氧化变色）。
4. 启动果汁模式搅打1分钟至细腻无渣。
5. 倒入玻璃杯中，根据个人口味调入少许蜂蜜即可即刻饮用。

## 💡 大廚美味秘訣 / Chef's Tips
- 水果现切现榨即刻饮用营养流失最少，柠檬汁能天然抗氧化保持果汁鲜艳色泽。

## 🌿 食材及佐料清單 / Ingredients
- 鲜银耳：半朵
- 鲜莲子：110克
- 蝶豆花：数朵
- 冰糖：适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 银耳切掉根部，洗净撕成小朵备用
2. 莲子去掉莲子芯，洗净备用
3. 蝶豆花洗净沥干水分备用
4. 把莲子和银耳一起放入锅中加入适量的水，大火煮开转中小火煮至银耳出胶，莲子绵糯
5. 根据个人口味加入适量冰糖调味，即可出锅
6. 找一个自己喜欢的玻璃容器把银耳羹盛入，把蝶豆花放进去浸泡一会至蝶豆花的颜色析出，用筷子挑一挑蝶豆花就会带出渐变的色彩
7. 一杯有层次感的银耳羹就搞定啦
8. 很漂亮的哦

## 💡 大廚美味秘訣 / Chef's Tips
- 1、银耳羹一定要温热的，这样蝶豆花才能泡出颜色哦！
2、冰糖的量，根据自己的口味来调整哦！

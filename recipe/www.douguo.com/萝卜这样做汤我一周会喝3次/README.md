# 萝卜这样做汤我一周会喝3次

## 🌿 食材及佐料清單 / Ingredients
- 白萝卜 半根
- 鸡蛋 2个
- 枸杞 10粒
- 盐 1茶匙
- 白胡椒粉 适量
- 葱花 少许
- 食用油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 白萝卜去皮切成细丝；鸡蛋煎成荷包蛋备用（荷包蛋是煮出浓白高汤的关键）。
2. 荷包蛋用锅铲切成大块，锅中留底油下入白萝卜丝煸炒至变软出水分。
3. 倒入滚开的水，放入煎好的荷包蛋大火狂滚5-8分钟，汤汁瞬间变得浓白如牛奶。
4. 加入食盐、白胡椒粉和枸杞炖煮2分钟。
5. 出锅撒上葱花即可趁热喝。

## 💡 大廚美味秘訣 / Chef's Tips
- 煎蛋加入滚开水大火炖煮是奶白浓汤的核心秘诀，清甜暖胃。

# 萝卜这样做汤我一周会喝3次

## 🌿 食材及佐料清單 / Ingredients
- 干面粉 2勺
- 青萝卜 2个
- 盐 1匙
- 葱姜末 适量
- 鸡蛋 2个

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 所有材料准备好，青萝卜清洗干净用蔬菜擦擦成细丝备用。
2. 葱姜切末备用。
3. 锅内倒入适量油烧热放入切好的葱姜末爆出香味后倒入切好的萝卜丝翻炒均匀倒入适量水煮开。
4. 取2个鸡蛋磕入碗中搅散备用。
5. 等萝卜丝煮开用筷子在中间戳出一个没有萝卜丝水多的圆圈倒入2勺干面粉，用筷快速把面粉搅散煮开。
6. 煮开后倒入搅散的鸡蛋，和1匙食用盐后再次煮开关火盛出即可。

## 💡 大廚美味秘訣 / Chef's Tips
- 1：家里没有青萝卜的可以用白萝卜或者其他蔬菜代替。

2：不会我这方法的可以把面粉倒在碗里把水龙头开到最小，然后一边倒水一边用筷子搅拌干面粉，直到面粉成为细小的颗粒。

3：在往锅内倒面粉的时候一定要开小火或者关掉燃气，防止干面粉和火相遇发生爆炸。

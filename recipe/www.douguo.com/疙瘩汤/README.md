## 🌿 食材及佐料清單 / Ingredients
- 普通面粉 110克
- 水 60克
- 西红柿 1个
- 胡萝卜 1根
- 香菜 3根
- 葱头 半个
- 葱花油 10克
- 辣椒油 1勺
- 盐 5克
- 米醋 5克
- 鲁花味极鲜 6克
- 鸡精 3克
- 黑胡椒粉 2克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 所有蔬菜洗净切好备用，加入所有调料搅拌均匀。
2. 面粉加入水搅拌成絮状
3. 锅中加入清水。
4. 水开后放入面疙瘩翻滚开。
5. 加入拌好的蔬菜料翻滚开就可以了。

## 💡 大廚美味秘訣 / Chef's Tips
- 1.面疙瘩一定要大小一致，太大的话不容易熟还会影响口感。
2.所有蔬菜根据自己的喜好。

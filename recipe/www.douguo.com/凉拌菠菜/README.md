# 凉拌菠菜

## 🌿 食材及佐料清單 / Ingredients
- 嫩菠菜 300克
- 熟花生碎 20克
- 熟白芝麻 适量
- 生抽 1.5勺
- 香醋 1勺
- 香油 1勺
- 盐 半茶匙
- 白糖 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 菠菜洗净切段；锅中水烧开加少许盐和油，下菠菜焯水40秒捞出过凉水挤干水分。
2. 碗中加入生抽、香醋、香油、盐、白糖调匀成凉拌汁。
3. 将挤干水分的菠菜放入大碗，淋入调好的料汁。
4. 撒上香脆花生碎和熟芝麻抓拌均匀。
5. 装盘即可享用，鲜嫩爽口营养丰富。

## 💡 大廚美味秘訣 / Chef's Tips
- 菠菜焯水能有效去除草酸，过凉水后口感更清脆翠绿。

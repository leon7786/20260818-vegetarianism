## 🌿 食材及佐料清單 / Ingredients
- 茄子 一个
- 鸡蛋 两个
- 青椒 两个
- 西红柿 两个
- 大蒜 五瓣
- 盐 适量
- 鸡精 适量
- 食用油 一大勺
- 十三香 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 茄子洗净切滚刀块或者厚点的圆片都行。我平时都是切圆片，今天的茄子有点粗就切成滚刀块。不过个人感觉还是圆片好吃。
2. 碗中打两个鸡蛋➕一点点盐和十三香。
3. 将茄子块沾满搅匀的蛋液。
4. 锅中倒入一大勺食用油，烧热后下入裹满蛋液的茄子油炸至两面金黄。
5. 全部炸完备用。
6. 其实，这样刚炸出来的也很好吃，每次我都会一边炸一边偷吃，外面酥酥脆脆，咬一口下去，里面软嫩，比肉好吃
7. 西红柿切块，清洁切滚刀块，大蒜切片，然后锅里留一点点底油，不留也可以，下入西红柿块，加一点点水翻炒至软烂，下入炸好的茄子块，盐，鸡精，青椒块，继续翻炒至青椒变色，最后家人蒜片翻炒几下，出了蒜味就可以出锅了。
8. 开吃
这辈子唯一拿的起放不下的就是筷子

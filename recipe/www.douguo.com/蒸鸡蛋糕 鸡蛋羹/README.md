# 蒸鸡蛋糕 鸡蛋羹

![蒸鸡蛋糕 鸡蛋羹](cover.jpg)

- **料理名稱**：蒸鸡蛋糕 鸡蛋羹
- **原始標題**：蒸鸡蛋糕（鸡蛋羹）
- **素食流派 / Diet**：蛋素 Ovo-Vegetarian
- **料理分類 / Category**：家常蔬食 / 經典熱菜
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2396690.html)

## 🌿 食材及佐料清單 / Ingredients
- 新鲜鸡蛋 2个
- 温开水 约150ml
- 盐 半茶匙
- 生抽 1勺
- 香油 几滴
- 葱花 少许

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鸡蛋打入碗中，加入半茶匙食盐，顺时针充分搅打均匀。
2. 缓缓倒入蛋液1.5倍体积的温开水（约40℃），边倒边搅拌均匀。
3. 将蛋液过细网筛1-2次，彻底滤除气泡和结块。
4. 碗口包上耐热保鲜膜，用牙签扎4-5个小气孔。
5. 蒸锅水烧大开后放入蛋液碗，中小火蒸8-10分钟。
6. 关火后虚蒸2分钟取出，撕去保鲜膜，淋上生抽、香油，撒上葱花即可食用。

## 💡 大廚美味秘訣 / Chef's Tips
- 水温、蛋水比例以及过筛包膜是蒸出滑嫩如布丁、零蜂窝鸡蛋羹的三大核心。

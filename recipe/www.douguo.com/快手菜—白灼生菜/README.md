## 🌿 食材及佐料清單 / Ingredients
- 生菜 200克
- 生抽 1勺
- 盐 适量
- 蒜末 10克
- 植物油 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 生菜洗净焯水，水中加盐可以让颜色更漂亮
2. 加生抽、盐，蒜末切好放最上边
3. 锅中烧油，油热浇在蒜末上就可以开吃啦

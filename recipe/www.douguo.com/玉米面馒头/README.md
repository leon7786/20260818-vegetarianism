# 玉米面馒头

## 🌿 食材及佐料清單 / Ingredients
- 细玉米面 100克
- 酵母 3克
- 糖 20克
- 中筋面粉 200克
- 水 60克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 先把玉米面、糖放入盆中加入100克沸水用筷子搅匀，微凉后加入中筋粉放入酵母粉再加入60克的清水拌匀。
2. 分成50克的剂子（其实我觉得玉米馒头两发更好吃，这次是因为时间不够用所以就用了一发，有时间的话还是建议二发）
3. 分别揉匀揉圆
4. 放入锅中醒发40分钟左右，看状态
5. 大火烧开转中火25分钟左右即可，关火后焖3-5分钟揭锅盖，建议揭锅盖时要快馏水滴到馒头上就不好看了。

## 💡 大廚美味秘訣 / Chef's Tips
- 玉米面用沸水烫后吃起来口感更好，之前我试过没烫的口感要差一些，看个人喜好。

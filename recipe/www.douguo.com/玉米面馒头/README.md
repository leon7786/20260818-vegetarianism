## 🌿 食材及佐料清單 / Ingredients
- 细玉米面 100克
- 中筋面粉 200克
- 酵母 3克
- 温水 160克
- 白糖 10克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 玉米面用80ml沸水烫过搅拌晾至温热（烫面口感更细腻）。
2. 加入中筋面粉、酵母、白糖和剩余温水揉成光滑面团。
3. 盖保鲜膜发酵至2倍大，取出揉搓排气。
4. 搓条切剂揉圆成馒头生胚。
5. 摆入蒸屉二次醒发15分钟。
6. 开大火上汽后蒸18分钟，焖3分钟揭锅。

## 💡 大廚美味秘訣 / Chef's Tips
- 沸水烫玉米面能破坏粗纤维，做出来的粗粮馒头松软不粗糙。

## 💡 大廚美味秘訣 / Chef's Tips
- 小贴士:
如何蒸出完美鸡蛋羹，几个小技巧掌握了，你就可以做出口感嫩滑的鸡蛋羹。
1、鸡蛋和水的比例是1:2。边加入水边搅动混合均匀。
2、混合好的鸡蛋液过滤一遍，搅动混合均匀的鸡蛋液会出现很多泡沫，这样避免蒸出来的鸡蛋羹出现许多蜂窝孔。
3、蒸鸡蛋的时候，包上一层保鲜膜，并在保鲜膜上叉几个小孔。

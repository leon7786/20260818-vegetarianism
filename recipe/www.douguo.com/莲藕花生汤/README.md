# 莲藕花生汤

![莲藕花生汤](cover.jpg)

- **料理名稱**：莲藕花生汤
- **原始標題**：莲藕花生汤
- **素食流派 / Diet**：全素 Vegan
- **料理分類 / Category**：湯品羹湯
- **來源平台 / Source**：[豆果美食 · 素食專區](https://www.douguo.com/cookbook/2361047.html)

## 🌿 食材及佐料清單 / Ingredients
- 莲藕 一节
- 胡萝卜 一根
- 花生 50克
- 鸡粉 5克
- 盐 适量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 准备好煮汤的材料。
2. 花生用清水浸泡一会儿清洗干净。
3. 莲藕洗干净削皮切小块。
4. 胡萝卜洗净削皮滚刀切块。
5. 将所有材料全部放入锅中，一次加入足够的清水，没过材料。
6. 撒入适量的鸡粉。
7. 放入蒸烤箱内，选择纯蒸模式，110度蒸制一小时15分钟左右即可。
8. 出炉后加入适量盐调味即可装碗开喝。别看它是素汤哦，也是色香味俱全的，赶紧来一碗尝尝吧！尝过保准你食欲大开，喝了还要喝。

## 💡 大廚美味秘訣 / Chef's Tips
- 没有蒸烤箱的小伙伴可以直接在煤气灶上煮，或者放压力锅压也是可以的。

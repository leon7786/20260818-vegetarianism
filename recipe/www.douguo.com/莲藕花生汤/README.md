# 莲藕花生汤

## 🌿 食材及佐料清單 / Ingredients
- 莲藕 1节
- 红皮花生米 50克
- 红枣 6颗
- 枸杞 10粒
- 盐 适量
- 清水 1500ml

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 花生米提前用清水浸泡1小时；红枣洗净去核备用。
2. 莲藕洗净刮去外皮，切成厚滚刀块备用（粉藕煲汤更香浓）。
3. 砂锅中注入足量清水，放入泡好的花生米和切好的莲藕块。
4. 大火烧开后撇去浮沫，转小火慢炖1小时至莲藕软糯粉香。
5. 加入红枣继续炖煮20分钟，出锅前5分钟加入枸杞与适量食盐调味即可。

## 💡 大廚美味秘訣 / Chef's Tips
- 挑选粉质莲藕（藕节短粗、表皮粗糙），砂锅小火慢煲能最大程度激发花生与莲藕的甘甜本味。

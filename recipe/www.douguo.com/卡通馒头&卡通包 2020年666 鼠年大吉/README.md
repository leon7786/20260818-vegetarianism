## 🌿 食材及佐料清單 / Ingredients
- 中筋面粉 250克
- 酵母 2.5克
- 红曲粉 少许
- 南瓜粉 少许
- 竹炭粉 少许
- 细砂糖 15克
- 水 125克

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 面粉与酵母、糖水混合揉成光滑细腻面团，分出少量分别加入红曲粉、南瓜粉、竹炭粉调色。
2. 红色面团包入豆沙馅捏出吉祥小老鼠身体，贴上粉嫩大耳朵。
3. 黄色面团捏出金元宝与“666”吉利字样贴在主体上。
4. 用竹炭面团搓细条点出萌萌胡须、小眼睛和小鼻子。
5. 生胚摆入蒸笼发酵至1.5倍大。
6. 水开后中火蒸13分钟，焖3分钟揭盖出炉。

## 💡 大廚美味秘訣 / Chef's Tips
- 制作卡通造型需动作迅速，防止先做好的部件提前过度发酵变形。

# 知足見花開

![知足見花開](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：知足見花開
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：全素 Vegan (佛教純素)
- **料理分類 / Category**：面食主食
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=102&id=29)
- **刊物出處**：資料來源：《佛聯匯訊》
- **功德鳴謝**：鳴謝：溫綺玲居士

## 🌿 食材清單 / Ingredients
- 椰菜花 300克
- 鮮茴香 200克
- 芫茜 3棵
- 薑粒 1茶匙
- 鮮腐皮 2片
- 炸菜粒 1湯匙
- 甘筍粒或紅圓椒粒 少許

## 🧂 調味料 / Seasonings
- 橄欖油 適量
- 生抽 適量
- 鹽 適量
- 胡椒粉 少許
- 稀少糖 少許
- 水 約1杯

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 椰菜花切小件，洗淨後，放進攪拌機攪至略碎。
2. 鮮茴香、芫茜切幼粒。
3. 熱油鑊，爆炒少許薑粒，加入剪碎的鮮腐皮，慢火邊攪邊加水煮成蓉，最後才加適量生抽、鹽、胡椒粉，炒勻盛碟。
4. 熱油鑊，爆炒薑粒、茴香粒、炸菜粒、甘筍粒及紅圓椒粒，兜炒一會，加入椰菜花碎、芫茜碎、鹽、糖等，灑少許水，冚上鑊蓋，略煮一會。
5. 上碟前，加入鮮腐蓉，炒勻即可。

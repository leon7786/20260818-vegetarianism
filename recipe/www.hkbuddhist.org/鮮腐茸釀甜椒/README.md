# 鮮腐茸釀甜椒

![鮮腐茸釀甜椒](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：鮮腐茸釀甜椒
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：全素 Vegan (佛教純素)
- **料理分類 / Category**：面食主食
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=64&id=29)
- **刊物出處**：資料來源：《佛聯匯訊》
- **功德鳴謝**：鳴謝：溫綺玲居士

## 🌿 食材清單 / Ingredients
- 鮮腐皮4塊
- 細紅
- 黃燈籠椒2個
- 鮮冬菇4粒
- 芫茜切碎2湯匙
- 馬蹄碎3湯匙
- 幼薑粒半湯匙
- 清水約3湯匙

## 🧂 調味料 / Seasonings
- 醬油1湯匙
- 麻油1/2茶匙
- 黃砂糖1茶匙
- 清水4湯匙
- 生粉約1茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 鮮腐皮撕碎，熱油鑊，爆薑粒，放入腐皮碎，炒勻；加入清水，慢火煮一會；再加入芫茜碎、馬蹄碎。腐皮煮成茸後，灑入鹽，炒勻盛起備用。
2. 洗淨燈籠椒切件去瓤，底部掃上生粉，釀入腐皮茸。
3. 鮮冬菇洗淨去蒂，底部掃上生粉，釀入腐皮茸。
4. 燒熱油，將燈籠椒及鮮菇放於鑊中，腐茸朝底。
5. 慢火煎約5分鐘，將腐茸煎至金黃，再反轉煎，加入調味料，冚蓋煮約3分鐘，盛碟，將餘下的汁料淋上面便成。

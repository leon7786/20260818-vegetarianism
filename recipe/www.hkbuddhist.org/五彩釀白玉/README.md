# 五彩釀白玉

![五彩釀白玉](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：五彩釀白玉
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：全素 Vegan (佛教純素)
- **料理分類 / Category**：面食主食
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=53&id=29)
- **刊物出處**：資料來源：《香港佛教》月刊
- **功德鳴謝**：鳴謝：鄺梓罡 佛門網 素食餐廳「雅．悠蔬食」

## 🌿 食材清單 / Ingredients
- 白蘿蔔 1條（中型約900克）
- 泰國蘆筍 4條
- 紅蘿蔔（細條）半條
- 白菌 4粒
- 雞脾菇（中型）1/3條
- 馬蹄 2粒
- 薑米 少許
- 南瓜蓉 50克

## 🧂 調味料 / Seasonings
- 糖 / 碎冰糖 1湯匙
- 白胡椒粉 少許
- 薑片 2片
- 鹽 1茶匙
- 香菇粉 1茶匙
- 素蠔油 半湯匙
- 醬油 1茶匙
- 鹽 1/3茶匙
- 糖 1茶匙
- 香菇粉 半茶匙
- 生粉水 適量
- 麻油 適量

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 將白蘿蔔切段後用曲奇餅模整形。
2. 用挖圓器在蘿蔔上半部挖一個洞，備用。
3. 用油將薑爆香後加水、糖、鹽、香菇粉及胡椒粉作素上湯。
4. 將白蘿蔔放入蒸碟，加入素上湯至蘿蔔的一半高度，蒸25至30分鐘至軟身，備用。
5. 將所有食材洗淨，切小粒，備用。
6. 燒熱鍋落油，下薑米爆香後，加入菌類炒香，再加入紅蘿蔔炒香後，加入蘆筍炒至微軟。
7. 加入醬油、素蠔油炒香後，加入少許水及其他調味料略煮一會，最後加入生粉水埋芡，備用。
8. 組合：
9. 將蒸蘿蔔後的素上湯隔去薑片加入適量南瓜蓉略煮，最後加入生粉水埋芡，備用。
10. 將南瓜汁淋在碟上後，放上已釀入餡的蘿蔔，再配上裝飾即完成。

# 炸素雲吞

![炸素雲吞](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：炸素雲吞
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：全素 Vegan (佛教純素)
- **料理分類 / Category**：面点小吃
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=56&id=29)
- **刊物出處**：資料來源：《香港佛教》月刊
- **功德鳴謝**：鳴謝：衍悌法師 凌雲寺

## 🔪 材料處理 / Preparation
1. 把所有材料（除雲吞皮外）切至非常小粒。

## 🌿 食材清單 / Ingredients
- 廣東雲吞皮
- 沙葛
- 紅蘿蔔
- 冬菇（少許）
- 雞脾菇
- 榨菜
- 唐芹菜
- 按其快熟程度要依次序炒
- 沙葛定要炒熟。雲吞餡一定要完全散熱才可以包。

## 🧂 調味料 / Seasonings
- 素咖哩粉
- 生抽
- 鹽
- 糖
- 胡椒粉

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 多油起鑊，按其快熟程度依次序加入紅蘿蔔，沙葛，雞脾菇，炸菜及冬菇。炒至材料軟身後立即起鑊。
2. 少許油起鑊，加入素咖哩粉，水少許及其它所有調味料。然後加入所有材料及唐芹，炒至水份收乾。
3. 讓所有材料徹底散熱後才可以開始製作雲吞。
4. 把煮熟之材料少許放置於雲吞皮的正中，三角形對邊沾上清水，兩指輕壓雲吞皮便可合上。
5. 用熱油炸雲吞至金黄色便可。

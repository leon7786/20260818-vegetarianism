# 法式焗素田螺伴紫薯薑蓉

![法式焗素田螺伴紫薯薑蓉](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：法式焗素田螺伴紫薯薑蓉
- **份量 / Servings**：4件份量
- **素食流派 / Diet**：奶素 Lacto-Vegetarian
- **料理分類 / Category**：养生汤品
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=69&id=29)
- **刊物出處**：資料來源：《香港佛教》月刊
- **功德鳴謝**：鳴謝：鄺梓罡 佛門網 素食餐廳「雅．悠蔬食」

## 🌿 食材清單 / Ingredients
- 白菌4粒
- 即食栗子4粒
- 片裝芝士1至2片（純素者可選擇以素芝士取代片裝芝士）
- 紫心蕃薯600克
- 牛油30克
- 淡忌廉60克（純素者可選擇以椰子油取代牛油及淡忌廉）

## 🧂 調味料 / Seasonings
- 素蠔油適量
- 海苔絲適量
- 薑汁2湯匙
- 鹽1/3茶匙
- 糖1茶匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 將紫心蕃薯去皮切塊蒸熟，蒸約30分鐘。蒸熟後趁熱加入牛油、淡忌廉及調味料，然後用叉壓成蓉，備用。
2. 片裝芝士一開四成小正方形，備用。
3. 用一焗盤先放紫薯薑蓉，然後將白菌去蒂放在紫薯薑蓉上。
4. 在白菌的凹處加入素蠔油及海苔絲，然後放上一粒即食栗子，最後放上小正方形芝士。
5. 用200度焗爐焗約10分鐘，完成，趁熱享用！

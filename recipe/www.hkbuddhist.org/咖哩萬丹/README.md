# 咖哩萬丹

![咖哩萬丹](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：咖哩萬丹
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：奶素 Lacto-Vegetarian
- **料理分類 / Category**：面食主食
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=48&id=29)
- **刊物出處**：資料來源：《香港佛教》月刊

## 🌿 食材清單 / Ingredients
- 薯仔2個
- 豆卜4両
- 冬菇丸10粒
- 冬菇少量
- 毛茄約10條
- 香茅2支
- 黃薑半両
- 檸檬葉數片
- 1湯匙黃咖哩粉
- 鮮椰汁半杯
- 花奶半杯

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 將香茅、黃薑、檸檬葉、黃咖哩粉爆香，加水煮半小時
2. 薯仔去皮洗淨，切開數塊，走油5分鐘備用。毛茄用鹽、油、水拖熟備用。咖哩汁煮好後放入豆卜、冬菇丸和冬菇炆15分鐘，再放入薯仔炆10分鐘；最後倒入椰汁及花奶攪勻，立刻熄火。上面加上已熟的毛茄做裝飾。

# 椰汁腐皮卷

![椰汁腐皮卷](cover.jpg)

## 📋 基本資訊 / Recipe Overview
- **料理名稱**：椰汁腐皮卷
- **份量 / Servings**：2-4 人份
- **素食流派 / Diet**：全素 Vegan (佛教純素)
- **料理分類 / Category**：面点小吃
- **來源平台 / Source**：[香港佛教聯合會 · 素食食譜](https://www.hkbuddhist.org/zh/top_page.php?p=medical_menu_detail&cid=7&type_id=2&mmid=63&id=29)
- **刊物出處**：資料來源：《佛聯匯訊》
- **功德鳴謝**：鳴謝：溫綺玲居士

## 🌿 食材清單 / Ingredients
- 鮮腐皮6張
- 青、紅、黃椒各1/5個
- 豆粉少許
- 馬蹄5粒

## 🧂 調味料 / Seasonings
- 黃薑粉1茶匙
- 玉桂枝1/4枝
- 薑1大片
- 椰奶1杯
- 五香粉少許
- 鹽少許
- 香葉3片
- 香茅1枝
- 做法：
- 1.在鍋內放入薑、香茅（拍扁）、香葉、椰奶、玉桂枝、鹽，再加入1/2杯水慢火煮至出味。
- 2.放入己煎好的腐皮卷煮一會即可。

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 4張腐皮切成大約3x3吋的正方形。
2. 將青、紅、黃椒、馬蹄切粒，加入少許鹽拌勻。
3. 2張腐皮加少許水，用慢火將腐皮煮成蓉，然後加入黃薑粉，再加入青、紅、黃椒粒炒勻。
4. 放少許五香粉在切成正方形的腐皮上。
5. 放入適量腐皮蓉，將腐對捲好，沿邊塗上少許豆粉包好。
6. 將己包好的腐皮卷煎至金黃色。

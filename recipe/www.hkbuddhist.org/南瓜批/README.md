# 南瓜批

![南瓜批](cover.jpg)

## 🌿 食材清單 / Ingredients
- 牛油（切粒） 50克
- 中筋麵粉 225克
- 冰水 2-3湯匙
- 南瓜醬 2杯（弄成薯蓉質地）
- 煉奶 一罐
- 費城奶油芝士 一塊
- 肉桂 一茶匙（根據你的口味，可以加入更多） 肉荳蔻 一茶匙
- 香草精華 一茶匙
- 玉米澱粉 兩湯匙

## 🍳 烹飪步驟 / Step-by-Step Cooking Steps
1. 用指尖搓勻凍牛油和麵粉。也可以使用搞拌器混合。搓勻後看起來應該像麵包屑。然後加入兩湯匙冰水，形成一個麵團。如果麵團沒有如期形成，再加入1/2到1湯匙冰水。麵團不應該是粘的，但應該是順滑和容易塑造。
2. 用你的手搓麵團，直到它看起來順滑。然後將它搓成球形，並把它放在冰箱約20分鐘，直到麵團變得比較硬。
3. 把焗爐預熱至220度，不用風扇。從冰箱取出麵團，根據你焗盤的形狀，將之攤平成一大圈或正方形。請確保你的麵團覆蓋了焗盤的外沿。
4. 將麵團放在焗爐中烤20分鐘。完成後，放在一邊。
5. 烤箱預熱至220度，不用風扇。南瓜和煉奶混合在一起，再拌入奶油芝士。由於奶油芝士是固體，你可能需要使用手動攪拌器混合，完成後應該是非常順滑的糊狀物。最後把所有其餘的成分加入搞拌。
6. 倒入剛才放在一邊的焗盤，焗50-55分鐘。攤凍後，就可以享用。
7. 智慧小錦囊：
8. 檢查餡餅看它是否已煮熟。方法是把牙籤插入其中，如拔出時沒有沾到餅餡，就是熟透了。有時你可能需要焗較長或較短的時間，或增加溫度，因為所有的焗爐都不同。
